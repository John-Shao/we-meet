# 会议实录子页面工具条

## 范围与行为

- Web 概要、章节纪要、译文及记录信息采用固定工具条与独立正文滚动区；文字记录沿用现有工具条。没有面板级操作的发言人页签不留空工具条。
- Android 概要、章节纪要、译文、记录信息及纪要工具行采用相同分层。常用操作直接显示，次要操作进入更多菜单，译文语言使用底部选择面板。
- 下载原文件固定在记录信息顶部；移入回收站进入页头菜单，保留权限、版本校验及确认流程。纪要文档页面不提供删除整条记录的入口。
- 段落编辑、片段回听、发言人修改、分页和错误恢复仍位于对应内容附近。
- 切换页签保留逐字稿搜索、译文语言及阅读位置；正文查询继续随页签卸载，权限失效仍清除私有正文。
- Web 页头可换行，短窗口限制页头和播放器区域高度，避免大字体时挤掉工具条和正文。

## 验证

- Web：118 项相关单元测试通过；TypeScript、ESLint、多语言结构和设计基础检查通过。
- Chromium：`src/frontend/scripts/check-transcript-toolbar-ui.mjs` 使用固定 GET 数据，检查 320、390、1440px、视频分栏、深色与 200% 字体、固定位置、搜索与语言恢复、滚动恢复、译文下载链接及键盘关闭菜单、删除取消无写入。
- Android：构建、设计 token 检查及 4 项 FoundationTokensTest 通过；模拟器使用隔离测试 Application，27 项译文、回收站、播放定位、页签恢复及截图定向测试通过。
- Android 窄屏：实际模拟器调整为 320dp、1.5 倍字体，记录信息下载和页头菜单、长译文滚动后工具条可见检查通过。测试后恢复原尺寸和 1.0 字体。
- 扩展运行 `RecordScreensTest` 时，旧 `detail` helper 仍查找已移除的“智能纪要”页签，另有列表排序用例等待空闲超时；该整组运行不计为通过。相关播放测试已改用新图标的无障碍标签，单独复验。
