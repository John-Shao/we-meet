# 第十批：发言时长与占比

录音与上传记录的发言人页现在显示服务端计算的片段时长和占比，Web 使用可访问的 meter，Android 使用进度条与文字。说话人身份仍是转写轨道；归属为某成员不等于已做声纹实名或跨轨道合并。

统计从 current_originals 读取当前发布的转写代次，跨全部原文及说话人分页计算，不只累加当前屏幕。对同一说话人/采集会话的区间取并集，多人重叠分别计时；包含未知发言人的时间。占比的分母为所有有效区间的说话人时长之和，不是媒体总时长。转写区间可能包含停顿，所以这是估算，不能解释为精确声学发声率。

缺少结束时间的区间不补猜终点，整体提示 partial；全部不可用、超过 50,000 段统计预算时返回 unavailable 和 null，不能把首批扫描结果冒充全量。旧后端缺少 activity 字段时客户端同样显示暂无统计。计算后复核 record revision，变化时返回 409，避免混用不同版本。

发言人接口仍要求全文权限，线上会议分支保持原接口；上传来源不再错误依赖原生录音 rollout 开关。本批未添加可点击的精细发言时间轴，未实现线上会议统计。

验证：后端 16 项通过，覆盖同轨重叠、未知发言、缺结束时间、跨页分母、预算、计算中版本变化及原有全文权限回归；Web 19 项通过，含 meter、无数据/非法比例降级和工作区；Android Pixel 8 / Android 16 模拟器 2 项通过，覆盖部分统计说明和无数据降级。TypeScript、ESLint、Ruff 通过。无需数据库迁移，没有用真实 ASR 样本声称统计准确率。
