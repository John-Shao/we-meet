# 第四十批：双端回收站入口与恢复

## 完成内容

- 记录库/纪要库只在服务器声明 `trash_available` 时显示回收站；旧后端或关闭开关不出现可用入口，空库仍可进入回收站。
- 信息页仅所有者获得 `capabilities.trash` 且有生命周期版本时显示“移入回收站”。确认展示目标记录和影响：隐藏内容、撤销记录分享、关闭自动纪要；外部文档副本保持独立。
- 回收站按服务端游标分页，选择目标后明确确认恢复；恢复不重新分享，不开启自动纪要。回收后退出详情，恢复后刷新列表。
- 请求冻结用户看到的 `lifecycle_revision`；结果未确认时可显式重试同一操作，冲突/权限错误禁止直接重复，返回刷新后重新核对。无自动写入重试。
- 双端隐藏失败权限检查后的旧列表；账号范围隔离。Android 前后台切换沿用私有内容清理机制；Web 确认面板卸载后不执行迟到的导航。
- 永久删除和自动过期清理尚未实现，界面明确说明；原有音频保留规则继续生效。

## 验证

Web 47 个不同用例通过（回收站 7、列表 15、工作区 25），TypeScript 构建、ESLint、五语言键和 120 份 JSON 检查通过。Android 29 项仓库单元、6 项 Pixel 8 仪器测试及设计检查通过：确认/取消、结果未知后重试、冲突禁止重复、分页恢复、权限变化清理。Android `210345aa` 已推送并安装 debug APK；正式分发仍待完成。

现网只读核对：Pixel 8 登录所有者测试账号，旧后端的记录库未出现回收站入口；专用音频样本 `miaoji-b30-20260920-audio` 的信息页未出现回收操作。点击已有人工导出的来源，实际打开只读的 Human revision 6，正文保留验收副本标记，没有创建导出。截图已检查。此项只覆盖一个来源跳转，不替代早于当前稿、撤权和账号切换的完整验收。

实测发现来源按钮仍写着“AI 纪要版本”，双端已统一改为“来源纪要版本”，同时适用于 AI 和人工稿。Android 文案修正 `9fcdb382` 已推送，资源编译通过；模拟器当前安装的 `210345aa` 尚未包含这两处文案修正。
