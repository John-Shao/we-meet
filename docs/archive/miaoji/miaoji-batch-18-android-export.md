## 导出阻断

真实 App 选择 TXT 并从系统文件选择器返回后，生成 `transcript-ca527aa6.txt`，但大小为 0 字节。`visibleRead` 在后台清空私有正文，导致包含 Activity Result 回调、导出格式和协程的 `RecordOriginals` 被销毁。选择器返回时已没有原来的导出状态。

导出控制器现放在稳定的详情页层，按 viewer/recordId 隔离，选择的格式通过 saveable state 保留；正文继续在后台清除。返回后重新请求受授权保护的导出接口，在 IO 调度器流式写入；失败或任务取消时清理不完整文件。不会为了导出而保留后台私有正文。

21 项 `RecordScreensTest` 仪器测试全部通过，包括新增“打开选择器→进入后台→私有正文清除→返回→收到结果→文件内容完整”的回归；原有撤权、草稿、引用及版本测试同时通过。提交设计 token 检查通过。初次新增测试曾因 MediaStore 测试夹具未创建物理文件失败，修正夹具后通过；不将该夹具错误记为产品回归证据，产品证据是上述实际 0 字节文件。

## 尚未覆盖

模拟器无实际听音验收；未覆盖物理设备、Web 页面、长于 30 段跨页、超过 100 MiB 分片故障恢复、签名 TTL 续期、其他身份撤权及分享。小文件普通上传只显示不定进度，取消语义还需核查，属于接下来应改进的上传体验。说话人分离仍默认未启用，不能把“未知说话人”统计展示等同于已完成分人能力。
