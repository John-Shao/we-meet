# 第三十七批：可靠媒体时长

## 行为与边界

信息页与发言分布使用有来源依据的媒体时长，不将识别结束时间当成完整媒体长度。发言占比仍以识别片段时长为分母；完整标尺保留尾部静音。

- 新上传音频转写成功时，原始音频时长随发布回执保存；不是计费时长。依据[供应商字段说明](https://www.alibabacloud.com/help/zh/model-studio/fun-asr-recorded-speech-recognition-http-api)中的 `properties.original_duration_in_milliseconds`；拒绝非法值、超过 12 小时和短于识别区间的值。
- 视频音轨长度不作为完整视频长度。Web/Android 在授权播放器读到媒体元数据后可使用整文件时长，切换记录或卸载播放器时清除；历史上传件也可采用此方式。
- 单次、已停止且保存回执完整的原生采集使用已保存 PCM 时长。缺片、间断或中断的回执仅显示已保存长度及局限提示；进行中、多次采集、线上会议和缺少元数据的记录显示未知。
- 采集保存回执证明保存产物长度，不证明现场声音完整。未增加视频后台探测、历史批量回填或多时钟映射。
- `media_timing` 是兼容性新增字段；无数据库迁移。保留现有可见性、播放器权限和共享边界，不保存客户端上报的时长或签名 URL。
