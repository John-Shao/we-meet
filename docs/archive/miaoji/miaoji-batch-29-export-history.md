# 第二十九批：个人纪要导出历史分页

## 实现

- document-exports 列表由固定最近 10 条扩展为每页 10 条，新增可选 next_cursor，旧客户端仍读第一页。保留原有 source_kind/source_id/language 组合选择行为。
- 使用 created_at/id 倒序组合键分页，同一时间创建多条结果和翻页期间新增导出不会导致旧记录遗漏/重复。签名游标绑定账号、记录及筛选条件，不能篡改、跨账号或跨记录复用；长度限制 2048。
- Web 和 Android 信息页增加前后翻页；每页重新鉴权，只读取本人的导出回执。读取/翻页不会创建文档、重试任务或修改 Docs 访问权限。账号/记录变化重置分页；读取失败隐藏旧链接。
- 老服务端缺少 next_cursor 时保持单页；导出开关关闭后已有回执仍可阅读，文档原站变化后的 can_open 保护保留。

## 验证与发布

- 后端 16 项、Web 9 项、Android 11 项单元及 10 项 Pixel 8 仪器测试通过；新版 debug APK 已安装。
- 类型、ESLint、Ruff、JSON/多语言结构、Android 设计 token 检查通过。
- 本批无数据库迁移，需要发布 backend/frontend 及新版 Android；生产验收尚未进行。第 26/27 批所需迁移仍按正常 Helm 发布执行。

G6 的“更多个人导出历史”已实现。可靠媒体总时长、人工纪要历史精确版本跳转仍未覆盖；本批的合成导出历史分页不等于用户延后的长原文跨页生产验收。
