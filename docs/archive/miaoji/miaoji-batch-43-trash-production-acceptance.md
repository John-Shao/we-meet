## 通过项

- 开关启用后，列表声明 `trash_available`，所有者详情声明 `trash`。App 信息页出现回收入口，确认包含目标标题及权限影响；取消后生命周期版本保持 0。
- 给主样本临时授予读者全文只读权限。读者可以读原文但无回收能力，回收/恢复 API 404，读者回收站不包含该样本。
- App 确认回收后样本从正常库消失；所有者和读者的详情、原文、发言人、纪要版本、人工纪要、导出历史、媒体续签 7 类接口均 404，上传控制旧入口也 404。回收站仅向所有者暴露 id、标题、来源、回收时间和生命周期版本，不含正文。
- 相同回收请求（观察版本 0）重试返回同一版本 1；旧版本恢复请求 409。App 回收站展示专用样本，明确说明永久删除未提供、原音频保留规则继续适用；确认恢复后回收站显示空态，关闭后正常库恢复该记录。
- 恢复后生命周期版本为 2，内容 revision 未变化；全部 18 个原文片段、纪要/人工稿/导出响应及媒体时长与基线一致，媒体端点恢复可读。该主样本的纪要/人工稿/导出基线为空，不据此宣称非空历史产物均已生产验收。
- 原读者恢复后仍 404，所有者分享列表为空。再次撤销已不存在的分享预览返回 409，这是没有可撤销授权的冲突，不是残留分享；最终以空授权列表和读者 404 确认清理。旧回收请求在恢复后重放 409，同一恢复请求可幂等重试且不复活分享。
- 新建原生会话 preparing、recording 两种状态均拒绝回收（409），生命周期版本保持 0。停止并 finalize 后显式开启自动纪要，再回收和恢复；自动纪要变为 off，版本加 1，恢复后未重启。空原文和空纪要版本集合保持不变。
- 原生样本回收期间，旧 capture 详情、audio、transcription、translation/archives 4 类接口全部 404；恢复后可正常读取。最后两条样本均处于正常库，原生采集 stopped、自动纪要关闭，主样本授权列表为空。

## 发现的问题与边界

**App 导航缺陷**：从 AI 录音的“录音详情 → 记录详情”进入，回收成功后的通用返回回调只弹出一层，落在已不可读的录音详情，显示错误页。权限拒绝符合预期，但导航体验不合理；第 44 批修正为回记录库并移除旧详情返回栈。此问题不阻止数据回收/恢复，但不将本批记为全流程无缺陷通过。

本批没有执行永久删除，未撤销已经发出的对象存储签名 URL；只验证新媒体读取/续签被拒绝。未生产构造 30 条以上回收站分页、处理中 ASR/外部导出忙态、非空历史产物回收恢复或不同端的撤权可见清理；已有相关本地回归证据不代替这些生产测试。Web 页面、正式 App 分发、物理设备仍待验收。大文件恢复与长原文跨页继续延后。
