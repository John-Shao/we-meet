# 第三批：文字与播放联动、长录音定位

日期：2026-09-20。对应复评中的播放同步和长内容阅读缺口。

- Web 从当前页面的真实时间区间计算高亮，修复页壳传入空高亮导致原文不跟随的问题；上传记录的文字时间戳接入播放器。
- Web 和 Android 在播放离开当前页时按 `at_ms` 获取有界窗口，可向前跳播、向后回放，不必下载全部原文。定位保留最近已开始段落以提供静音间隙上下文，高亮仍遵守段落结束时间。
- 服务端先执行权限、当前/指定已发布转写版本、搜索及发言人过滤，再定位并分页；保留记录版本冲突检查。
- 手动分页、搜索、校对期间暂停自动定位；“回到播放位置”清除过滤并恢复跟随。Web 手动滚动的抑制到期会主动恢复；Android 拖动暂停至主动恢复。
- Android 上传记录接通文字跳播，取消仅取第一页的独立时间轴请求；修正发言人筛选参数 `speaker_id` 与服务端 `speaker` 不一致。Web 不再发送非法空 `speaker`。

验证：服务端搜索/定位 5 项通过（含 65 段跨页、游标连续性、时间边界、权限、版本冲突）；Web 原文、页壳、时间定位和滚动跟随回归通过；TypeScript 与 ESLint 通过；Android Repository / TranscriptSync 单元测试及设备测试源码编译通过。没有连接设备，未声称完成真机视觉或交互验收。

边界：只对具有源时间偏移的独立录音和上传记录启用；线上会议的墙钟原文不强行映射到独立媒体时间。仍为段落级定位，没有新增字词级 ASR 时间戳。
