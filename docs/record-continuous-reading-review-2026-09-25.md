# 会议实录连续阅读

文字记录、导入文件译文、会议/AI 录音译文归档改为按滚动位置自动追加。
接口仍分批请求；已加载内容按片段 ID 去重，失败停在底部，显式重试同一游标。
重复游标终止加载，防止循环请求。刷新重读已加载范围，保留正文和滚动容器；
权限、来源或响应身份失效时隐藏全部旧正文。

刷新属于页签顶部工具条。编辑逐字稿时禁用刷新和自动追加；搜索和播放定位
仍由服务端定位，跳到中部后可从工具条/更多菜单“从头阅读”。
App 刷新文字不刷新详情页，因此不会重建播放器。

Web 使用 IntersectionObserver 观察实际面板滚动区，提前 240px 请求；
不可见片段使用 content-visibility 延迟布局/绘制，保留搜索命中和编辑节点。
Android 使用 LazyColumn，在距末尾三个条目时请求下一批。
底部保留可访问的加载更多入口作为自动加载的兜底。

测试覆盖自动加载、追加后前文仍可读、重复触发不重复请求、失败重试、刷新
位置保持、搜索范围切换、权限撤销和来源身份校验。浏览器脚本使用本地模拟
响应，覆盖 320/390/1440px、深色模式、大字体；Android 使用本地模拟器。
