# Android 导入前身份选择与恢复流程走查

日期：2026-10-10（Asia/Shanghai）。范围：Android AI 录音／导入入口、三种上传声明、登录会话边界、目录生命周期和预检失败决定；核对现有后端和 Web 的导入契约。

Android 实现提交：[`abee2a10`](https://github.com/John-Shao/we-meet-android/commit/abee2a103cbd4b424ccf9a00ea7fb6578af9c815)，分支 `feature/speaker-identity-voiceprint`。

## 本轮实现与走查结果

Android 上传前可以显式开启身份识别，选择本人或有权限的组织范围，搜索、分页并选择候选人。开启身份识别同时开启说话人区分；切换范围清空原候选，关闭说话人区分清空身份意图。目录仅显示姓名与用户 ID，不显示是否登记声纹，也不会自动选中成员。

普通上传、直传及分片携带同一个冻结身份声明；个人范围明确发送 `organization_id: null`。新增独立 Retrofit 上传控制接口，为生产请求绑定预期账号和原登录会话；账号切换、同一账号重新登录或迟到响应均不能继续旧上传或导航。登录标识只作为本地请求 tag，不作为 HTTP 头发送；对象存储请求不携带应用账号或凭据。

预检停止后显示“重新进行身份预检”和“继续普通转写”两个明确决定，发送原 attempt 后读取新状态。界面不会自动继续、重新上传文件或调用收费 ASR 重试。转写成功后的独立身份请求显示排队／已提交／不可用状态；身份失败保留完成的转写和人工标记能力。

| 走查问题 | 修复 |
|---|---|
| 上传仅绑定用户 ID，同一账号重新登录仍可能沿用旧请求、票据和选择 | 上传面板与请求固定原登录世代；恢复保存状态还核对登录标识，旧会话关闭面板并阻止迟到写入／导航 |
| 分片恢复使用通用异常回退，会吞掉协程取消并尝试新建上传 | 单独传播 `CancellationException`，取消恢复不能发起 begin |
| 私有请求的内部超时捕获可能吞掉外层超时取消 | 转换自身超时前检查父协程，外层取消继续传播 |
| 页面进入后台后，未完成的目录刷新可能接着重读成员并写回姓名 | 隐藏时使读取失效并清除姓名／目录；可见状态门禁阻止刷新链继续读取，恢复前台重新读取当前授权目录 |
| 范围切换短暂保留旧目录；点击当前范围可能意外清空已选成员 | 切换立即清除旧页，当前范围重复选择保持原显式选择 |
| 能力关闭使候选预算为零，容易阻止已经 PUT 的文件完成确认 | 新选择继续受当前能力约束；已发送声明保持冻结，重试原完成确认不再依赖新目录预算，仍由服务端核对原声明和当前授权 |
| 身份选择门禁可能收窄系统文件提供者原有的未知大小支持 | 保留未知大小的有界流式上传，实际字节同时受上传和身份预检上限约束 |
| 未选候选可能被误报为文件无效 | 文件有效性与候选就绪条件分开；目录失败阻止新的身份导入，但保留明确选择，允许关闭身份选项 |
| 大字号长姓名在全圆角按钮中换行后仍被圆角裁掉首尾行 | 范围按钮与移除候选按钮改用主题小圆角；候选姓名使用有界可换行布局，底部提交按钮保持可达 |

选择恢复仅保存明确选择的组织／用户 ID，不保存目录姓名、声纹存在性或音频内容。成员姓名只存在于当前可见选择器内。其他原有导入恢复信息仍遵守已有上传流程；进程重建需要重新读取私有目录才能发起新身份导入。

## 验证

上传与新身份契约／控制器共 56 项 JVM 回归通过，其中普通上传、直传、分片和取消既有回归 33 项，身份契约 14 项、选择器 9 项。覆盖三种声明、个人 null、候选预算、错误目录、登录切换、迟到签名、冻结完成确认、未知大小字节上限、后台刷新及内外层取消。

新增六项 API 29 模拟器测试使用独立应用 `com.we.meet.fixturespeakeridentity`、隔离 Application runner、合成 WAV 与进程内 HTTP 拦截器，通过范围切换／候选选择、两种明确预检决定、同一账号重新登录、能力关闭后仅重试完成确认，以及中文暗色 1.8 倍字号和无空格长姓名交互。长姓名额外检查文本布局无溢出及位于弹窗横向边界内，并人工查看截图。

最终将六项新增界面测试与三项既有文件选择／同文件未确认重试／大文件分片进度和取消用例组合执行，共九项通过。既有分片夹具将全零字节标记为 MP4，API 29 的 MediaStore 持续返回零大小，导致测试尚未进入界面即失败；改为同样 101 MiB、结构有效的合成静音 WAV，并在有界时间内等待准确元数据，保持实际大小、分片路径和取消断言。没有放宽产品文件校验或把该失败计为通过。

英文／中文新增 27 项资源的名称及格式占位符一致；其他现有语言使用 Android 默认英文回退。设计规范检查、Debug 与隔离 AndroidTest APK 构建、diff 空白检查通过。截图和验证日志保存在工作区 `work/voiceprint-import-android-ui-2026-10-10/` 及 `work/android-import-*.log`，不进入仓库。

没有使用真人声音、真实麦克风、收费 ASR 或云端存储，也未部署生产环境。测试应用的录音权限保持未授予。合成测试只证明交互、请求契约与恢复边界，不证明 Qwen 的真人识别准确率。

## 完整目标仍需完成的部分

Android 导入前接入完成后，可信通话采样、暂停与共享设备排除、实际设备分组、AI 录音分人／时间对齐、部署调度、原始对象版本化清理与可信恢复，以及获授权真人评测和生产容量验收仍属于完整开发范围。模型路线继续 Qwen 优先；目前没有获授权真人评测失败证据，不启动 CAM++ 替代部署。
