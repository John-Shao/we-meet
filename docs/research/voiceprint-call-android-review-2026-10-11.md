# Android 通话采样接入与走查证据

日期：2026-10-11。Android 分支：`feature/speaker-identity-voiceprint`。本阶段接通三类通话共用的本人采样入口，使用 Web 阶段已验证的可信连接 API；后端契约见[Web 通话走查](voiceprint-call-web-review-2026-10-11.md)。模型继续 Qwen 优先，功能默认关闭。

Android 已提交并推送 `0b7dfa87578792ec2df34f5b0024c546d017a73f`；完整实现、修复及复现见[对应版本的 Android 走查记录](https://github.com/John-Shao/we-meet-android/blob/0b7dfa87578792ec2df34f5b0024c546d017a73f/docs/voiceprint-call-review-2026-10-11.md)。

## 行为

公共 `RoomScreen` 接入只读能力开关、当前本人状态、告知／配额、设备草稿与保存并暂停、共享排除、独立允许、本次暂停、当前组织积累关闭和设置入口。PiP 只显示状态。本阶段不增加音频或视频来源，也不请求录音权限；服务端的独立许可／sampler 继续负责实际采样。

私有客户端冻结登录与 RTC SID，首次成功读取固定服务端组织／会话。GET 不分配许可；PATCH 只发送原 revision、本次设备及共享声明。积累关闭仅修改当前可信组织的积累权限。设置入口保留当前组织，即使其不在目录第一页，也不推定管理员权；四个有效组均使用本地化标签。

活动证明采用五秒期限，连接快照十五秒，计入读取耗时；配置每三十秒复核，关闭时不继续读取连接。本地静音覆盖旧正活动文案。监听建立前禁止允许，监听失效、输入设备、路由或麦克风 track 变化要求安全清除及重新声明。后台清空私有状态、关闭弹窗并尝试安全暂停；返回不自动允许。登录／RTC 变化拒绝旧结果；允许响应丢失和 409 不重放写操作。

89 项 JVM 通过：新通话契约 10、新控制器 17、既有声纹契约／设置控制器 34、既有识别契约／控制器 28。隔离 API 29 模拟器 28 个不同用例通过（通话 10、设置 18），43.106 秒；涵盖原生无录音权限的设备监听、设备草稿／保存／允许、共享排除、静音、PiP、期限、积累关闭、登录／后台、中文暗色大字号及当前组织恢复。生产 application ID 的 debug APK、隔离 debug／androidTest APK、设计 token、五语言 47 个新增键／格式参数和差异检查通过。
