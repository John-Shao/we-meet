# Web 说话人身份识别与代码走查

日期：2026-10-10。范围为导入转写后的候选选择、独立识别请求、建议试听及人工确认。模型继续 Qwen 优先，功能开关默认关闭；本轮不包含真人效果、收费 ASR、通话采样或生产发布。

## 接入与权限边界

新增两个只读接口：`meeting-records/{record_id}/speaker-identification-options/` 和 `speaker-identification-candidates/`。前者返回当前来源中尚未归属的已分人标签，以及当前用户有效组织的库选择；后者要求显式指定 personal 或组织 UUID，只返回本人或该组织当前有效真人成员的 ID、公开姓名。每页最多 25 项，偏移最多 10000，姓名检索最多 80 字符。组织记录限制为记录所属组织，不展开外部联系人或其他组织。

两接口校验当前编辑及媒体权限、来源版本、有效账号和可选预期账号标识，响应为 private、no-store；目录不解密模板，不暴露登记状态、许可、邮箱、评分或向量。模板是否有效仍由实际提交和结果复核决定，不能从目录推断谁已经登记。

Web 仅在已完成导入、当前可编辑且可播放媒体，并开启匹配时显示入口。打开面板只读取状态和目录，不录音、不启动 ASR、不登记声纹。候选人员须逐人选择，上限 50；选择其他库立即清空原库人员，分页保留明确选择。原始 ASR 标签用于标识待识别目标。

## 请求和人工决定

- 私有客户端固定打开时的账号和登录会话；发请求前、接收响应后及处理迟到结果时复核。切换账号关闭面板并取消读请求，不把候选姓名放入共享查询缓存。
- 网络结果未知时，只在当前标签页内存保存原请求 key、版本、范围与 ID 列表，最多 20 个未确认命令；没有姓名、音频、凭证或浏览器持久化。关闭再打开仍可显式重试同一命令，换登录即清空。不会自动用新 key 重复提交。
- 处理中的请求及完成后仍待人工决定的建议每 5 秒复核。结果不可验证时隐藏姓名和试听入口；不可恢复失效由后端清理，临时不可用不能被确认。整批结束后才允许人工决定。
- 确认和拒绝只发送 suggestion ID、动作及当前 revision，由既有事务重新校验来源、候选、权限和期限。成功刷新记录和工作区；确认只写最终归属，不更新声纹库。
- 409 后立即隐藏候选，禁用旧决定；面板“刷新”先读取服务器当前 revision，再读取目录，可在父工作区尚未更新时恢复。
- 试听使用与查询共同固定源 VersionId 的既有媒体播放器，只播放已复核的 3～10 秒来源区间。关闭面板、账号变化、决定或错误都会停止试听；普通跳转可退出片段模式。

## 走查发现与修复

| 问题 | 修复和证据 |
|---|---|
| 旧 revision 的目录读取先失败，面板刷新无法自行恢复 409 | 先读取当前批次及 revision，再加载对应目录；交互回归及真实浏览器两次逐人确认、中间版本冲突通过 |
| StrictMode 重建可能复用已取消控制器；旧操作 finally 可能清除新操作状态 | 生命周期 effect 每次创建新控制器，用独立操作 token 清理；StrictMode、迟到响应及账号变化回归通过 |
| 不确定提交关闭面板后可能丢失原请求，改用新 key 重复排队 | 在当前登录的有界内存保留未确认原命令；显式原命令重试、关闭重开及换登录清空回归通过 |
| 完成后的待确认建议若不再复核，撤销后的姓名可能持续展示 | 待确认状态继续只读轮询；候选失效后隐藏姓名、试听与确认的回归通过 |
| 库下拉的标签包含选项文字，控件无障碍名称不准确 | 使用独立标签 ID 及 aria-labelledby，精确控件名称断言和真实浏览器选择通过 |
| 动画帧更新绕过试听结束检查，必须等 timeupdate 才暂停 | 两类时钟更新共用结束检查；新增用例修复前失败，修复后通过；浏览器实际音频停在区间末尾 |
| 旧试听 play Promise 的失败可能停止新试听 | 独立试听 token；旧失败不取消新试听，回归通过 |
| 同一记录另一个面板覆盖未确认命令，随后查询或取消使用新的 key | 拒绝不同命令覆盖，读取返回副本；恢复原 key，原命令确认之前不发送第二次提交；双面板客户端与交互回归通过 |

## 验证方法与限制

后端使用隔离 PostgreSQL 和 Redis 验证真实 API、来源、组织权限与人工决定。前端回归覆盖显式选择、分页 50 人上限、整个批次决定门禁、暂不可用、取消、版本冲突、会话隔离和试听。

| 检查 | 结果 |
|---|---|
| 后端目录、识别 API 与人工决定组合回归 | 115 项通过，无跳过；新增目录／配置门禁 27 项 |
| Web 声纹、播放器、人工标记、账号会话及工作区 | 147 个不同用例通过；9 文件 143 项加账号会话 4 项，面板 13 项收尾复验通过 |
| TypeScript 与生产构建 | `npm run build` 通过；保留既有静态资源未解析和大 chunk 警告 |
| 修改文件静态检查 | ESLint、Ruff、Prettier 通过；旧 urls 文件既有格式诊断不在本轮扩大修改 |
| JSON 与多语言 | 130 个 JSON 可解析；中、英、法、德、荷五种语言的新增命名空间及占位符一致 |
| 浏览器走查 | 一次提交、两次确认、冲突恢复、只读隔离和真实合成音频限段播放通过；无页面异常或外部 HTTP 请求 |

`src/frontend/scripts/review-speaker-identification-web.mjs` 使用实际 RecordWorkspace、实际播放器及 Chromium，以本地合成 WAV 和模拟 HTTP 契约检查一次提交、两次确认、中间 409 恢复、只读用户不读取识别目录，以及片段播放自动停止。脚本禁止真人媒体采集和外部 HTTP／WebSocket。后端并未参与这次浏览器模拟，不能把它当作真实模型匹配验收。

桌面 1280px、手机 390px、手机 24px 字号分别检查浅色和暗色，无横向溢出；12 张可见视口截图和 result.json 位于 `D:/workspace/jusi-meet/work/speaker-identification-web-review-2026-10-10/`，不入库。滚动面板的整元素截图会含被祖先裁切的空白，因此改为分别截取入口和建议的可见视口。

收尾同步走查补齐多面板未确认命令保护，新增两个不同用例；私有客户端 13 项和识别面板 14 项复验通过，TypeScript、修改文件 ESLint／Prettier 通过。这两项加入本阶段的 147 个不同用例后，共覆盖 149 项，不累计重跑次数。
