# 组织声纹聚合运行状态走查

日期：2026-10-11。分支：`feature/speaker-identity-voiceprint`。

方案第 4／18 节要求组织管理员查看聚合运行状态。此前编码器和采样服务已有各自指标，但缺少组织级业务汇总。新增后端只读接口和 Web 声纹设置管理入口，功能仍默认关闭。

## 接口及权限

`GET /api/v1.0/voiceprint/organizations/{organization_id}/operations/?hours=24`。`hours` 支持 1～168，默认 24；未知参数拒绝。Web 固定显示最近 24 小时，不自动请求或轮询，通过“查看／刷新运行状态”加载。接口按账号限制每分钟 6 次。

仅当前有效真人账号、有效组织的 active ADMIN／OWNER 可以读取。组织成员、其他组织管理员、已离开成员、设备账号及匿名请求拒绝；聚合前后分别复核账号／组织／角色，请求期间降权则丢弃结果。接口沿用 `X-Voiceprint-Owner` 会话约束、`private, no-store` 和固定错误码。

关闭总功能或组织采集不会隐藏积压，管理员仍能观察待清理数据；接口不改变开关、授权、任务或模板，不调用 ASR、编码器或对象存储。个人范围及其他组织的数据不计入当前组织。

## 指标定义

| 字段                            | 含义与边界                                                                                                                                          |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `queues`                        | 编码、语音质检、身份识别及删除队列的保留状态计数、最早 queued／running 任务年龄；有租约的队列统计过期或缺失的 running 租约                          |
| `completed_in_window`           | 窗口内有合法 `finished_at` 的 succeeded／failed／canceled／expired 任务量；不是只统计成功任务                                                       |
| `request_to_finish_p95_seconds` | 上述完成任务的 `finished_at - created_at`，数据库计算连续分位数；包含排队及重试，没有完成数据则 null。**不是**方案第 15 节的 ASR 完成至建议可见延迟 |
| `profiles/templates/samples`    | 当前保留行的状态计数；不解密或重新验证模板的匹配资格                                                                                                |
| `expired_candidates`            | pending／processing／ready 且已到期的候选数量                                                                                                       |
| `samples_in_window`             | 窗口内创建且仍保留的样本数、来源片段时长、通过声明质量标记的有效语音时长、本人接受／拒绝计数；物理清理后计数会减少，不是累计采集量或计费统计        |
| `contribution_cleanup`          | 组织贡献清理 queued／purged／complete 计数；使用独立作用域字段，档案删除后仍可观察积压                                                              |
| `suggestions_in_window`         | 窗口内创建且仍保留的建议结果、固定白名单拒绝原因及状态。人工拒绝量单独按 `decided_at` 统计，包含本窗口拒绝的历史建议                                |

业务状态及拒绝原因仅输出固定字段；未知值合并为 `other`，不返回任意错误文本。SQL 只取得聚合结果，测试确认不会选择音频密文、向量密文或档案密钥列；不加载样本正文／转写、人员姓名、ID 或相似度。损坏的历史质量 JSON 经过类型／格式／范围保护才做数值转换；该汇总不替代声音质量验证。

这些是当前保留数据的 gauge／窗口观察值，多次只读查询不是事务恢复证明。不得作为单调累计 counter 使用，也不能据此推断识别精确率、污染率或声纹真实性。生产数据规模下的查询成本、监控采集、告警和完整端到端延迟仍需目标环境验证。

## Web 与验证

仅组织管理员显示管理入口。客户端绑定当前登录与组织，响应只保留校验过的数字／时间字段；刷新开始清除旧统计，失败／取消不回显服务器详情，卸载或换作用域丢弃迟到响应。五种语言同步文案；近 24 小时拒绝结果、积压、暂停档案、语音量及 P95 分别展示，缺数据不显示假零。

- 后端 24 项组合测试通过：16 项新操作接口／PostgreSQL 汇总测试及 8 项现有作用域回归，涵盖权限、降权竞态、跨组织／个人隔离、P95、损坏 JSON、删除后的清理意图和历史建议本期拒绝。
- Web 31 项测试通过，包括管理入口可见性、私有请求、账号切换、卸载迟到响应、错误刷新清理和空 P95。`tsc -b`、改动文件 ESLint、JSON／语言结构校验通过。
- 真实无头 Chromium 在 1280／390 宽度完成两组本地合成 HTTP 走查：聚合可读、无横向溢出、403 刷新清除旧统计。4 次合法读取，0 非预期读取、0 页面错误、0 外部请求；截图已目视检查。
- Django system check、迁移漂移检查及改动 Python Ruff 检查通过。未增加模型或迁移。

浏览器走查可从 `src/frontend` 执行 `node scripts/review-voiceprint-operations.mjs`。可用 `VOICEPRINT_OPERATIONS_REVIEW_PORT` 和 `VOICEPRINT_OPERATIONS_REVIEW_ARTIFACT_DIR` 设置本地端口及输出目录；默认输出到忽略的 `test-results/voiceprint-operations`。fixture 服务仅监听回环地址，结束关闭浏览器和服务器。

所有数据均为合成夹具，没有生产请求或真人音频；此阶段不证明真人效果或完整生产验收。Android 的本人授权／采样／识别界面保持原行为，组织运维管理本轮在 Web 提供。
