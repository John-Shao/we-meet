# 第三十四批：Android 日期校验提示保持可见

第 33 批生产验收发现：日期倒置时虽然正确阻止提交，新增错误文字却会让筛选面板切换到半展开位置，错误提示落到屏幕下方。

## 修改

- 筛选面板跳过半展开状态，内容高度变化时保持展开；仍可滚动和关闭。
- 点击“完成”时清除输入焦点并收起键盘，避免错误提示出现后底部按钮被键盘遮挡。
- 沿用现有日期校验、时区转换、查询和清除逻辑，不更改后端契约。

## 验证与边界

- Pixel 8 / Android 16 三项仪器回归：日期与来源组合、分页重置、倒置日期不提交、错误提示/完成按钮可见、清除日期、旧后端不得显示未筛选数据；另含原有搜索/筛选回归。
- 设计规范检查通过。新增截图步骤最初因两个窗口根节点而失败，改用整个屏幕截图；截图检查又发现键盘遮挡，补上焦点/键盘处理后重新验证。
- 本地仪器数据用于布局和行为回归，不替代物理设备、多种字体尺寸与生产多页样本验收。
- 第 33 批临时分享撤销后，额外观察到 App 重试清除了原记录内容，显示记录不可用。

仅 Android 运行代码变化，不需重新部署 backend/frontend 或执行迁移；修复需随新版 App 分发。
