# 声纹授权与生命周期契约

日期：2026-10-10（Asia/Shanghai）。这是后端授权／加密／撤销基础，仍未开放音频登记或身份匹配。整体进度见[开发记录](../plan/speaker-identity-implementation-2026-10-10.md)。

## 作用域和独立权限

`organization_id=null` 为本人的个人范围，组织范围必须显式指定 UUID。每个用户／作用域只有一条当前授权；每个授权／模型只有一条当前档案。三项权限均默认 `false`：`allow_enrollment`、`allow_accumulation`、`allow_identification`。关闭某项不会默默关闭其余项，也不把已有会议录音或手工姓名视为声纹授权。

组织开关保存在 `Organization.settings.voiceprint`，默认关闭。配置版本必须是非负整数；缺失、布尔、浮点、字符串或负数版本均按关闭／版本 0 处理，目标组织管理员可以修复。仅目标组织的有效 administrator／owner 可以变更；部门管理员、其他组织的管理员和仅有全局 staff 标志的账号均不获得这个权限。本人设置只能写登录者，所有 `user_id`／向量／密文等额外输入均拒绝。

全局 `MEETING_VOICEPRINT_ENABLED=false` 默认阻止新的有效授权及档案使用，既有本人设置读取、撤销和删除仍可执行。组织暂停与个人关闭识别立即影响授权检查。组织失效或退出组织后，已有本人设置允许读取和撤销，不能再次授予该组织权限。

## 已实现 API

所有响应包含 `Cache-Control: private, no-store`。错误只返回固定 code；权限与参数仍由服务端重新验证。

| 路径（`/api/v1.0` 下） | 行为 |
|---|---|
| `GET /voiceprint/settings/` | 个人范围默认值，不写数据库；可带 `organization_id` 查询本人组织范围 |
| `PATCH /voiceprint/settings/` | 显式 `organization_id`、整数 `expected_version` 和至少一项布尔权限；不接受字符串／数字代替布尔值 |
| `DELETE /voiceprint/profiles/{id}/` | 仅本人；整数 `expected_version` 与 UUID `request_key`，返回 202 和清理任务 |
| `GET /voiceprint/deletions/{id}/` | 仅本人，读取清理状态和固定错误类别 |
| `GET/PATCH /voiceprint/organizations/{id}/settings/` | 目标组织管理员；PATCH 仅 `enabled` 和 `expected_version` |

设置读取的 `version=0` 表示没有保存过授权。无变化不会推进版本；旧版本写入返回 409。第一次创建在本人行锁下进行，并有数据库唯一约束。档案响应只有 ID、状态、generation 与确认／更新时间，不包含原音频、向量、评分、包装密钥或密文。

删除清空该作用域的三项权限，推进版本和 generation，令旧档案立即不可用。相同 `request_key`、profile、expected_version 的重试返回同一任务；改变参数返回 409。旧请求重试即使发生在重新登记之后，也不再删除新登记的数据。

内部 `ensure_profile` 只用于后续已授权登记流程，尚未提供公共登记端点。`authorize_profile` 每次重新读取账号、组织、成员、权限、版本、generation 和墓碑；识别还要求有效的本人确认及来源质量。仅有加密向量、待确认样本或标记为 active 的未经确认／质量检查数据，均不足以匹配。365 天未更新的档案停止用于识别。

当前模板就绪门禁只接受固定 Qwen 特征空间和 1024 维模板，每个档案最多 5 个当前 active 设备组。每组全部贡献必须属于同一档案和当前 generation，具有本人确认、非空加密特征，以及严格布尔值的语音／单人检查。`quality.valid_speech_ms` 必须是整数、在 3～10 秒内且不超过片段区间；每组至少 3 个不同音频摘要、合计至少 30 秒有效语音。重复摘要不增加时长；混入外部档案、旧世代或未确认贡献会拒绝。确认后的试听音频到期不影响仍有效的特征支持。

这些是方案中的保守技术门禁，尚未在人声数据上校准。当前 Qwen RPC 的信号检查仍返回两个质量检查为 false，没有有效语音时长，不能直接创建可识别模板；后续质量 worker 必须完成真实检查，不能由客户端提交这些字段。

## 私有加密数据

`MEETING_VOICEPRINT_KEYRING_FILE` 指向仓库外、由运维权限控制的 keyring JSON；缺失、过大或格式不合法时拒绝建立／读取档案密钥。密钥不放在普通环境变量、Django secret、日志或 API 中。

文件结构为 `active` 指定当前 key ID，`keys` 保存最多 8 个 ID 到标准 Base64 的映射。ID 为 1–32 个 ASCII 字母／数字／下划线／短横线；每个 Base64 值必须解码为独立随机 32 字节密钥。轮换后保留旧 ID 可读取旧包装；删除旧 ID 后相应旧包装无法读取。目前没有自动重包装／旧密钥退役命令，部署前须补充托管密钥方案和轮换规程。

档案数据密钥也是独立随机 32 字节，使用 AES-GCM 包装；音频、样本特征和模板分别加密。每次使用独立随机 nonce，并把本人 ID、组织／个人范围、profile UUID、generation、特征空间、用途和对象 UUID 绑定到附加认证数据。跨组织／对象交换、旧世代、篡改或截断均失败。Ciphertext 存 PostgreSQL BinaryField；新模型不注册 Django admin，也没有导出密文或向量的 API。

删除包装密钥可以立即禁止正常在线解密，但不代表旧备份里的包装和数据已被物理擦除。已运行 worker 的内存和旧租约仍需在结果提交前复核；这些 worker 尚未接入。

## 撤销、清理与恢复边界

`VoiceprintDeletionJob` 以 UUID 保存本人／组织／被撤销 generation，外键可为空；硬删除本人、组织或授权时也保留独立墓碑。Django 级联删除期间不新增依赖即将删除的授权的审计子记录，避免删除收集器之外的外键残留。

账号停用／设备账号化、最后一条有效组织关系丢失会撤销权限、清除包装密钥并创建清理任务。批量 SQL／QuerySet 更新绕过信号时，档案使用仍立即因当前账号／成员状态被拒绝，巡检命令补做持久撤销。

在启用此功能前，部署须调度以下有界命令；当前仅在隔离测试数据库执行过，不表示生产已接通：

```text
python manage.py reconcile_voiceprints --limit 100
python manage.py expire_voiceprint_samples --limit 100
python manage.py purge_voiceprints --limit 100
```

- 巡检只撤销失效作用域，不授予权限；保持仍有另一条有效组织关系的账号。扫描后已被并发删除的账号或授权会跳过，继续处理余下批次。
- 待确认／异常样本到期后清除音频和特征；确认样本到期清除短期试听音频，仍有效的特征保留。旧世代特征也会被清除。
- 删除任务按本人行、授权、任务锁定；清理仅覆盖较早世代，重新登记的样本和密钥不会被旧任务清除。重复完成不重复计数。
- 失败仅记录 `cleanup_unavailable`，最多尝试 3 次；持续失败应由部署监控提示，不能宣称已完成物理删除。

当前没有外部对象或特征缓存，回执明确 `external_objects=0`、`cache=not_used`；后续引入这些存储时必须扩展回执与清理实现。来源记录删除后的贡献重建、采样／匹配任务取消、独立 worker 硬期限、真实存储／备份清理仍待完成。

运行时的当前墓碑会阻止低 generation 的旧数据恢复可用。可信外部墓碑导入、签名／恢复规程和实际备份恢复测试尚未完成；不能只恢复旧备份中的墓碑后开放识别，也不能据本轮测试声称生产恢复已安全验收。

## 验证证据

新增 75 项授权、加密和清理测试、45 项 Qwen 客户端回归，以及接入信号后的既有账号／离职／人工归属／热词回归 74 项，共 194 项通过。本次走查先复现 17 项失败：10 项模板门禁、5 项损坏组织版本、2 项并发删除巡检；修复后通过。额外覆盖设备组上限及混入无效组，确认音频到期仍可使用有效特征。测试使用临时随机测试密钥和合成载荷，没有真人声音或声纹准确率测量。

隔离 PostgreSQL 的空测试库重建并完整执行迁移后，默认设置用例通过。迁移漂移和新增文件 Ruff／格式检查通过；固定 `cryptography==46.0.7` 已提升为直接依赖，沿用原 lock 中版本及包哈希，没有升级其他依赖。测试告警来自既有 Django 过渡设置和测试静态文件目录缺失。
