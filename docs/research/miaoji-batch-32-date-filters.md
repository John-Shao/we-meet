# 第三十二批：创建日期与现有范围组合筛选

## 用户行为与契约

- 实录库和纪要库新增创建日期起止条件，可与“我的 / 参与的 / 分享给我”、来源、标题搜索组合；Web 同时沿用创建时间升降序。
- 使用设备本地日历日期。开始日包含当天，结束日转换成次日本地零点的排他上界；不是简单增加固定 24 小时。两端允许只填一端、清空日期，并拒绝非法日期和倒置范围。
- 日期仅在确认后生效；改变已应用日期会清空游标并返回第一页，进行中与历史两段列表使用相同日期条件，页面显示已应用范围。
- 服务端 `created_from`（包含）/`created_before`（不包含）接收显式带时区时间戳，在授权范围内、分页前查询 `created_at`，不使用会议开始时间代替创建时间。重复参数、无时区时间和反向/等值区间返回 400。
- 列表响应增加 `supported_filters`。只要发出日期条件而服务端没有声明支持，客户端就显示读取失败，不展示可能忽略筛选条件的旧后端结果；未使用日期时仍兼容旧后端。

## 回归中修正

- 第 31 批整理脚本二次运行在 Android 中英文资源中留下同名字符串，发生在该批首次构建之后。本批构建发现并去重；新增检查扫描两套默认/中文资源的 3294 个字符串名，最终源码重新编译验证。第 31 批最初安装的 APK 使用的是重复写入前的资源，不能将当时通过的测试当成重复资源提交的构建证据。
- 原文导出系统选择器往返测试触发 Toast 在无 Looper 线程创建。现在显式在 `Dispatchers.Main.immediate` 显示完成/失败提示，保留文件 IO、重新鉴权、取消和失败清理语义；复跑原有生命周期回归。

## 验证与发布

- 后端 PostgreSQL 48 项回归通过：包括 34 条匹配记录跨页双向排序、组合筛选、包含/排他边界、时区偏移、共享撤权、非法参数及既有记录链路。
- Web 16 项组件/日期测试、TypeScript、ESLint 通过：日期提交、分页重置、两分区一致、清除范围、旧服务端不可误显结果；5 种语言同步。
- Android 28 项单元测试、36 项 Pixel 8 / Android 16 仪器测试全部通过，含夏令时 23 小时日期、真实 Retrofit 参数、旧后端拒绝、日期组合/分页重置、导出生命周期和第 31 批空态；设计 token 检查通过。最终源码构建的 debug APK 已安装。Android `d5796c85` 已推送。中英文资源同步，日期输入明确要求 YYYY-MM-DD；复杂日历选择器、预设时间窗口暂不增加。
- 无数据库迁移，需要 backend/frontend 配套发布和新版 Android；summary/agents 无本批运行变更。当前生产仍为用户部署的 `ad06f3e8a`，新日期筛选尚未做生产验收。

## 剩余范围

G4 的“日期 × 归属范围 × 来源 × 标题”已实现，指定任意所有者、标签/文件夹、保存筛选、Android 可选排序仍未覆盖，不据此宣称所有列表管理能力对齐妙记。G6 可靠媒体时长和人工纪要历史精确导航、G7 回收站等仍是后续开发项。大文件恢复与长原文跨页验收继续按用户要求延后。
