# Qwen 多片段匹配核心、候选范围与走查

日期：2026-10-10（Asia/Shanghai）

本阶段新增内部匹配核心和授权候选池，用于后续导入／AI 录音身份任务。没有新增公开向量接口，没有修改 MeetingSpeaker 归属，没有把识别结果写回登记库。模型继续限定固定 Qwen 特征空间；暂无获授权真人数据，不生成已通过评测的生产门限，也不切换 CAM++。

## 匹配行为

`voiceprint_matching.match` 接受内部生产者提交的一组查询片段，以及已授权、已解密的候选模板。本模块仅在内存中处理查询和模板，不写数据库或缓存，默认 repr 隐藏向量、用户 ID 和评分。没有新增接收客户端向量／质量布尔值的公开接口；真实媒体片段的来源认证、质量生产和任务协议继续接入。

查询最多 12 段，每段区间 3–10 秒，时间坐标不超过首期两小时边界；要求固定 Qwen 空间、有限 1024 维向量、有效语音和单人质量证据。同一 speaker 的查询片段必须具备不同音频摘要和不重叠时间区间，不能把同一段复制成多份证据。至少 3 段及相应有效语音下限由冻结策略确定；不使用登记模板的 0.85 一致性工程值作为身份接受门限。

精确评分策略为 `qwen-cosine-template-mean-v1`：

1. 对每段查询、每名候选，计算该人所有有效设备组模板的余弦均值；设备组有界且等权，不取所有模板中的最高值。
2. 每段分别排序。第一名必须达到绝对门限；有第二名时还必须达到差值门限。只有一名候选时差值为 null，仍检查绝对门限。
3. 全部片段必须指向同一个合格第一名。不能用高分片段或多数票掩盖低分／小差值片段。
4. 查询片段两两向量一致性、单段多人证据和各片段明确身份冲突均有独立拒绝路径。

通过时返回该人的逐段第一名分数均值及逐段差值均值；它们是内部相似度诊断，不是概率。多组分人标签可分别匹配同一账号，不做强制一对一分配。

| 状态 | 触发情况 |
|---|---|
| suggested | 每段质量、时长、身份分数和差值均通过，所有片段身份一致 |
| unknown | 至少一段第一名未达到绝对门限，不由平均高分覆盖 |
| ambiguous | 分数足够，但至少一段无法区分第一／第二名 |
| insufficient_audio | 段数、有效语音不足，或重复／重叠片段缺乏独立证据 |
| mixed_speaker | 单段多人、片段两两不一致，或不同片段明确指向不同候选 |
| unavailable | 没有已授权模板、质量证据尚未完成或门限未校准 |

输入结构损坏或超过资源边界返回固定错误，不降级为通过；不合格状态均不返回推测用户和评分。

## 候选池和权限

`voiceprint_candidates.load_pool` 要求明确选择 1–50 个唯一 UUID，重读当前记录和请求者，验证当前编辑权限、记录 revision 及所选组织。组织记录只使用自己的组织库；个人记录默认仅识别当前编辑者本人，识别同事必须明确选择一个当前共同组织。外部联系人关系和较宽的人工标记通讯录权限不赋予声纹访问权。

候选必须为当前有效真人账号和组织成员。仅从所选作用域、固定 Qwen 空间加载档案；识别授权、generation、撤销墓碑、模板时效及原始本人确认贡献均重新核验。新增 `authorize_profile(expected_scope=...)`，在解密证明前绑定预期本人／组织，防止刷新后的档案跨越最初选择范围。

没有登记或没有识别许可的明确候选不会被静默扩展为其他组织成员；它仍留在请求快照中。若原本 active 且允许识别的候选无法读取／认证模板，整个池返回不可用，不能把故障候选删掉后人为制造“只剩一人”的接受机会。

候选摘要绑定记录／生命周期 revision、请求者、组织政策、明确候选集合、授权版本／generation、档案确认与更新时间，以及模板 ID／revision／策略／贡献摘要／密文摘要。尚无模板候选的授权版本也参与摘要；该人随后登记完成或修改授权，将使旧快照失效。公平扫描时间或尚未纳入稳定基线的新确认片段不会无故改变摘要。

`match_record` 在评分后重新加载候选和当前策略；撤销、模板损坏、候选变得可用、记录 revision 或门限变化时返回 context changed，不释放旧建议。此步骤是内部返回前复核，不替代未来任务结果发布和人工确认的事务锁／源 generation／租约复核。

## 门限和开关

`MEETING_VOICEPRINT_MATCHING_ENABLED` 默认 false，`MEETING_VOICEPRINT_THRESHOLD_CONFIG_FILE` 默认空。全局或匹配开关关闭时，不读取门限配置、不解密模板。尚未校准或配置不可用时阻止匹配，不回退至登记一致性门限。

挂载 JSON 必须完整提供以下字段，不接受额外或重复字段，文件最多 8 KiB：

- `threshold_version`、固定 `feature_space`、固定 `score_policy`。
- `accept`、`margin`、`min_pair_cosine`，全部为有限的显式门限，拒绝 bool／零／越界值。
- `min_query_clips`、`min_query_speech_ms`，至少 3 段和每段至少 3 秒的总量下限。
- `max_candidates`、`max_device_groups`，不得超过 50 人／每人 5 组，实际请求不得超出已校准容量范围。
- `calibration_sha256` 与严格布尔 `calibrated`，引用评审过的独立校准报告。

策略内容本身生成摘要；仅复用同一个 threshold_version 但修改门限或报告引用也会失效。配置中的声明和摘要不能证明真人报告内容已达标，发布仍需原方案第 15 节的真实评测与独立验收。本仓库不提供任何声称已通过真人评测的生产配置；测试策略只存在隔离测试夹具。

## 走查修复和验证

| 边界问题 | 处理 |
|---|---|
| 高平均分／多数片段可能掩盖一个低分或异身份片段 | 逐段门限与差值，全段身份一致，先检查全部查询对 |
| 多设备模板多的人取最大值获得额外优势 | 固定有界等权均值，并将评分方法和模板组范围纳入待校准策略 |
| 只有一名候选就无条件确认，或相似度被当作概率 | 单人仍要求绝对门限；差值 null，不生成百分比置信度 |
| 失效模板读取故障把竞争者从候选中移除 | active 识别候选读取失败使整个池不可用，不制造缺失第二名的差值 |
| 尚未登记候选的新登记／授权变化不影响旧摘要 | 请求快照包含未就绪成员和对应授权 epoch，评分后重新验证 |
| 刷新的档案改变本人／组织 | 在解密前核验 expected_scope，错范围直接拒绝 |
| 复用旧对象／旧策略仍放行 | 重读记录、当前权限、密文证明、撤销墓碑和完整策略摘要 |

新增回归覆盖合成多说话人几何、未知访客、单候选、相近声纹、不同明确身份、低分少数片段、模板数量偏差、边界数值、组织／个人范围及隔离数据库证明。评分中注入撤销、登记、记录修订和策略更新，验证旧结果不被释放；未使用真人声音。

全部声纹相关 501 项回归通过，无跳过，含 115 项本阶段新增用例及 1 项实际固定 Qwen encoder 完整登记链路。随后补上重复门限字段拒绝回归，匹配／候选 116 项专项复验通过；上述共 502 个不同后端用例，该补充不构成真人校准。Ruff／格式和迁移漂移检查通过，本阶段没有数据库迁移、Web／Android DTO 或模型服务改动。

当前状态仍是匹配与授权核心：查询生产者必须继续接通真实录音的分人预检、可信区间／音轨、媒体到期、隔离有界解码、Qwen 查询质检／特征提取，以及独立身份任务、持久建议版本和人工确认。候选池自身不授权读取音频。Web／Android 的身份建议界面及生产部署也尚未完成；完整范围不因本阶段提交而缩减，见[开发记录](../plan/speaker-identity-implementation-2026-10-10.md)。
