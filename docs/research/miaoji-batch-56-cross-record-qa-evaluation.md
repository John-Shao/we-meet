# 第 56 批：跨记录问答质量评测基线

## 本批结果

先评测，不改生产召回策略。新增 **31 道合成题**及测试数据库执行器，调用现有关键词抽取、完整 meetings scope 上下文准备和 ORM 召回；没有访问生产会议数据、发起真实模型请求或部署新镜像。基线运行代码为 we-meet `96aa580a8`（问答实现没有在本批改变），Django 5.2.14 / jieba 0.42.1；题库与关键实现文件 SHA-256 存入报告。

- **25 道有证据题：16/25 找到全部所需记录，15/25 获得完整证据；宏平均证据召回 60%。** v1 中正例恰好都是全中或全失，不将此特性推广到真实题。
- **5 道应为空题：5/5**。另有 1 道“有预算讨论但金额未定”，允许相关材料召回，回答是否正确拒绝猜测尚未测量。
- 所列权限/撤权/回收和旧校对/旧人工纪要替代边界无泄露；不等同于全场景安全审计。
- 新评测与评分/比较器测试 **46 项通过**；既有统一检索及搜索问答 API **35 项通过**（此前与当时版本评测合跑 72 项，最终题库及工具又独立跑 46 项）；Ruff 通过。不能把 pytest 成功率称为问答正确率。

[机器可读基线](evaluations/miaoji-qa-baseline-v1.json)保留逐题关键词、候选记录、实际上下文、引用卡片片段、gold 证据、缺失证据、原始生成提示和分组指标。回答与人工评分保持 null。

## 确认的真实缺口

| 类别 | 对照结果 | 对应实现原因与下一步 |
|---|---|---|
| 近期同一记录挤占 | old_decision_crowded、conflict_crowded 均只召回最新记录的4段，早期决定/两侧变更全缺；加日期范围的对照题可命中旧决定。 | 原文分支按时间排序后全局取4段；应先评估候选池、每记录配额和覆盖率，不能直接据此断言必须上向量库。 |
| 标题命中带入无关段 | title_crowding 的新记录只有标题含预算，4条会议室安排挤掉旧预算结论。 | 标题 OR 正文等价命中，缺少正文相关性区分。 |
| 纪要分支近期偏置 | summary_crowded 的旧批准被3份近期无结论纪要排除。 | 每纪要分支只按时间取3条；需与原文一起评估记录多样性。 |
| 关键句不在模型上下文 | tail_truncation 命中正确记录，但800字前缀没有末尾的终验日期，证据召回0。 | 原文用前缀截断，尚无围绕命中位置的窗口；属于合成短记录的片段截断评测，不恢复用户延后的真实长录音跨页验收。 |
| 英文问句抽词 | 相同语料下 rollback 关键词可命中；完整英文问句抽到 What/is/the，被近期办公室闲聊占满。 | 英数 token 优先且只保留3词，常见词占位。不能把这个失败一概算作跨语言能力问题。 |
| 同义/跨语言漏召回 | 开销/经费 对 费用预算、推迟 对 延期、rollback 对 回滚均无证据。 | 字面 icontains 无语义桥接；需要独立评估术语归一/查询扩展与排序后的收益及噪声。 |

总计 **10 道有证据题未完整覆盖**。普通字面题、已召回两侧的冲突题、跨记录角色组合、当前校对/人工纪要替代和全文/仅纪要权限对照均有通过样本；不将局部缺口概括成“跨记录问答不可用”。

## 评测契约与边界

旧 `ask_eval` 关注来源状态、引用编号和耗时；没有 record/事实 gold，不能证明回答所需证据完整。本批采用独立题库，不改变其生产行为。负例与 N/A 使用单独分母；候选卡片命中不代替模型上下文证据；两侧证据必须齐全才算冲突题覆盖。

[执行方式、指标及人工评分规则](../../src/backend/core/tests/evaluations/README.md)的实际仓库路径是 `src/backend/core/tests/evaluations/README.md`。比较器要求相同题库 hash/题目与 gold，逐题证据召回、记录召回、精度不能退化；安全与应为空边界不能由总分抵消。

本轮不声明真实 LLM 的语义正确性、矛盾处理、引用忠实度和指令隔离已通过。报告保存固定 prompt 和人工评分要求，下一阶段需要实际生成与复核；同样未测生产大库延迟/成本。31题均为公开合成诊断集，validation 分组不是盲测集；需逐步加入脱敏真实问题及独立留出集。

## 建议下一批

先做可由此基线验证的召回改进：**正文相关性与每记录配额 → 命中窗口 → 英文常见词过滤**；跑同一题库逐题比较，再决定同义/跨语言扩展。优先让四个挤占样本、一个截断样本和英文问句样本恢复证据，保持权限、修订和无答案边界。暂不将部署向量数据库设为前置条件。

本批仅测试资产与文档，需要提交/推送，不需要 backend/frontend/agents 发布，也没有 Android 改动。第 55 批专用记录的永久删除最终复核仍是独立待办；本批不改写其结果。
