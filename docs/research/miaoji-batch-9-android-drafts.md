# 第九批：Android 原文列表校对草稿

Android 原文行使用局部 remember 状态和行级协程，记录 revision 更新重新读取分页时，行会暂时退出组合，造成草稿丢失或保存协程被取消。

将草稿、开始编辑时的版本、等待和冲突状态提升到原文阅读页；保存使用阅读页的协程作用域。列表重建后仍显示同一草稿及保存中状态，不允许重复提交，也不自动改用最新 correction revision 覆盖他人的修改。取消和保存成功清空文本；撤权/非法读取及离开原文页清除内存状态，晚到响应不再写入已清除的编辑状态。失去校对权限后不能保存。

验证：Pixel 8 / Android 16 模拟器新增 2 项通过，分别覆盖 record revision 变化后的草稿与原始冲突版本、正在保存时重建页面内容且只发送一次写请求。构建同时编译 Android 测试源集。

本批没有持久化草稿，也没有承诺切换到另一记录、离开原文页、后台隐藏私有内容或进程被杀后恢复。草稿生命周期比 Web 页签作用域更短，后续如要统一离页恢复，应单独设计用户可见的草稿管理。
