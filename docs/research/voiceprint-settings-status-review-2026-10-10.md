# 本人声纹有效性状态与跨端设置走查

后续私有状态／试听期限走查修复见[补充记录](voiceprint-private-state-review-2026-10-10.md)，包含迟到音频拒绝、撤权清理和旧删除字段的保守展示。

日期：2026-10-10。分支：`feature/speaker-identity-voiceprint`。本阶段补齐方案 12.1 的八种设置状态、公开更新原因及有效设备组展示，避免把数据库 `active` 当成可识别证明。模型仍为固定 Qwen；不启用 CAM++，不开放未获授权的真人评测。

## 只读投影契约

本人 `GET/PATCH /voiceprint/settings/` 增加作用域 `display_state`。每个档案追加 `display_state`、`update_reasons` 和 `effective_device_groups`，原始 `status`／generation／时间字段保留，旧客户端仍可解析。

| 展示状态 | 依据 |
|---|---|
| 未开启 `not_enabled` | 没有当前有效的登记会话或候选；仅开启权限不代表已开始采样 |
| 采样中 `collecting` | 当前授权版本／世代及组织政策下有开放登记或尚未完成质量／建库的片段；不是实际麦克风正在录制的证明 |
| 待本人确认 `awaiting_confirmation` | 当前本人样本通过与样本 API 相同的可确认元数据门禁，且未过期；仍须完整试听、本人明确决定和服务端最终复核 |
| 已建立 `established` | 当前模型、档案密钥、本人确认、365 天更新期限、有效贡献及加密模板证明均通过，存在有效组 |
| 需要更新 `needs_update` | 曾建立的档案已超过期限、模型变更、贡献／模板失效或私有密钥不可读取 |
| 已暂停 `paused` | 当前作用域不可用或三项本人权限均关闭；不更改存储中的基线 |
| 删除中 `deleting` | 世代已撤销但尚无成功清理回执；失败清理仍不可使用 |
| 已删除 `deleted` | 对应世代已撤销并有成功清理回执 |

当前有效设备组复用识别授权的 `ready_device_groups` 验证，不使用数据库中的模板数量或 `active` 标记替代加密证明。最多五组，任一混入无效贡献或模板都会拒绝。现有构建器只证明 `default` 登记基线，界面显示“登记基线”；这不是已完成真实硬件识别或多设备分类。真实通话来源与设备分组随采样阶段继续开发。

公开更新原因只包含 `expired`、`model_changed`、`contributions_changed`、`storage_unavailable`。不返回原音频、向量、评分、模板／样本引用、设备私有标识或内部错误正文。旧服务不提供新增字段时，两端提示服务未提供有效性状态，旧 `active` 不显示为已验证的“已建立”。

读取不创建授权、不修改档案、不调用模型／云端接口、不启用任一权限。登记候选最多检查 25 份有界元数据，查询使用音频／特征存在性的 SQL 布尔注解，不装载候选密文。验证有效基线仍会在服务器内读取与解密有界模板／贡献，原始候选音频不参与状态读取。

## 一致性与走查修复

- 从数据库状态升级为当前授权／世代／墓碑、组织政策、时间与模板证明共同决定的状态。原有身份授权门禁复用同一有效组结果，未降低匹配门槛。
- 对应清理尚未成功、清理失败或仅有外部撤销世代时，不宣称物理清理完成；原 generation 的使用仍立即被拒绝。旧清理不能覆盖重新登记后的当前状态。
- 档案列表只读取一次并传入投影，避免第二次枚举中档案被并发删除而发生缺失映射；GET 仍不是供后续写操作使用的授权凭证，提交继续复核版本与世代。
- 未绑定登记许可、旧版本／组织政策、错误作用域或过期候选不显示为可确认／有效采样。关闭组织隐藏有效组但不修改模板。
- 缺失轮换密钥返回固定公开原因，原始错误和路径不进入响应。已建立状态须具备时间及有效组；客户端拒绝未知状态、未知原因、重复组、私有设备标签及状态／组列表矛盾。
- 浏览器实际走查发现长更新原因将删除按钮压成竖排。档案行允许换行，按钮保持完整；390 像素、暗色、24 像素根字号复验无水平溢出，按钮正常横排。

首次组合回归发现一项测试夹具使用未绑定登记的 pending 样本，却期望“采样中”。修正为模拟可信登记生产者，并新增未绑定样本的拒绝投影用例，不通过放宽生产门禁使夹具通过。默认无授权设置的精确响应断言同步包含新增的 `display_state`。
