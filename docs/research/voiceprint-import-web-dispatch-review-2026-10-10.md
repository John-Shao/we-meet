# Web 导入身份选择与独立请求调度走查

日期：2026-10-10（Asia/Shanghai）

范围：声纹 feature 分支中的 Web 导入入口、收费 ASR 前的身份预检恢复、候选目录，以及转写发布后的独立身份请求。模型路线仍为 Qwen 优先，本轮没有改用 CAM++。

## 完成的行为

Web 在上传前支持显式开启身份识别、选择本人或有权访问的组织声纹库、搜索及分页选择候选成员。开启身份识别同时开启说话人区分；切换声纹库清空原候选，关闭说话人区分清空身份意图。候选数量遵守服务端当前政策，目录不返回成员是否登记声纹的信息。

普通上传、直传和分片上传使用相同的身份声明。身份操作固定预期账号，所有上传请求固定原登录会话并拒绝迟到响应；直传结果未确认时保留原文件、声明及已经上传的票据，重试完成确认不会再次 PUT 文件。账号切换或组件卸载取消上传并清理旧票据及本地会话引用。

预检停止时，界面提供“重新进行身份预检”和“继续普通转写”两个明确决定，提交原尝试版本，随后重新读取任务状态。界面不会自动选择继续、重传文件或触发收费 ASR 重试。普通继续完成后不再显示身份预检正在执行的提示。

ASR 发布原文、更新记录 revision 与保存 `RecordingIdentityDispatch` 在同一事务内完成。独立调度记录保存服务端请求幂等键、发布版本、配置摘要、期限和租约；现有上传任务 tick 同时扫描身份调度，不依赖 HTTP 请求或 ASR 重复执行来恢复。

身份 worker 在当前授权范围锁定后复核账号、候选、政策、来源及记录版本，创建现有记录级身份请求；请求创建与调度完成在同一事务内提交。租约过期可恢复，旧租约不能重复创建或覆盖结果，独立临时故障最多三次尝试。授权或上下文不可用只使身份调度不可用，保留已完成的转写。普通导入及明确继续普通转写不排身份任务。结果仍是需要人工确认的建议，不自动实名归属或登记声纹。

新增 `0210_recording_identity_dispatch` 迁移，以及上传前的私有候选目录 `recording-uploads/identity-candidates/`。目录要求预期账号、明确声纹库范围及当前组织成员权限，仅返回姓名与用户 ID，具有分页、搜索及限流。

## 走查发现与修复

| 问题 | 修复 |
|---|---|
| 新导入可以沿用目录刷新失败前的就绪状态 | 以当前范围的成功目录响应作为就绪条件；读取失败阻止新导入，保留原显式选择，已经发送的完成确认仍可重试 |
| 声纹库追加分页没有绑定组件生命周期 | 刷新、关闭选择面板及卸载取消请求；丢弃被取消或不同登录会话的结果 |
| 预检失败容易呈现为收费转写失败，普通继续仍可能显示预检提示 | 增加独立预检停止文案，仅在 pending／preflighting／ready 显示预检状态；决定必须由用户点击 |
| 未选候选人被误报为文件错误，能力关闭后已选身份选项无法直接取消 | 分开文件有效性与候选就绪条件；能力不可用阻止新开启，但仍允许关闭已选身份识别，转回普通转写 |
| 能力关闭后候选预算变为零，会阻止已经 PUT 文件的完成确认 | 已发送的声明保持冻结，完成确认不受新候选选择门禁阻断；仍由服务端核验原声明和授权，新增导入继续受当前能力限制 |
| 手机大字号下搜索框超出表单，长姓名可造成更大溢出 | 限制表单及字段的最小宽度，为搜索标签提供可收缩布局，为候选姓名和已选项提供有界换行 |
| 语言包检查没有覆盖新 importIdentity 命名空间 | 五种现有语言均提供该文件，并将其纳入结构与占位符检查；de／fr／nl 的新增文本目前使用英文 |
| 浏览器验证只检查弹窗／页面外层宽度，漏过内部横向滚动；异常退出可能被 Vite 进程处理吞掉 | 同时检查表单 scrollWidth；加入大字号长姓名及已选姓名检查，显式设置失败退出码 |
