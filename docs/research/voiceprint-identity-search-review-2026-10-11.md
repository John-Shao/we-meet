# 当前说话人身份与搜索走查

日期：2026-10-11（Asia/Shanghai）。分支：`feature/speaker-identity-voiceprint`。

## 问题与修复

人工确认身份后，有效原文已展示通讯录姓名或自定义标签，但统一会议搜索只匹配正文，原文搜索 API 也只匹配正文；检索证据缺少说话人姓名。例如将 `Speaker 1` 标记为“张敏”后，直接搜索“张敏”无法找到该人发言。

- 统一检索与原文 API 在 SQL 中同时匹配正文和当前展示姓名。独立录音／导入使用现有有效原文投影，线上会议使用精确 session 内的 `speaker_name`；继续在授权与发布版本范围内、分页前过滤。
- 当前转写证据带上说话人展示姓名，保留原片段时间与记录引用。每项上下文继续最多 800 字、引用摘要最多 160 字，每来源候选 64 条、每记录候选 4 条、每记录引用 2 条、总引用 8 条的预算保持一致。
- 去重同时考虑展示姓名和正文，保留不同说话人的同一句话。每关键词在姓名和正文同时命中时只计一次分数。
- 姓名继续来自统一的最终归属投影，通讯录姓名、自定义标签、更换和清除立即影响下一次查询。原始 ASR 标签和原文保持可追溯；没有姓名的账户回退到来源标签，邮箱不作为姓名检索字段。

## 验证

使用本地隔离 PostgreSQL／Redis 和模拟 LLM；不调用付费模型，不采集真人录音。新增 7 项回归覆盖通讯录／标签更换与清除、原文不可变、旧 revision 冲突、无姓名账户隐私、组织／转写授权及撤销、不同说话人同文、长正文窗口与时钟。首次测试的两项权限用例未创建组织成员资格，按已有组织边界返回 404；补齐合法成员 fixture，并保留退组织时拒绝读取的验证。

组合回归覆盖新增身份搜索、统一检索、原文分页、排序预算、引号短语、归属接口、身份决定事务与搜索问答 API：131 项通过，耗时 80.70 秒。两个生产文件及新增测试的 Ruff 检查通过，新增测试与检索服务的格式检查和 `git diff --check` 通过。没有新增前端或 Android 修改，也没有通过测试数量推导真实识别效果。
