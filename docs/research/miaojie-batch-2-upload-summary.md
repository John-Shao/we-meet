# 第二批：上传纪要与编辑权限

首批已推送：Web/后端 `c1bce8769`，Android `e02b097f`。

本批完成上传转写到纪要、引用和问答快照的衔接。上传使用独立输入适配器，核验上传发布状态、唯一 capture 归属、段序号、原文哈希及本次发布的段数；不伪造原生录音的 ASR 作业或音频分片。旧上传记录兼容读取，新发布记录额外记录段数和尝试号，防止丢失末尾原文仍生成纪要。

上传只开放最终纪要，必须由有权用户显式请求；沿用既有全局生成开关、完整输入预算、幂等意图、执行前后授权复核和不可变快照。已确认的转写可以在原生录音协议开关关闭时生成纪要。关闭上传入口不会删除已经发布的文字或要求重新付费转写。

人工校对和发言人归属改用独立编辑授权，不再依赖原生录音纪要开关。上传属主可以校对；只读成员没有编辑或生成权限。人工纪要修订和文档导出使用管理身份判断，生成仍使用单独的 AI 能力和开关。Web 上传原文页已接入校对版本和权限契约；Android 沿用首批已落地的通用客户端实现，并补充上传读取和最终纪要请求契约测试。

验证：后端上传/生成/原生录音回归 78 项通过；另组权限、人工纪要、导出和问答测试 74 项通过（两组有重叠）。新增集成测试走上传发布、校对、公开生成请求、模拟模型响应、引用读取和问答执行；还覆盖未发布、缺失原文、旧数据、上传幂等重放和只读权限。Web 39 项测试、TypeScript 和修改文件 ESLint 通过；Android 仓储契约测试通过。真实模型、生产环境和真机画面不在本批验证范围。

没有数据库迁移。新原文发布计数保存在既有上传作业 JSON 中；上传幂等比较排除此内部元数据。相关 Python 修改通过 Ruff 格式化；上传服务原有 3 项参数数量 lint 提示保留。
