# 第十一批：纪要与文字记录的独立共享范围

分享界面现在可明确选择“纪要版本”或“文字记录”。默认保持纪要；全文授权包括本记录当前/后续文字及历史原文引用，不自动增加纪要、媒体、独立文档、写入或二次分享权限，也不会发送消息。

复用 MeetingRecordAccess 的 read_summary / read_transcript 字段，无需迁移。授权和撤权只修改选中的字段；两项都关闭时才删除显式授权行。预览展示对应范围操作后的有效权限；会议角色/所有者带来的继承权限不会被一次显式撤权误报为已经消失。

保持原有组织/已知参与者候选范围、经理权限、锁定与预览哈希检查。全文范围进入请求摘要，跨范围重用幂等键会冲突；已撤销的旧授权回放只返回回执，不恢复权限。旧纪要请求的摘要与恢复格式兼容。

客户端仅在后端 advertised supported_scopes 包含 transcript 时显示全文选项。Android 默认省略新的可选字段，兼容旧后端严格请求验证；恢复时保留原来的选择范围。Android 还核验返回的预览范围、未选中权限保持不变及无媒体/文档/消息副作用。

验证：后端分享服务/API 16 项、Web 12 项、Android repository 10 项通过；Pixel 8 / Android 16 模拟器分享 UI 7 项通过，包括明确选择全文后才提交、旧恢复/撤权/无预选及权限撤销。TypeScript、ESLint、Ruff 通过。未向真实账号授予权限或发送消息。本批不包含媒体授权与原媒体下载。
