# 第二十八批：发言分布与回听

## 实现

- 录音/上传件 speakers 接口在既有 activity 中追加可选 timeline。沿用当前已发布原文、转写阅读权限及 revision 冲突检查；未发布 ASR 重试不进入分布。
- 同一说话人同一采集时钟的重叠/相邻区间合并，静音间隔保留。各发言人、各分页共享整条记录的最后有效识别结束时间作为比例尺，明确标为“已识别原文范围”，不充当媒体总时长。
- 多时钟不画混合时间轴；缺失结束时间不猜测，保留有效区间并注明部分数据。超过 50,000 原文片段不提供统计；合并后超过 1,000 区间不提供分布，既有占比仍可用，不截取前段冒充完整结果。
- Web/Android 提供比例图、展开区间列表及定位回听。列表每页 10 个完整触控/键盘目标，精确传递起始毫秒；图表保留真实比例，不为点击面积拉长发言。
- 只有已有媒体播放能力才传递定位回调；全文只读分享可以查看时间但不能借此获得媒体权限。旧服务端不返回 timeline 时保持既有统计。

## 验证

- 后端 22 个不同用例：既有说话人/统计与新增静音、交叠、统一分页比例、时钟隔离、预算、权限撤销、未发布 ASR 过滤。
- Web 34 项：分布组件 10、统计组件 4、工作区 20；覆盖上传及原生录音的回听接线和撤销播放能力。
- Android 3 项单元、3 项 Pixel 8 / Android 16 仪器测试通过；debug APK 已安装。
- Ruff、TypeScript、ESLint、JSON/语言结构、Android 设计 token 检查通过。

## 发布与边界

需发布 backend + frontend 和新版 Android；本批无迁移。第 26/27 批的 0183/0184 仍需随正常 Helm 发布应用。生产未部署/未验收本批，不把本地合成区间测试记为长录音生产验收。

G8 的单时钟片段级分布已实现；多时钟统一映射、超过预算的渐进加载、媒体全长标尺、词级对齐未实现。线上会议完整录像仍依赖真实录制产物。大文件恢复、长原文跨页生产验收继续按用户要求延后。
