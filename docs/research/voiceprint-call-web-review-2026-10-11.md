# Web 通话声纹采样入口与代码走查

日期：2026-10-11（Asia/Shanghai）。分支：`feature/speaker-identity-voiceprint`。

模型路线保持 Qwen 优先，功能默认关闭。本轮在独立 worktree、隔离 PostgreSQL 和本地 Chromium 中验证，RTC 连接与 HTTP 响应均为合成数据；浏览器主动禁止麦克风、屏幕与相机媒体调用。未调用收费 ASR、采集真人声音或部署生产。

## 本轮实现

语音通话、视频通话和视频会议共用 `Conference` 内的声纹状态入口。前端仅在 `speaker_identity.enabled` 与新增 `sampling_enabled` 均为 true，且当前账号已登录、RTC 已连接并取得房间／参与者 SID 时挂载。摄像头是否开启不参与声纹决策，不订阅或上传媒体。

新增本人只读 `GET /api/v1.0/voiceprint/sampling-connection/?room_sid=…&participant_sid=…`。服务端从签名 webhook 已保存的本人参与记录解析真实会话、组织和授权，不接受客户端选择组织；访客／agent、错误 identity、其他账号、退出／结束连接和已删除来源均拒绝。GET 不创建声明、档案、许可、派发或采样活动，返回 `private, no-store`。

响应包含：可信房间 SID、组织 ID／名称（个人范围为 null）、服务端观察时间、实际采样及候选保留限量、当前登记／积累授权和版本，以及已有的连接声明与许可绑定运行状态。不返回 profile、grant、token、声音特征、联系方式或其他参与者信息。Web 使用普通本人登录及 `X-Voiceprint-Owner`，不复用会议 join token。

面板显示用途、授权作用域、单片段／会话／滚动 24 小时预算、未确认音频保留期、本人试听确认和删除入口。共享麦克风默认保持不采样，设备仅允许本人声明耳机／手机／电脑组，不依据设备名称猜测。选择设备先成为本地草稿；保存设备或修改共享状态必先暂停，允许本次采样是单独动作。另有本次暂停、关闭此作用域后续积累，以及进入该作用域本人设置的入口；关闭积累不改写登记／识别授权。

## 发现与修复

| 问题 | 修复及验证 |
|---|---|
| Web 只知道 RTC room SID，无法可靠选择后端会话及授权范围 | 新接口按本人、room SID、participant SID 解析；连接缺少 webhook 时等待／轮询，不创建虚构会话 |
| 允许采样或启动成功容易被视为正在采样 | 使用上一阶段的许可绑定活动；有效心跳过期 5 秒转为等待，连接投影超过 15 秒为不可确认。计算过期计入整个 HTTP 耗时，迟到响应不能续期 |
| 读请求覆盖新暂停结果，丢失确认触发重复允许 | 每次读／写有本地 revision 和 AbortSignal；写入废弃旧读取，仅重新读取服务器当前状态。普通声明失败清除不确定结果，不自动重放允许 |
| 账号、房间或参与者变化后显示旧私有对话框 | 一个 controller 对应一个固定登录和精确 RTC 连接；切换卸载并取消请求，迟到结果再次校验登录。客户端首次读取后固定可信会话及组织，拒绝范围漂移 |
| 重连事件可能先于 SDK state 变化，旧 SID 再次返回 | Reconnecting／Disconnected 独立清空并废弃未完成 SID 请求；Promise 返回还须当前仍 Connected。重连建立新界面生命周期并清除设备声明 |
| 麦克风重启／切换继承旧设备许可，缺少 deviceId 时无法检查 | 本地仅比较已有 SDK 的设备标识，不传输／缓存／记录；音频输入设备事件、麦克风 track 替换、不同 deviceId 均暂停并清空声明。摄像头／扬声器事件不触发。失败只重试安全的暂停／共享／未声明状态，不重试允许 |
| 麦克风切换期间另一项写操作尚未完成 | 立即显示设备已变化并阻止允许，待正在进行的写入完成后执行安全清除；读状态恢复后再处理安全清除 |
| 设置页只接受登记基线组，会拒绝通话设备模板 | 校验和展示支持 default／headset／handset／computer，仍拒绝重复／未知组；五语言使用对应设备标签 |
| 当前通话组织不在通讯录第一页时选择框空白 | 设置入口携带服务端组织 ID／名称作为初始范围和缺页展示项；该展示项不授予管理策略权限，所有数据仍由本人设置 API 校验 |
| 窄屏大字号标题占用弹窗外部高度，操作超出屏幕 | 标题纳入有界滚动区域；保留对话框无障碍名称，关闭按钮留在区域外。320／390 像素及 1.5 倍字号检查面板边界、横向溢出、底部按钮、关闭及 Escape 焦点恢复 |
| 积累关闭后发起按钮变为 disabled，键盘焦点落到 body，Escape 无法关闭 | 主面板失去焦点时恢复到面板内；不抢占嵌套设置的焦点。实际浏览器验证关闭积累后的 Escape 及入口按钮焦点恢复 |

## 验证

- 后端新增连接专项 17 项；与既有采样及派发恢复组合，共 99 项通过（64.68 秒）。覆盖本人范围、无分配读取、组织／授权版本、关停、来源删除、webhook 延迟、ExpectedOwner 和配置双开关。
- 前端声纹、连接 SID 与现有会议状态组合 126 项通过。新增接口 14、controller 12、通话界面 12、连接 hook 3 项，并扩展既有设置及设备组验证。使用合成数据，不创建真人录音。
- `scripts/review-voiceprint-call-web.mjs` 使用实际 Chromium、产品组件和本地 HTTP；媒体调用为 0、浏览器异常为 0、外部网络请求为 0。覆盖默认不写入、设备草稿、保存暂停、键盘切换共享、明确允许、运行状态回落、本次暂停、全局积累关闭、网络失败恢复及固定错误文案。
- 桌面明／暗主题、390／320 像素与 24px 根字号（默认 16px 的 1.5 倍）截图已经检查；大字号面板边界为 x=61…261、y=61…785，视口为 320×844，无横向溢出，底部按钮滚动后在视口内。
- TypeScript、生产构建、变更 ESLint／Prettier、JSON 和五语言占位符检查通过；Django 检查无问题，变更后端 Ruff／格式与差异检查通过。本轮无新增模型或迁移；既有生产构建仍有大型 bundle 提示。

## 剩余边界

本轮交付 Web 入口及契约验证，不证明真实会议音轨、实际设备切换／RTC 重连时序、云端 Qwen 质检或真人实名识别质量。Web 设备变化须由服务端确认暂停；网络中断时面板显示无法确认，并阻止重新允许，不能宣称后端已收到暂停。后端仍依赖短期许可复核、精确来源和断流丢弃约束。

Android 通话入口／告知／设备声明／状态、完整 RTC 联调、Helm／镜像／独立队列／监控、可信外部备份恢复、历史版本／搜索整体回归及获授权真人／生产验收继续推进。自动归属、自动模板更新和实时身份展示仍不随首期开放；完整开发目标尚未完成。
