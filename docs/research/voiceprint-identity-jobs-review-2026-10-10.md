# 独立身份队列与持久建议走查

日期：2026-10-10。范围：内部身份任务、查询／候选协调、结果提交、撤销与独立批处理命令。用户提交／读取 API、建议确认／拒绝事务及跨端界面仍待接通，不能据此宣称完整实名识别已交付。

## 数据和状态

迁移 `0206_speaker_identity_jobs` 新增 `SpeakerIdentityJob` 和 `SpeakerIdentitySuggestion`。一个任务处理一个已发布来源说话人；记录级接口以后可按同一请求批次分派最多 50 个有界任务。每次不同请求追加建议版本，相同请求重放已有任务；识别不修改 ASR 任务或 `MeetingSpeaker`，不创建登记样本／模板，不推进展示 revision。

任务绑定记录、说话人、请求者、明确组织和候选、来源及候选摘要、固定 Qwen 特征空间、校准策略摘要／版本。幂等约束为记录／说话人／request_key；同 key 的不同来源、候选、请求者或策略返回冲突。建议独立保存结果、固定原因、片段数量／有效语音、候选账号及非概率的分数／差值；只有当前结果为建议时才有候选，不返回其他竞争者的排名。

状态为 queued → running → succeeded／failed／canceled／expired。租约最长 15 分钟，不延长私有文件租约；整个任务最多排队 24 小时，TEXT 来源取既有音频窗口更早值。每个任务最多三次尝试，过期租约可重领且更换 token，迟到结果不能写入新租约。可重试失败、排队和过期运行任务按创建时间有界扫描；模板密钥暂不可用也消耗有限尝试，避免一个坏任务无限占用队列。每请求者最多 100 个 queued／running 任务，达到预算仍允许完全相同的重放。以上是工程上限，不是已测得的生产容量或延迟。

## 当前授权与事务

提交、领取和发布均读取完整来源及候选证明。事务按照本人／候选账号、组织、授权、档案、记录、任务的顺序加锁，与现有登记／模板路径一致。候选用户锁同时防止没有授权行时的并发登记幻象；档案锁序列化正常模板重建。任何 provider、媒体下载或原生进程调用都在事务之外。

执行期间检查当前任务 token、租约、来源头、记录／媒体权限、用户／成员状态、候选授权和校准策略。新增轻量候选摘要，仅查询授权 epoch、档案／active 模板元数据、撤销 generation 下限、有效期和选定组织政策，不反复解密音频／模板。读取完整候选前后比较该摘要；领取和发布仍解密并验证全部贡献证明，轻量检查不能替代最终校验。

查询结果现在明确绑定目标 speaker UUID。发布复核 source digest、同一目标、私有下载 SHA-256、每段属于目标的净来源区间及固定 Qwen 查询契约。组内任意混人、不同明确身份、语音不足、未知和歧义均保存独立诊断，不采用多数票。评分后再核验期限与当前授权／策略，防止解释或评分期间条件改变。

三类授权设置的 epoch 变化及作用域删除会取消相关任务，并立即清除该候选池的所有待确认建议关联、分数和差值。撤销一个未胜出的竞争候选同样使整个旧池失效，不能保留一个人为变小后的旧比较结果。已经人工确认的历史归属不通过此路径改名；确认／拒绝服务及其历史审计关联继续开发。来源记录物理删除时任务和建议级联删除，独立主动登记档案保留。

## 独立执行

`speaker_identity_jobs.process_one` 连接私有下载、原生选段、固定 Qwen encoder、查询短 ASR、匹配和持久建议。没有可用授权模板时保存 `no_authorized_templates`，不读取源音频、不调用收费质检。默认关闭时无需 provider 配置，不领取任何任务。

新增命令：

```text
python manage.py identify_speakers --limit 1 --ffmpeg /opt/ffmpeg/ffmpeg --ffprobe /opt/ffmpeg/ffprobe
```

单批默认 1 个任务，可配置 1～10 个；使用既有 encoder／quality 私有配置文件和私有 S3 存储配置，凭证不出现在命令参数。原生工具必须是经审核的固定绝对路径。输出仅包含启用状态和各终态数量，不记录候选名、向量、音频、签名地址或 provider 正文。命令未接入 Helm 或生产调度，独立 worker 并发、组织预算、队列压力、Linux、实际 Aliyun 条件读取和版本清理仍需部署阶段验证。

## 验证边界

使用隔离 PostgreSQL、随机测试 keyring 和合成特征验证任务幂等、预算、DB 唯一／次数／评分／片段上限、竞争领取、旧租约、有限重试、当前授权／模板／策略／来源变化、撤销竞争者、密钥恢复及来源删除。初次接入复现个人作用域的 nullable／blank 校验问题，补上可空作用域和已删除请求者的模型契约后复验。

实际固定 Qwen 的数据库链路使用合成 WAV：真实私有 S3 HTTP 下载、原生探测／三段选取、实际 encoder 子进程、模拟短 ASR 和完整 DB 结果提交。恢复真实来源授权检查，没有用模拟的来源快照代替数据库发布证明；输入特征、来源及模型空间仍按实际结果决定建议或正常拒绝，不降低阈值。该链路不证明真人身份准确率，也未调用真实收费 ASR。

846 项整组回归通过，无跳过，包含登记／查询／模板／授权、39 项身份任务回归、35 项既有人工决策及上传／保留回归。收尾的真实登记竞态先复现一项失败：空池任务被新登记取消，但 worker 返回值仍写死为 succeeded；修复为读取数据库终态后，40 项身份任务专项全部通过，共验证 847 个不同后端用例。实际模型和原生资源沿用[媒体记录](voiceprint-query-media-review-2026-10-10.md)的仓库外审核包，不能把缺少资源导致的跳过当作验收证据。

`0206` 在隔离验证库执行成功，迁移漂移检查通过；`identify_speakers` 默认关闭命令执行返回零任务、enabled=false。修改的其余 8 个 Python 文件 Ruff／格式通过；新增模型段已格式化，`models.py` 与提交前相比仍是相同的 8 项既有 lint 诊断，没有新增。当前没有 Web／Android 变更或生产部署。

完整待办保留：记录级提交／读取／取消 API、建议确认／拒绝及审计、多个建议的版本协调、Web／Android 接入、收费长 ASR 前的预检、AI 录音派生分人、可信通话采样、部署与获授权真人验收。生产门限尚未校准，匹配和组织功能保持默认关闭，继续 Qwen 优先，不触发 CAM++ 替换。
