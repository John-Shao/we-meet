# 声纹私有状态与试听期限代码走查

日期：2026-10-10。分支：`feature/speaker-identity-voiceprint`。本轮检查本人设置、样本试听、撤权后的状态清理以及后端状态／识别授权门禁；不修改模型路线或匹配阈值。

## 发现与修复

| 问题 | 修复 |
|---|---|
| Web 与 Android 只在发出试听请求前检查样本期限，慢响应跨过到期时仍发布音频 | 响应返回后再次检查当前样本、档案及期限；采用请求前和当前期限中的较早值。Web 不创建播放 URL；Android 将迟到的合成音频字节清零 |
| Android 刷新样本后未缩短已缓存试听的到期时间 | 已加载预览同步更早期限；不能通过刷新延长原期限。到期 tick 停止播放、清零并移除预览 |
| Web 撤权后保留设置、样本及删除回执，Android 保留删除回执和部分分页／删除目标 | 收到访问拒绝后立即清空私有元数据、分页、待删除目标和命令；仍需显式重新加载后才能继续写入。Web 对 401／403／404／410 使用相同拒绝路径 |
| Web 旧接口的 `status=deleted` 被展示为清理已完成 | 缺少服务端投影时显示“删除中”，不凭逻辑撤销标记宣称物理删除。Android 原有“声纹已撤销”措辞正确，无需修改 |
| 两个 Android 合成录音 UI 用例依赖模拟器事先授予麦克风权限 | 使用测试 Activity Result 注册器明确返回模拟权限结果；实际录音来源仍为合成 WAV，无需授予隔离包真实麦克风权限 |

新回归用例在修复前实际失败：Web 三个用例、Android 三个 JVM 用例。首次模拟器运行另发现上述权限依赖，16 项中 2 项失败；修复测试的权限返回流程后重跑，不能以 adb 退出码作为通过依据。
