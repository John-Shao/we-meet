# Qwen 登记质检与代码走查

日期：2026-10-10（Asia/Shanghai）

本轮接通登记样本的独立 Qwen 质检任务，检查有效语音时长、录音内单人证据及本次随机朗读内容。固定 Qwen encoder 继续负责特征提取；质检不生成语音，不自动确认样本、不开启任何本人权限，也不直接产生实名匹配。测试使用合成音频、隔离数据库和本地模拟 ASR 响应，没有调用真实收费 ASR，没有采集真人声音。

## 质检契约

使用 `qwen-audio-3.1-asr-flash` 的短音频同步接口，发送 Base64 WAV 并开启 `speaker_diarization_enabled`，读取最终句子及词时间戳。音频只在请求正文中传输，不增加公开音频地址，也不向模型提供预期朗读内容、热词或上下文答案。[阿里云短音频 ASR 官方契约](https://help.aliyun.com/en/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)

输入沿用登记规范：3–10 秒、24 kHz、单声道 PCM16 的规范化 WAV；此 ASR 模型的官方说明支持任意采样率，不能套用另一实时模型的 8／16 kHz 限制。[官方 ASR 模型说明](https://help.aliyun.com/en/model-studio/asr-model)

策略为 `qwen-short-asr-enrollment-v1`：

- 严格检查最终句子、声道、非空整数 speaker ID、词类型与区间；缺失或无效分人证据属于不可用，不能判为通过。
- 按词开始／结束时间重建朗读顺序，合并词区间计算有效语音，避免乱序、重复区间和标点虚增时长。标点不计入语音，仍限制词文本长度。
- 所有句子和实际词的 speaker ID 必须指向同一人；发现多人即拒绝，不按多数票忽略其他声音。
- 有效语音至少 3 秒。核对登记槽位的六组两位随机数，支持五种界面语言的数字及常见基数词写法，数字和顺序必须精确一致；固定正文归一化后相似度至少 0.70。只有数字而没有正文不能通过。
- 新登记使用较短正文，便于在 10 秒以内朗读；已经签发的挑战保持原文本，以数据库中的实际挑战核验。

0.70 是未经真人校准的正文容错工程值，不是声纹身份阈值。随机朗读用于减少旧片段复用，不能据此宣称具备强活体或抗语音合成能力。供应商分人和词时间戳的真实效果仍待获授权样本验证；官方模型名称没有在本系统中冻结云端权重 revision。

## 队列、授权与加密证明

`0205_voiceprint_quality_jobs` 增加独立 `VoiceprintQualityJob`，每个样本最多一条任务，尝试次数有数据库上限 3。编码成功仅为登记来源建立质检回执；已有信号检查通过、未到期的登记样本可由有界批处理补入。通话来源不进入随机朗读质检，须另行完成可信采样与质量契约。

领取沿用用户 → 组织 → 授权 → 档案 → 样本 → 任务的加锁顺序，忙碌作用域跳过。租约最多 40 秒，外部请求使用可终止子进程，连接超时 3 秒、读取等待最多 30 秒、父进程硬期限最多 35 秒。等待期间持续复核授权；撤销、过期、进程异常或超时后回收子进程。供应商正文最多 64 KiB，内部固定结果最多 4 KiB；拒绝压缩及重定向，禁用环境代理，云端仅允许指定阿里云 HTTPS 主机并验证 TLS。

完成时再次核对租约 token、世代、授权版本、源区间、登记挑战、音频摘要及两份密文摘要。质检前必须解密并验证 `VPS1` 的原始信号质量证明；元数据被改成“已质检”也不能跳过认证。通过后只重封装同一向量，绑定新的时长、单人结果和当前挑战摘要。本人确认与模板构建继续验证该证明，不能通过编辑质量布尔字段激活样本。

明确的多人、语音不足或朗读不符：拒绝样本并清除音频／特征，任务标记已完成评估。网络、凭证或响应契约不可用：保持待质检，不伪造失败音频的质量结论；仅明确可重试故障允许在三次上限内重试。未确认数据仍受原有 24 小时候选期限约束。本人拒绝、权限撤销和 TTL 清理同时停止编码及质检任务。

不保存 ASR 正文、推测姓名、供应商私有错误或请求标识。音频、凭证和挑战只经有界 stdin 交给子进程，不写入命令行／临时文件；子进程 stderr 丢弃。命令只输出固定状态的聚合计数。

## 配置与运行

`MEETING_VOICEPRINT_QUALITY_ENABLED` 默认 false，配置文件路径默认空；关闭时命令不读取凭证、不补任务、不调用模型。它与全局开关、模板开关以及本人三类授权互相独立。部署前需按项目密钥挂载方式提供私有 JSON，不能把真实凭证提交到仓库：

```json
{
  "url": "https://WORKSPACE_ID.cn-beijing.maas.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation",
  "api_key": "REPLACE_WITH_PRIVATE_API_KEY",
  "ca_bundle": true
}
```

以实际小写 workspace 主机替换示例，设置 `MEETING_VOICEPRINT_QUALITY_CONFIG_FILE`；也支持文档中的北京／新加坡指定主机形式。loopback HTTP 仅供隔离技术验证使用。配置缺失或无效时，开启的命令在领取任务之前失败，不消耗样本的调用尝试。

正常项目环境中的顺序为：

```sh
python manage.py migrate
python manage.py process_voiceprints --limit 10
python manage.py check_voiceprint_quality --limit 10
# 质量通过后由本人试听并明确接受；然后才可构建模板。
python manage.py build_voiceprint_templates --limit 10
python manage.py expire_voiceprint_samples --limit 100
```

旧的无认证裸特征或不完整质量来源不会被自动升级为可信证明。生产 worker 调度、云端预算及发布配置仍待部署阶段完成。

## 走查修复与验证

| 发现的问题 | 修复 |
|---|---|
| ASR 句子数组乱序导致正确随机数被误拒绝 | 按词时间戳重建顺序；中文词边界不拆散基数词 |
| 标点／重叠时间可能抬高有效语音时长 | 排除纯标点、合并时间区间，并保留文本长度限制 |
| 等待超过 3 秒就误认为云端不可用，可能重复计费 | 允许 30 秒读取等待，同时用父进程硬期限和取消回收约束总占用 |
| 修改元数据为已质检可能提前结束任务 | 提前结束也必须验证当前挑战及解密后的来源／质量证明 |
| 信号检查结果可能被当作语音／单人检查 | 独立策略证明、当前挑战摘要及严格结果契约；不可用时保持待质检 |
| 迟到结果、修改来源或撤销后仍可能提交 | 租约、原始来源、授权及密文摘要复核；覆盖撤销、替换租约、删除和过期 |
| 编码队列重试被质检消耗，通话来源错误进入朗读任务 | 独立队列和三次上限，仅登记来源接入此策略 |

验证：全部声纹相关后端 386 项回归通过，无跳过，包括 95 项新增质量／朗读／独立任务／真实子进程边界用例，以及 1 项实际固定 Qwen 权重的完整登记链路。真实本地 HTTP／子进程测试覆盖 4 秒正常推理等待、慢速响应头硬期限、撤销回收、无重定向和固定错误隐私；隔离数据库覆盖并发领取、三次重试、迟到结果、修改密文／挑战、伪造已质检元数据、本人确认及模板构建。实际 encoder 和本地模拟 ASR 分别验证，不能将模拟响应解释为真实云端质量验证。

Ruff 与格式检查通过；隔离库迁移至 `0205` 成功，迁移漂移检查无变化。默认关闭命令的 admitted 和全部任务计数为 0；53 项纯质检回归收尾复验通过。Web／Android DTO 和独立模型服务源码未改动。
