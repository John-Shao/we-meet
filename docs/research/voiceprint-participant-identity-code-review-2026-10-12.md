# 参会者声纹身份识别代码走查

日期：2026-10-12。后端／Web 基线为 `aliyun-dev` 的 `f12d6c04c`，Android 基线为 `main` 的 `53d5a721`。

本轮检查从录音来源、明确选择的候选人员、声纹模板与匹配门限，到异步任务、建议读取和人工确认的链路，重点复核临时故障、权限变化和未知提交结果。继续使用 Qwen 优先的既定路线，不调整识别门限。

## 发现与修复

| 问题 | 修复 |
|---|---|
| 后端完成任务时，模板密钥或校准文件暂不可用被当作授权变更，任务永久取消；评分后的最后一次门限复核也会发生同样的问题 | 领取与完成共用上下文错误分类；503 标记为失败并允许有限重试，完成阶段不重复计入尝试次数，最多三次。恢复后重新领取租约并复核完整来源、候选和门限；故障期间不创建建议 |
| Web 保留未知提交命令后，401／403／普通 404 错误仍允许点“重试原请求”；410 没有进入访问拒绝分支 | 访问拒绝后禁用重试和取消，在提交函数内增加同样的限制；隐藏姓名及候选。需要显式刷新成功才能恢复操作 |
| Web 对提交明确返回的 400 仍保留无效命令；Android 则会把其他读取请求的 400 误当作原提交被拒绝，丢失尚未确认的命令 | 只有提交请求返回的 400 才清除原命令；刷新或目录读取的 400 保留未知命令与原 key，防止改用新 key 重复排队；409 继续使旧命令失效 |
| Android 只要存在未知提交命令，就把所有 404 当作批次尚未创建，记录已不可访问时仍可重试 | 私有客户端仅在带 request key 的读取返回 404、且 JSON code 精确为 `voiceprint_identity_request_unavailable` 时，转换成可恢复的批次缺失异常。错误 JSON 最多解析 8 KiB，其他状态、错误码、无 key、无效或超限 JSON 均保留 HTTP 错误；普通 404 禁止写入 |
| Android 导入预检失败时虽然隐藏了姓名，但控制器仍保留旧姓名和组织目录；并发目录响应可在库读取失败后重新填入私有数据 | 目录失败清空姓名；库读取失败清空姓名、目录及分页，并使在途人员请求失效。保留用户明确选择的 ID，不把旧姓名当作已重新核验的结果 |

后端授权、来源或有效门限版本确实变化时仍取消任务；任务到期仍终止。自动匹配只生成待人工确认的建议，不写最终说话人身份，也不登记声纹。

## 交付边界

本轮只修改代码、回归用例和走查记录，整理到后端 `aliyun-dev` 与 Android `main`；生产部署及安装包另行交付。本轮没有重新部署或变更生产声纹匹配／采样开关；此前交付的 Android `0.3.0-work.3` 内部 APK 也没有替换。

测试仅使用合成音频、特征和私有 API 夹具，不采集真人语音，不调用收费 ASR。真人多人实名匹配准确率、真实 Qwen ASR 和生产验收仍需按原方案补齐，代码回归通过不能替代这些验收。
