# 登记声纹模板、来源校验与代码走查

日期：2026-10-10（Asia/Shanghai）

本轮补上登记模板构建及验证，并走查样本确认、来源撤销、独立授权和批处理。模型继续使用已固定的 Qwen encoder。测试只使用合成向量、合成音频和隔离数据库；没有采集真人声音，也没有获得真人识别准确率结论。

## 当前行为

`build_voiceprint_templates --limit 10` 是独立、有界的内部批处理。`MEETING_VOICEPRINT_ENABLED` 和新增的 `MEETING_VOICEPRINT_TEMPLATES_ENABLED` 默认均为 false；关闭时不构建、不修改档案。后者控制模板构建，不替代本人登记／积累／识别权限，也不代表已允许发布实名匹配功能。

首次构建要求当前作用域、账户和 generation 有效，本人仍允许登记，并满足以下条件：

- 同一固定 Qwen 特征空间、当前档案／generation 的 3–12 个不同音频片段，合计至少 30 秒有效语音。
- 每段有效语音为 3–10 秒，且不超过片段区间；语音和单人检查均已通过。
- 每段都有本人的接受决定，且决定的用户、generation、原始授权版本一致，确认在候选期限内完成。
- 登记许可、槽位、所属档案、组织及版本对应；确认距今不超过 365 天。
- 所有特征可在正确的档案／对象作用域解密，来源和质检元数据与加密证明一致；拒绝旧的裸向量格式。
- 各片段向量两两一致，不能用多数票忽略异声片段；各片段等权平均后再次归一化。

本轮只构建一个 `default` 登记设备组。通话贡献须先完成可信采样许可；不会凭一行 `source_type=call` 或 `status=confirmed` 进入该构建器。多设备分组、受控更新及通话来源删除继续按完整方案开发。

两两余弦下限暂为 0.85，策略版本为 `qwen-enrollment-baseline-v1-cos085`。这是尚未校准的工程默认值，不是实名匹配的绝对阈值，不能据此开放身份建议。真人验证、匹配绝对阈值／第一二名差值及发布门禁仍待完成。

## 加密证明和稳定模板

样本特征仍使用档案密钥及原有 AES-GCM 作用域。其明文改为 `VPS1` 来源／质检头加固定 1024 维 little-endian float32 向量，头与向量一起加密。头绑定样本和档案 ID、generation、模型空间、原始授权版本、音频摘要、登记许可／槽位，以及原始记录／会话／音轨／区间和质检 JSON。单独编辑元数据或把信号检查布尔值改成 true，无法通过解密后校验。本人确认状态和时间不写入编码证明，因为本人确认不能改变编码器的质量结论。

模板明文为 `VPT1` 头及聚合向量，绑定模板 revision、策略、generation、模型空间、维度和全部贡献摘要。贡献摘要包括源证明、特征密文摘要及本人决定。身份授权检查会验证当前贡献和加密模板，不能只凭 `status=active`、维度或存在密文判断可用。

有效基线保持不变；新增本人确认录音不会自动更新它。贡献被删除、变成无效来源或元数据被修改后，授权检查立即拒绝该模板，构建器暂停旧模板；仅在剩余有效贡献足够时生成新 revision。旧 revision 的密文不能替换新模板。

确认后的短期试听音频到期，可以清除原始音频并保留仍有效的特征和基线。修改权限版本会停止旧会话中未完成的上传／任务，但不会取消已经完成的本人决定。关闭登记后，有效旧基线仍由独立的识别权限控制；删除档案、撤销 generation、关闭组织或离职的检查照常生效。

## 走查发现与修复

| 问题 | 修复 |
|---|---|
| 裸特征密文没有绑定音频摘要和质检结论 | 增加来源／质检证明；本人确认及模板构建均验证证明，拒绝旧格式和被修改的元数据 |
| 存在模板密文和合格样本元数据就可能被认为可识别 | 验证策略、revision、贡献摘要及实际解密载荷；限制每个模板的贡献数量 |
| 不合格 pending 档案可能长期占据队列前列 | 增加 `template_checked_at`，按从未检查／最早检查顺序轮转，单批 limit 为 1–100 |
| 新确认样本增多后，固定扫描范围可能把原基线挤出验证集合 | 验证精确的原贡献 ID；新构建仅扫描最近的有界候选 |
| 关闭登记导致旧会话取消，可能连带废弃已确认基线 | 已完成决定保留效力；维护批次仍检查有效旧基线，不自动重新开启登记权限 |
| 混音可以通过多数相近片段掩盖一个异声片段 | 对全部片段做两两检查，不选择多数票或最高分子集 |
| 损坏的模板维度可能在重建时继续被沿用 | 重建显式恢复固定 1024 维，生成新证明 |
| 超大数值、NaN、零向量或历史密文重放 | 有限数值／单位范数检查、对象作用域加密、来源及模板 revision 绑定 |

锁顺序保持用户 → 组织 → 授权 → 档案 → 模板，忙碌作用域跳过。构建在事务内完成，不调用外部模型。命令只输出 enabled 和各固定状态的聚合计数，不输出用户、样本、模板 ID、音频、特征或私有错误正文。

## 迁移和运行

`0204_voiceprint_template_proofs` 添加档案检查时间和模板 revision／策略／贡献摘要。旧模板的空策略和旧裸特征不会被自动升级为可信登记；应重新登记、重新编码并完成真实质检与本人确认。迁移不会开启任一功能或本人权限。

在正常项目环境配置独立 keyring 后，内部批处理示例：

```sh
python manage.py migrate
python manage.py process_voiceprints --limit 10
python manage.py build_voiceprint_templates --limit 10
python manage.py expire_voiceprint_samples --limit 100
```

当前编码器只提供信号检查，`speech_checked` 和 `speaker_consistency_checked` 都为 false；因此真实编码结果仍停在 `quality_pending`，不会被这个构建器激活。需要继续接入语音／单人质检，不允许通过人工编辑质量字段绕过。
