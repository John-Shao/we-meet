# 声纹候选、许可与轨道周期回收走查

日期：2026-10-10（Asia/Shanghai）。分支：`feature/speaker-identity-voiceprint`。

在[来源删除清理](voiceprint-source-removal-review-2026-10-10.md)上补齐周期维护，继续 Qwen 优先，功能默认关闭。只用隔离数据库、合成 WAV 和合成模型结果；没有真人采样、收费 ASR 或生产部署。

## 保留与回收

1. **已确认试听音频**：已完成特征的当前 generation 样本，在下一次维护时清除音频，不等待原 24 小时上限。样本特征、本人决定、模板密文及已消费回执保持；未完成特征的异常确认行仍受原试听到期上限约束。正常结束或采样暂停不撤销已确认特征。
2. **到期候选**：待确认、拒绝、到期、已删除及旧 generation 样本，达到原到期时刻后物理删除样本、相关租约／任务和本人决定。先冻结贡献与许可引用，清除受影响模板密文；独立来源清理任务随后用剩余合格贡献重建。旧 `expire_voiceprint_samples` 保持原契约，新维护命令提供物理回收。
3. **许可过期与私有上下文**：过期的 issued 许可转为 expired；没有样本引用的终态许可清除 participant、房间／轨道 SID、设备组及 profile 关联。保留 owner、预留时刻、会话 UUID 和预留时长，全部状态继续占用原配额。
4. **滚动／会话配额**：只有没有样本引用、超出滚动 24 小时窗口、许可已到期且会话不存在或已结束的终态许可才删除。边界采用严格 `<`，与发放时的 `>=` 一致；超过 24 小时仍在进行的会话继续保留 60 秒会话预留。引用合法样本的已消费许可不能回收，即使其短期许可和试听音频均已到期。
5. **重试与轨道**：一般终态许可暂时保留 track FK，阻止原 request key 重试时再次预留；来源明确删除时沿用来源墓碑门禁。许可释放后，只有已取消发布、参与者已离开或会话已结束，且没有许可／样本引用的轨道才删除。先取会话锁，再重新检查轨道关闭状态和全部引用；SID 摘要墓碑阻止迟到发布重新创建该轨道。有效特征引用的来源保持完整。

## 走查补充修复

- 已完成清理回执遇到再次出现的旧样本行时，重新清理相同 UUID 的原作用域／generation，不将 `complete` 当作原数据必然不存在。周期来源恢复和维护均可处理；新的幸存贡献模板因摘要已变化而保持。此验证针对保留当前可信墓碑的本地行恢复，不代替生产外部备份恢复。
- 来源 SID 摘要改为 UTF-8 编码，合法 ASCII SID 的摘要保持相同；损坏的旧非 ASCII 元数据也能删除，不阻塞账号／来源清理，仍不能经过正常 SID 校验入库。
- 过期状态和音频擦除采用锁内 SQL 更新，允许清除 profile／track 已失去关联的旧许可，不依赖旧元数据通过完整模型校验。清理不加载声纹密钥、不解密音频和向量、不调用 provider。
- 许可按 owner → session → track → permit 顺序；轨道按 session → track；样本沿用 owner／组织／授权／profile／sample 锁序。忙碌行跳过，不等待其锁；每次重新核验时刻、generation、关闭状态及引用。异常只计入固定 `failed` 数量，不输出原异常、身份、音频或签名地址。
