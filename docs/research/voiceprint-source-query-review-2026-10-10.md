# 可信上传源与 Qwen 多片段查询走查

日期：2026-10-10。范围：已发布导入转写的内部查询生产者、私有存储读取与临时文件回收。身份任务、实名建议和确认 API 尚未接通。

## 上传对象与转写版本

小文件经过后端上传时，保存实际字节的 SHA-256；直传和分片上传保存服务端 HEAD 返回的 ETag、VersionId 和长度。直传意图摘要和分片会话摘要只用于幂等判断，不能作为音频内容摘要。新证明存于私有 `_identity_source`，不返回公共元数据，不改变重放意图。

ASR 提交及播放签名统一使用已采纳的 VersionId。私有查询 GET 使用固定 bucket／前缀／服务端对象键、IfMatch 和该 VersionId，核验响应、实际长度、下载 SHA-256及读后的同版本 HEAD。[Boto3 GET 文档](https://docs.aws.amazon.com/boto3/latest/reference/services/s3/client/get_object.html)定义条件读取，[HEAD 文档](https://docs.aws.amazon.com/boto3/latest/reference/services/s3/client/head_object.html)定义指定版本及不透明 ETag；ETag 不是本实现的完整内容 SHA-256。

**没有固定 VersionId 的直传／分片源不能进行身份查询。** 云端 ASR 只读取签名 URL，不能发送后续查询的 IfMatch 请求头；仅在查询阶段检查 ETag，无法证明 ASR 当时读的是同一代对象。普通转写保持兼容，旧记录或缺失证明的源同样不开放身份查询。以后若支持未启用版本的直传，需先实现受控、不可覆盖的私有源复制及其生命周期，不从上传意图或当前 ETag 推断历史内容。

## 可信来源与选段

`voiceprint_sources` 重新读取当前账号、组织政策及记录权限，要求编辑能力与媒体读取能力同时存在。仅支持 `upload`，要求转写成功、采集停止、没有正在执行的重转写、没有开始清理，且分人明确启用。TEXT 来源使用既有期限：开始后最多 24 小时，结束后重试窗口最多 30 分钟，两者取更早值；身份查询不能延长音频保留。

快照绑定记录／生命周期 revision、组织政策、采集 revision／时间、上传任务 attempt、已发布数量、配置摘要及对象证明。只读取原始片段的来源、时间、分人编号和 payload_hash，不读取文本或词对齐。片段必须属于当前采集的 `uploaded-file`，序号完整、原始 revision 为 1、没有其他转写任务、时间有效。未知编号作为阻断区间，不能被命名或当作单人证据。

最多读取 20,000 条原始片段、50 个已知说话人。扫过时间边界，去掉与其他／未知说话人的重叠；同人相邻句合并，静音或重叠不能跨越。每个净区间两端各留 100 ms，选择最多 12 段、每段 3～10 秒，分布覆盖完整净时间线。可用时长足以提供最少独立片段但不足标准 5 秒切片时，改用合法的较短切片；不补零，也不把不连续语音拼成一段。

## 私有读取与 Qwen 查询

存储读取由固定模块子进程执行，显式服务凭证通过管道传递，不使用客户端 URL、代理、环境凭证发现或自动 SDK 重试。连接／空闲读取分别限制为 3／5 秒，整个下载最多 90 秒，文件最多 512 MiB。沿用进程树、内存、CPU、输出和父退出边界，持续核验授权，异常不输出凭证、对象键或 SDK 正文。

`voiceprint_query_producer` 为一个当前已分人的说话人生产查询：先验证校准状态与配置，私有下载后探测原媒体，仅允许一个单声道音频流、最长 2 小时。净片段不足时不调用收费质检；每段实际解码后，先过固定 Qwen encoder 信号质量，再调用 `qwen-short-asr-query-v1`。每个合格片段绑定同一音频摘要、模型空间、质量与源区间；混人片段或组内两两特征不一致直接拒绝，不采用多数票。

开始和释放合格查询前全量复核来源快照，执行期间复核当前授权与来源头。向量只在内存返回，不创建登记样本／模板或修改说话人身份。上层必须把当前任务租约、候选授权 epoch 和校准策略加入授权回调，并在持久建议及确认事务中再次核验；当前生产者不能替代该协调层。

## 临时文件与部署约束

原始下载仅写入专用私有目录 `we-meet-voiceprint-query/query-*` 的固定 `source.media`，任务租约上限 15 分钟。正常和异常退出清理整个目录；独立计时器到期删除音频，即使调用方仍等待，也不能仅依赖上下文退出。原生句柄短暂占用时最多重试既有的 45 秒排空期，下载读回之后再次检查期限，不能把晚到数据重新写入。

新增 `python manage.py purge_voiceprint_query_files --limit 100`，按到期租约加 45 秒排空期回收主进程突然退出后的残留。单次扫描最多 100 个目录项（可配置 1～1,000），只处理专用根目录的直接 `query-*` 子目录；递归删除前核验绝对目标，拒绝跟随链接。坏／缺失租约按目录时间加 15 分钟兜底，输出只有扫描／删除／失败计数。

生产仍需把此命令接入同一临时卷的周期调度，验证 Linux、目录权限／Windows ACL、异常父退出和源文件回收。当前不存在身份任务 worker，尚无其并发容量或回收调度部署证明；大规模目录的回收吞吐和公平性也需随 worker 预算验证。存储要求显式服务凭证及 TLS；实际 Aliyun 存储的条件读取／版本兼容性尚未实测。现有 TEXT 存储门禁继续拒绝未实现物理版本清理的版本化桶，不能为了身份查询绕过该保留规则。

## 走查修复与验证

| 问题 | 修复 |
|---|---|
| 直传／分片意图摘要被误当作内容摘要 | 区分实际字节 SHA-256 与服务端对象证明 |
| 查询指定版本，但 ASR／播放仍读取最新对象 | 共用已采纳 VersionId；未固定版本的直传源不开放身份查询 |
| 已过期、媒体权限缺失或未完整发布的转写源进入查询 | 重新检查当前权限、保留、attempt、来源及片段完整性 |
| 混叠／未知区间或相邻同人句边界导致错误切片 | 全时间线扫边界、去重叠、同人合并与两端保护 |
| SDK 私有 client 被误用为上下文管理器，实际子进程无法读取 | 实际本地 S3 回归复现后改用 `closing`，流与 client 都关闭 |
| 主进程异常退出后临时音频没有独立回收 | 到期删除、硬期限及专用目录有界回收命令 |
| 慢速读取在到期之后才返回，仍可能写入音频 | 每次读取返回后再次核验期限；晚到正文及 EOF 回归 |
| 错误类型的存储 endpoint 泄露非契约异常，含 NUL 的地址被接受 | 两条失败先复现，再提前检查字符串、长度与控制字符，统一配置错误码 |

测试使用合成音频、随机测试密钥、隔离数据库和本地 S3／ASR HTTP 响应，没有真人录音或真实收费 ASR 请求。实际固定 Qwen encoder 通过完整私有下载、原生选段和 5 段查询传输，输出仍按真实一致性结果决定 ready 或拒绝，不放宽门限。数据库来源快照和生产者分别测试，尚未宣称已经完成身份任务的端到端事务协调或多人实名验收。

768 项整组后端回归通过，无跳过，包括实际固定 Qwen 的登记／查询、108 项新增来源／选段／下载／生产／回收用例中的 104 项，以及既有普通上传、直传、分片、保留与存储回归。收尾增加 4 项存储配置检查并复现两个失败，修复后 29 项私有读取专项复验通过，共验证 772 个不同后端用例。16 个修改 Python 文件 Ruff 和格式检查通过；回收命令实际执行返回零残留、零失败。没有新增数据库迁移、Web／Android 修改或生产部署。

可复验的测试文件：`test_services_voiceprint_sources.py`、`test_services_voiceprint_source_adoption.py`、`test_services_voiceprint_source_storage.py`、`test_services_voiceprint_query_producer.py`、`test_services_voiceprint_query_files.py`。实际原生／编码器用例需要仓库外经校验的 FFmpeg 与固定 Qwen pack，使用环境变量 `VOICEPRINT_TEST_FFMPEG`、`VOICEPRINT_TEST_FFPROBE`、`VOICEPRINT_FLOW_PYTHON`、`VOICEPRINT_TEST_MODEL_DIR`、`VOICEPRINT_TEST_ENCODER_SHA256`；无这些资源时的跳过不能作为验收证据。本轮资源与上一阶段一致，详见[媒体验证记录](voiceprint-query-media-review-2026-10-10.md)。

完整待办仍包括导入前分人预检（在收费长音频 ASR 前）、身份任务／持久建议／确认、AI 录音派生分人、可信通话采样、跨端识别交互、部署和获授权真人验收。生产匹配保持默认关闭，仓库没有批准的生产门限；继续 Qwen 优先，本轮证据不触发 CAM++ 替换。
