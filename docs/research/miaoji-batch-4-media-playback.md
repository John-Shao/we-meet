# 第四批：上传媒体播放与签名续期

日期：2026-09-20。

- Web 按 `media_type` 使用 audio/video 元素，视频保留比例并限制阅读页占高。签名 TTL 前续期，换地址后恢复时间、倍速和播放/暂停状态；提前点击原文的 seek 等元数据就绪再应用。失败显示重试，重新鉴权失败移除媒体，离开时取消请求与计时器。
- Android 播放器按记录 ID 管理生命周期。每次媒体地址复核不会再重建引擎，下一次播放/定位采用最新地址；旧流出错且已有新地址时从当前位置恢复。
- Android 上传视频使用 SurfaceView 输出画面；播放器支持动态画面比例。MediaPlayer 改用异步准备，加载和失败状态可见；异步定位期间保留目标时间，避免先向文字区域报告错误的 0 秒。
- Android 纪要引用也支持跳转上传媒体。

验证：Web 播放器 10 项测试通过，TypeScript/ESLint 通过。Android Pixel 8 / Android 16 模拟器上 8 项设备测试通过：点击播放、位置回传、精确 seek、暂停、失败反馈、播放/暂停时更新签名地址、Surface 输出连接、真实 WAV 的异步准备与定位。设备测试所用 WAV 在测试内生成并清理，没有访问真实会议内容。

仍需发布环境验证：实际视频解码及竖屏视觉表现、对象存储 Range/CORS、超过真实签名 TTL 的网络播放和大文件。这些不能由模拟地址与短本地文件测试替代。
