## 开始所需信息

- 已部署本轮后端/Web/Android 提交的测试环境地址及版本标识。
- 可用的测试登录方式；至少所有者、仅纪要读者、全文读者三个测试身份。不要把密码、令牌或云存储密钥放入本文件。
- 可用于测试的媒体或记录：约 47 秒竖屏视频、超过 30 段的长录音、大于 100 MiB 的文件。截图不是可上传或解码的媒体样本。
- ASR、LLM、对象存储和需要测试的 Worker 在该环境中可用。

当前会话尚未获得上述目标环境/样本信息；本地隔离 PostgreSQL、Redis、Mock API 与 Android 模拟器测试结果不能替代这些结果。仓库部署交接文档描述了配置与部署流程，未据此推断某个远程版本已经更新。

## 操作与通过条件

| 场景 | 操作 | 必须观察的结果 | 证据 |
|---|---|---|---|
| 短竖屏视频 | 导入、播放、查看全文/纪要/章节、改名 | 画面比例正确；无章节有明确空态；改名在两端一致 | 待实测 |
| 长原文 | 播放越过 30 段；搜索另一页；点击原文/章节回听 | 高亮、跨页定位与媒体时钟一致；手动阅读期间不抢滚动 | 待实测 |
| 并发校对 | 两端打开同一段，分别修改；另一端刷新/保存 | 草稿保留；旧版本保存冲突；搜索/新纪要/导出使用有效文本，旧引用不变 | 待实测 |
| 分片恢复 | >100 MiB 上传，在合并请求后制造响应丢失 | 重新进入后识别已合并对象，免重传并且只建一条记录 | 待实测 |
| 媒体续期 | 播放超过签名 TTL，再定位远端片段 | 获得新签名；位置/倍速/暂停状态保留；实际 Range 请求成功 | 待实测 |
| 原文件下载 | 上传所有者在 Web/Android 信息页下载 | 服务端 attachment 文件名正确；浏览器完成传输；文件大小/哈希一致 | 待实测 |
| 纪要/全文分享 | 分别授予、撤销两种范围，再重试旧请求 | 未选权限不变；无媒体权限提升；仅纪要不能读全文；回放旧请求不恢复已撤权授权 | 待实测 |
| 撤权 | 打开原文与媒体后撤销对应权限，再刷新或等待复核 | 不再请求/展示被拒绝内容，不再获取新媒体签名 | 待实测 |
| 发言统计 | 使用有重叠、未知发言和不完整结束时间的已知样本 | 与“识别片段时长”口径一致；部分/无数据有说明；不是录音总时长占比 | 待实测 |
