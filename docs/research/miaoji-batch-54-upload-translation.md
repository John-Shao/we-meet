# 第五十四批：上传文件全文翻译

## 范围与决策

用户选择先补上传文件全文翻译。线上会议统一录像回看继续后置：需部署 LiveKit Egress 并启用云录制，ECS 容量/成本尚待核验；本批不修改云录制或 Egress 开关。原生分人、原生热词等保留待办，不再沿用此前建议的第 54–58 批编号排期。

## 实现

- 为上传来源新增 `UploadTranscriptTranslation`（迁移 0187），与实时译文档案分开。只有当前所有者能显式发起有用量的翻译；全文阅读者可查看/导出，只有纪要权限者不能读取。每个读取/导出都复核当前权限，禁用缓存。
- 首批目标语言为英语、简体中文。从发布成功的上传件读取**校对后的全部段落**并冻结原文、段落 ID/修订、说话人和源时间；不依赖先生成纪要。一个语言一个产物，可切换查看。
- Celery backend 异步执行；beat 恢复消息派发，任务原子认领防重复执行。用户请求键绑定记录、语言和原文修订；相同修订的成功产物复用。付费执行失败不会自动重试，用户手动重新发起创建新任务；丢失响应时双端保留请求键核对。
- 按段落分批翻译，对返回 JSON 的段落数量、顺序、ID、非空文本逐项验证；缺段/错误 ID/供应商截断/任一批失败均不发布半份“全文”。输入中的指令按引用文本处理，模型没有工具。
- Web 和 Android：译文 Tab、语言选择、任务状态/进度、原文对照、原声回听定位、50 段分页、TXT/SRT/VTT 导出。语言切换和读取不会触发付费生成。App 导出在系统文件选择器返回后重新鉴权，不把正文保存在选择器状态中。
- 校对/归属等原文修订变化后，旧成功译文保留且标明过期，禁止旧版导出/定位；需要显式重新翻译。执行中来源变化或权限失效则不发布结果。
- 活跃翻译参与回收/删除忙碌检查；超时任务终止为 incomplete。任务、原文快照和译文随记录删除级联清理；没有创建独立 Docs 副本。
- 列表轮询只读取任务元数据，延迟加载正文/快照；状态期限建立数据库索引。

## 本批发现并修复的既有回归

扩大回归时，已有 `test_upload_replay_after_publication_preserves_idempotency` 返回 409。上传完成会写入 `_original_audio_duration_ms`，原幂等比较只排除 `_file` / `_published`，从而把内部派生时长误认作用户修改选项。本批仅将该派生字段加入排除项；仍验证相同内容可重放、修改 diarization 仍返回 409。未放宽永久删除键的拒绝规则。

## 边界

- 完整输入上限：2,000 段、快照 JSON 240,000 UTF-8 字节、单段文本 6,000 字节、最多 32 批（每批至多 20 段/8,000 文本字节）。超限整体拒绝，**不截取前面部分当作全文**。本批并未恢复用户明确延后的长原文/大文件验收。
- 原文、译文数量及引用结构完整，不等于语义准确率保证；真实样本需检查人名、数字、否定、术语及混合语言。
- 历史产物在数据库保留；当前 UI 每种语言展示近期任务中最新一份，不是完整历史版本管理器。当前列表最多 30 项。
- 下载副本由用户控制，撤权/删除不会收回已下载的文件。旧原文变更后的导出采用 409，避免冒充当前译文。
- 首批复用 backend 中既有 Qwen 文本模型与用量记账；不会占用 Egress 编码资源，但仍占用现有 backend Celery 并发和供应商用量，需上线观察排队时间。

## 发布与验收

需要 **backend + frontend** 新镜像；backend 同时更新 `meet-backend`、`meet-celery-backend` 和 `meet-celery-beat`。迁移 **0187** 必须完成。生产 Helm 设置 `UPLOAD_TRANSCRIPT_TRANSLATION_ENABLED=True`；通用默认 False。无需更新 agents、summary 或部署 Egress。Android 需安装本批新 APK。

发布命令使用本批已构建镜像的固定 tag：

```bash
bash deploy/aliyun/release-meet.sh --tag <本批提交前9位> backend frontend
```

上线验收用专门上传测试记录，先中文原文→英语，再英语原文→中文：核对全段对照、首尾段和原声定位，三个导出格式；修改一段验证旧版提示/拒绝导出，再生成新版；用 13800000008 验证全文分享可读、纪要分享不可读及撤权清理。核对任务只有一次供应商执行，并确认回收/永久删除包含译文。生产发布和真实供应商验收未在本批提前记为通过。
