# 第三十八批：人工纪要导出来源精确导航

## 完成内容

Web 和 Android 信息页的人工纪要导出回执可以打开导出对应的人工历史版本。读取既有 `human-summary/history/{uuid}/` 接口，直接定位不可变版本，不翻页猜测，也不回退到当前人工稿或 AI 稿。

- 显示历史版本、只读说明及正文；提供明确返回普通纪要视图的入口。打开来源不创建导出、不修改纪要、不发送通知。
- 引用使用该版本的 `input_snapshot_id` 与原始片段引用，保留全文权限及媒体回听权限；Web 采集回听继续按会话时钟换算。
- Web 空/重复 human 参数，以及同时指定 human/summary 的歧义链接显示不可用。错误响应清除历史正文；账号、记录、版本隔离查询和引用状态。
- Android 沿用前台可见性轮询与账号校验，退后台清除私有正文；历史详情不可用时不读取当前稿作为替代。Docs 文档仍有独立权限，导出副本不与源版本同步。

## 验证与发布

- Web 45 个不同用例通过：导出链接、历史正文/引用、撤权、账号切换、空参数/歧义路由和记录工作区；TypeScript 构建、触及文件 ESLint 通过。
- Android 8 项仓库单元、21 项 Pixel 8 仪器测试和设计检查通过，包含实际 Compose 入口和只读历史读取、引用、退后台后撤权。
- 既有后端人工纪要服务 8 项回归通过，覆盖历史分页、精确记录归属、只读及撤权。无后端运行改动或迁移。
- Android `4934a960` 已提交推送；本批需 frontend 发布和新版 App 分发。结合第 37 批，应发布 backend/frontend；summary/agents 无需变更。

本批没有生产写入，生产 App/API 导出旧人工版本对照尚待验收。下一批进入记录回收站，须同时覆盖旧采集入口、媒体签名、共享与异步任务，不能只从列表隐藏记录。
