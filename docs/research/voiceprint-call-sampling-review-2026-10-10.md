# 通话采样许可基础与代码走查

日期：2026-10-10（Asia/Shanghai）。分支：`feature/speaker-identity-voiceprint`。

后续已接通 sampler、派发、加密候选入库和通话单人质检，当前状态以[采样管线走查](voiceprint-call-pipeline-review-2026-10-10.md)为准。本篇保留许可基础阶段的范围与验证证据。

本阶段接通后端的可信麦克风来源、本人连接级声明与短期采样许可。默认关闭，不接收 PCM，不订阅音轨，不派发采样 agent，不调用云端 ASR，也不将通话样本加入模板。完整方案的通话采集和上线验收仍未完成。模型路线继续 Qwen 优先；没有新增转用 CAM++ 的决定。

## 已实现的边界

- LiveKit 原有 webhook 接收器先验证签名与正文 SHA-256，再记录房间实例、参与者连接与麦克风轨道。仅 `STANDARD`、非设备的有效账号可以申请，身份按 `User.sub` 映射，而非显示名或数据库用户 UUID。未知轨道、访客、agent、屏幕音频、视频以及已结束的连接均拒绝。
- 本人接口 `GET/PATCH /api/v1.0/voiceprint/sampling-control/` 只允许操作自己的连接；更新要求当前 revision，布尔值严格校验。未知／共享麦克风默认排除，个人设备分组必须显式声明。这里的设备分组只是本人声明，不代表已验证实际硬件；`ready` 表示具备申请资格，不代表正在录音。
- 私有接口 `POST /api/agent/voiceprint-sampling/permits/` 与 `POST .../<id>/validate/` 使用独立 `X-Voiceprint-Agent-Token`，不能使用普通登录态或现有 ASR agent 的共享凭证替代。请求不能指定 owner、组织、音频或质量结果。回执和错误均标为 `private, no-store`。
- 许可有效期 30 秒，绑定用户、组织、档案、授权版本／generation、组织策略版本、控制 revision、房间 SID、会议实例 UUID、参与者 SID／identity、轨道 SID 和设备声明。独立 HKDF 用途密钥签发 HMAC 令牌；验证会重新读取身份、权限、组织成员关系、来源与控制状态。
- 每段预算 3–10 秒，每用户单个会议实例最多 60 秒，滚动 24 小时最多 120 秒；跨组织、重连、不同设备共同计数。按用户行锁串行计算。同一轨道的 request key 幂等；失效或取消的许可仍计入预算，删除来源或声纹档案不会退款。
- 轨道取消发布会关闭许可；乱序到达的发布事件不能重新打开来源，轨道 SID 不能迁移到另一参与者。声明改变、暂停、撤权、退会、策略改变、停用账户及 generation 失效均阻断旧许可。
- 通话样本只有关联已消费且唯一链接的可信许可回执，才能通过已有样本读取／确认授权检查；仅修改 `source_type` 或提供许可 UUID 不足以证明来源。当前尚无消费许可或提交音频的接口，因此不会产生可确认的真实通话样本。以后合法完成采集的样本可在普通暂停／会议结束后继续审核，仍须当前积累授权及单独的登记确认授权。
- 撤销立即取消旧版本许可；声纹删除清理会移除许可中的参与者、房间、轨道和设备来源标识及来源链接，保留用户、会议实例 UUID、时间、时长等最小配额记录，防止删除后重新申请绕过上限。

## 本轮复现与修复

1. 许可无法签发：令牌使用 `call-permit` 上下文，但加密用途白名单未支持该值。补齐用途并通过加密回归。
2. 重连后旧许可可能跟随来源行中的新连接信息：签发时未冻结参与者与房间 SID。增加不可由 API 修改的签发快照，并在验证和样本来源复验时核对。
3. 非 ASCII 令牌传入 `hmac.compare_digest` 会抛出异常：接口限制 URL-safe ASCII，服务额外检查类型、长度与字符范围，返回受控拒绝。
4. 旧许可状态与删除清理遗漏：授权版本变化时立即取消，物理清理时擦除来源标识，但保留已预留预算。
5. 跨组织配额测试曾在已耗尽单会话配额的连接上断言，不能证明全局上限。改用第三组织的新会话，并增加并发抢占最后一段日配额的真实 PostgreSQL 测试。
6. 登记确认 API 的旧通话测试只改写登记样本类型，未提供来源回执。改为内部合成的已消费许可夹具，保留“积累授权不能单独授予确认权”的断言；伪造来源仍拒绝。
