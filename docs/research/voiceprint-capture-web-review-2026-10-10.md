# AI 录音分人与身份识别 Web 代码走查

日期：2026-10-10（Asia/Shanghai）。分支：`feature/speaker-identity-voiceprint`；本轮基线：`59f6d2de8`。

本轮接通并走查 AI 录音的 Web 分人操作、派生版本阅读、身份识别入口和区间试听，复用已完成的候选选择／建议人工确认流程。后端仅增加供界面读取的当前成功派生版本投影；没有数据库迁移、生产发布、真人录音或云端模型调用。模型路线仍为 Qwen 优先，未满足要求后再考虑 CAM++。

## 发现的问题与修复

| 问题 | 修复及验证 |
|---|---|
| 录音页面没有分人操作入口，付费请求失联后无法可靠恢复 | 显式费用确认后才提交；先持久化 nonce 与原始 revision，再发送请求。未知结果由用户恢复同一请求，不自动重复提交；回执必须匹配 nonce 和 capture scope，再验证任务版本并清除本地意图。读取和取消在创建开关关闭后仍可用 |
| 原文查询未固定派生版本，版本更新可能混用旧分页游标 | 每次原文查询同时绑定 ASR 与派生 job ID，版本改变时更换查询和阅读组件；编辑中暂时保留旧阅读版本及草稿，保存／取消后切换，禁止编辑中发起新的付费分人请求 |
| 录音身份识别入口缺少当前成功分人版本门禁 | ASR 状态和录音状态共用小型元数据查询：当前 ASR 成功、派生任务成功且完成发布、至少一条派生原文。只读取 ID，不读取大体积 `inputs` 证明。入口按该指针开放，派生版本改变后清除旧候选和试听状态 |
| 身份试听只支持导入媒体，录音播放器可能继续播到其他说话人的区间 | 实录按来源调用对应播放器。录音试听限 10 秒、须为连续音频区间，下载前拒绝时间缺口；源时钟边界、播放速率调整与 30 秒总时限共同约束，结束后清除 Blob。关闭未使用的身份识别面板不会中断普通回放 |
| 登录切换或私有状态读取失败可能留下旧状态／音频 | 新分人客户端固定拥有者和登录会话；晚到结果不可写回，账号切换中止请求、清除待恢复意图和私有状态；播放器同步清除播放数据，授权检查失败后禁止继续读取 |
| 新增中文／法语／德语文案有编码损坏，分人成功后仍显示旧的“不区分说话人”提示 | 用 UTF-8 修正文本，补充与派生版本一致的试听／身份确认提示及未知说话人标签；五种语言结构一致，并检查中文浏览器截图 |

人工身份确认、通讯录选择、自定义标签仍通过既有流程完成；新派生版本不自动继承实名确认，也不自动登记声纹。
