# 第五批：播放能力与上传改名

日期：2026-09-20。

`play_media` 改为真实能力：上传文件要求当前属主、原文访问权和保留的媒体；独立采集还要求唯一且已停止的采集、已封存的 saved/incomplete 清单和实际存储的音频分片。列表批量预取判定元数据，避免逐记录额外读取。

Web 和 Android 都按该能力展示播放器、原文时间戳及纪要回听入口。Android 读取签名地址前后再次校验播放能力。文字访问权仍不隐含媒体访问权；没有扩展原媒体下载或分享权限。

上传记录的属主可以改名；改名继续使用 `expected_title` 防止覆盖并发修改，不改变原文版本。Android 接受上传来源的改名响应。

验证：后端播放能力、上传媒体、改名、资料库及记录访问共 45 项通过；Web 页壳和改名控件 18 项通过，TypeScript/ESLint 通过；Android Repository / Media 共 31 项单元测试通过。

发布顺序：先部署后端，再更新客户端。客户端缺少 `play_media` 时默认拒绝，不能依赖旧服务端的恒 false 返回值提供播放入口。
