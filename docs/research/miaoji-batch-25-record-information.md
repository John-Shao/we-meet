# 第二十五批：记录信息与个人纪要文档导航

本批补齐 G6 中可直接复用现有契约的部分：所有者、创建时间、已导出文档和 AI 来源版本导航。批量校对、个人热词、发言时间分布仍独立排期，不把本批记作 G5–G8 全部完成。

## 变更

- Web/Android 记录信息页展示所有者和创建时间。创建时间使用 `created_at`，与已有来源开始时间 `origin_at` 分开；旧后端未给出创建时间时显示未知，不拿来源时间冒充。Android DTO 增加可选字段，兼容既有记录。
- 信息页增加“我的纪要文档”，直接复用已有 document-exports 读取接口，显示当前用户最近 10 次导出的类型、时间、语言和处理状态。准确说明这是个人导出范围，不声称列出全体参与者的文档或所有历史导出。
- 仅当 `status=ready`、`can_open=true` 且有文档 ID 时提供 Docs 入口。即使当前不再允许创建新导出，已有可打开的文档仍能导航。读取信息页不会自动创建、重试导出，也不发送通知。
- AI 导出可回到准确的 `source_id` 纪要版本：Web 使用现有版本路由，Android 切换到该版本并清除上一次引用/管理面板。文档仍是独立副本，没有建立双向内容同步或共享权限继承。
- 无 `read_summary` 时不请求导出接口；账号进入缓存键，刷新错误不显示缓存链接。Android 沿用前后台复核并清除旧内容，信息页整体可滚动，避免增加条目后底部操作不可达。

## 验证

- Web：信息页/导出导航/既有导出控制共 38 项通过。新增覆盖只读全文身份不读文档、无创建行为、精确 AI 版本路由、不可打开状态、账号切换、撤权刷新后移除缓存链接。
- TypeScript、修改文件 ESLint、120 个 JSON 解析、五种 Web 语言结构及占位符检查通过。Web 五种语言和 Android 中英文均补齐文案。
- Android：Pixel 8 / Android 16 上 `RecordExportsTest` 共 9 项通过，含原有导出行为及新增信息页读取、文档/版本回调、无纪要权限不读取、撤权清理。为取得布局截图单独复跑信息页用例通过（不重复计入测试总数），人工检查信息行、文档状态与两个导航按钮无遮挡。提交设计 token 检查通过。
- 测试使用受控夹具；本批没有写入生产记录、导出生产 Docs、修改共享权限或调用 ASR。不能将模拟器导航回调断言说成实际生产 Docs 全链路已经验收。

## 发布与剩余边界

Android `98a20dba` 已推送，debug APK 已安装到模拟器；正式分发待完成。Web 需要发布 **frontend**。本批没有 backend、summary、agents 或数据库迁移变更；生产仍以第二十四批确认的 `66b3e3bb3` 为准。

部署后验证：真实信息页所有者与创建时间；已有个人 Docs 打开及文档独立权限；AI 导出返回旧版本；仅全文分享身份无文档入口。Web 实际页面和物理 Android 仍待验收。

G6 剩余：可靠的媒体总时长及多来源处理信息、超过 10 次导出的历史导航、人工纪要历史版本直接定位。不能用最后一条转写结束时间代替媒体总时长，也不能把识别发言人当参会者。G5 批量校对/可复用热词是后续复核效率批重点。用户延后的大文件恢复与长原文跨页保持延期。
