# ADR 0014：能力版本冻结，授权实时收窄

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A07
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

固定版本保证可复现和审计，但不能把旧快照当作永久授权；撤权必须立即阻止新动作。

## 决策

能力、技能、套件和模型路由固定到快照版本；每次动作仍按当前席位、策略、连接器 grant 与目录许可收窄。

## 备选与取舍

运行中的 Run 可能因权限收窄暂停/失败；历史结果保留但访问需重新校验；快照不能绕过安全撤回。

## 证据与关闭条件

架构 §8.1–§8.2、§11.4；DDL capability_snapshot。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
