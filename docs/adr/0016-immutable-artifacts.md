# ADR 0016：成果版本不可覆盖，正文与元数据分开

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A09
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

覆盖文件会破坏来源、采纳、删除和不同驻留位置的语义；元数据与正文混存会扩大备份和权限边界。

## 决策

每次保存/发布产生不可变 ArtifactVersion；正文进入版本化 Content Store，元数据、来源、授权和采纳独立记录。

## 备选与取舍

需要 staging/finalize、对象版本和孤儿回收；local-only 版本只保存设备 receipt 与引用，服务端不声称已扫描正文。

## 证据与关闭条件

架构 §13.1–§13.3；DDL artifact/version/tombstone。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
