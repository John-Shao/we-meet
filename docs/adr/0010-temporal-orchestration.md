# ADR 0010：Temporal 管持久编排，领域命令决定业务状态

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A03
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

审批等待、设备断线、跨小时任务需要持久恢复；单纯队列或长连接不能提供可审计的等待/恢复语义。

## 决策

Temporal 保存等待点、定时器、重试与重放历史；所有业务状态仍通过 Work 领域命令写 PostgreSQL。

## 备选与取舍

增加 Temporal 运维和历史存储成本；禁止 Temporal history 承载正文；工作流不能绕过领域状态和账本。

## 证据与关闭条件

架构 §3.1、§7.1–§7.4、§21.2 S1。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
