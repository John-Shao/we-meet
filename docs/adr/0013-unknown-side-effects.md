# ADR 0013：不承诺外部副作用 exactly-once，unknown 必须核对

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A06
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

网络提交与发包无法原子化，供应商幂等能力不一致；声称 exactly-once 会在超时/崩溃时重复收费或重复写入。

## 决策

内部提交/派发可幂等；外部动作只承诺至多一次许可和可核对回执，断线后进入 unknown，禁止盲重试。

## 备选与取舍

需要运营/对账和人工处置能力；unknown 会暂时阻塞新 Run/采纳；系统可用性让位于账本正确性。

## 证据与关闭条件

架构 §6.2、§7.4、§11.3、§21.1 F04/F21；H04/H12。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
