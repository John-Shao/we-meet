# ADR 0018：R1 单 Run 提示组合，R3 才启用确定性 DAG

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A11
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

提前暴露工作流编辑器会让模型/产品把编排复杂性推给用户；R1 不需要 Step 级预算、审批和恢复。

## 决策

R1 只做一次 Run 内的提示/技能组合；R3 才引入不可变 PlanVersion、Step 状态机、schema 和有限 DAG。

## 备选与取舍

R3 需要计划编译器、Step Operation/预算/审批和复用输出校验；R1 不能把技能偷偷映射为隐藏工作流。

## 证据与关闭条件

架构 §8.4–§8.5；DDL plan_version/plan_step（待扩展）。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
