# ADR 0008：模块化控制平面，不按表拆微服务

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A01
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

提交、审批、预算和采纳需要跨模块强一致。按每张表拆服务会引入分布式事务、重复授权和新的旁路，而不是提高安全性。

## 决策

控制面以领域模块组织，提交、授权、预算、成果等共享同一事务边界；只有安全域或真实负载瓶颈才拆进程/服务。

## 备选与取舍

初期共享数据库与模块接口，独立扩缩容较晚；代价是必须维护模块边界、事务组合和查询投影纪律。

## 证据与关闭条件

架构 §0.1 A01、§2.2、§20.2。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
