# ADR 0015：本机目录授权不等于 OS 沙箱

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A08
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

用户选择目录不代表 Runtime 可信；路径字符串检查可被 symlink/reparse point/子进程绕过，H06/S2 已证明单层防护不足。

## 决策

本机只提供类型化文件工具；目录 grant 是资源范围，不是隔离证明；任意 Shell/脚本必须另有 OS 隔离条件。

## 备选与取舍

R0b 工具能力受限；需要 Rust Broker、句柄级路径约束、AppContainer/VM/Job 组合；无法满足隔离就不开放工具。

## 证据与关闭条件

架构 §10.1–§10.2；H06、S2；ADR-0007。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
