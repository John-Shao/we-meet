# ADR 0012：所有模型与工具动作经受控代理

> 状态：Proposed（目标架构提案，待架构评审签收）
>
> 日期：2026-10-25
>
> 决策编号：A05
>
> 决策范围：目标架构；不证明当前仓库已实现，也不替代真实用户/生产验证。
>
> 关联：[Work 系统架构](../plan/work-system-architecture-2026-10-25.md)

## 背景

模型输出和提示注入不可信；把工具、凭据和网络直接交给 Runtime 会绕过审批与租户边界。

## 决策

Runtime 只提出 ModelCall/ToolCall；策略、审批、预算、凭据注入和审计在模型之外的 Gateway/Broker 强制执行。

## 备选与取舍

增加一跳延迟和网关运维；Runtime 不持有长期供应商 Key；网关必须按 Operation 记账并拒绝未知目标。

## 证据与关闭条件

架构 §9.1、§11.3、§12；契约 egress proto。状态保持 Proposed，待架构评审、对应验证闸门和风险登记签收后转为 Accepted；不得仅因文档存在而宣称生产就绪。
