# 阶段 3 第三十三批（累计第 53 批）：共享同传 Web 协议边界

本批补齐 Web 收听所需的订阅身份和租期字段，并提供前端事件校验与有限译文列表。

- 订阅查询和续期结果增加真实订阅 ID，以及服务端计算的剩余秒数；失效或撤销的订阅返回零。客户端以请求发出时的单调时钟计算保守截止时间，不使用客户端日期推测服务器租期，也不把响应延迟算作额外授权。
- 译文必须同时匹配频道、代次、目标语言、订阅 ID 和修订号，来自频道对应的 Agent；验证发言人参与 ID/SID、音频轨道 SID、response/item 标识，拒绝非法 UTF-8、超大包和非翻译事件。
- 各发言人独立去重，确认译文不能被较早的候选文本覆盖。前端只保留最近 60 条，不写入正式逐字稿。

验证：5 项前端协议测试、28 项频道与 Worker 后端测试通过，TypeScript、ESLint、Ruff 和差异检查通过。没有数据库迁移，没有真实会议、模型或消息发送。下一批接通实际收听生命周期和会议内界面；频道开关仍默认关闭。
