# 阶段 3 第三十五批（累计第 55 批）：确认译文关联会议笔记

新增独立译文档案与确认片段表，不复用或改写正式逐字稿。此批完成共享频道的后端契约，Agent 投递与 Web 保存/阅读入口随后接入。

- 开启频道时可以明确传入 `save_translations: true`。只有记录及译文留存开关都启用才接受；在同一事务内绑定准确会议场次的笔记，重用该场次唯一的记录，不根据标题或“最近会议”猜测来源。默认不留存。
- 每个档案冻结频道 ID、代次、所有者、记录及配置。确认片段以发言人参与记录、方向和供应商 response/item ID 幂等保存；重试相同内容返回原回执，不同内容不能覆盖。并发操作共用一条序号和字节计数。
- 内部写入口要求专用 Agent 鉴权、认领 Worker、会议/SID/代次一致，以及当前频道和组织权限。只接收标准参与者的确认译文；允许正常停止的限时尾段，不接收候选文本、旧 Worker 或结束后的新片段。
- 单档案最多 20,000 个片段、8 MiB 文本；超限不部分落库。译文写入不更新正式原文或其修订号。精确重试只返回无正文回执，不重新写入，即使功能已关闭或执行已结束。
- 查询在分页前后检查当前原文阅读权限，仅参会或仅能阅读纪要均不够。档案每页 30 项、片段每页 50 项，序号稳定；未来私人档案按所有者进一步过滤。当前共享频道不会因为收听而创建资料权限。
- 片段明确标记时间为 `delivery`，原文引用为 null。供应商目前未提供可验证的逐句源音频对应关系，不能把到达时间用于精确回听或冒充正式原文引用。
- 档案完成由独立 `archive_finished` 回执确认；供应商/本地音频完成不等于留存完成。Worker 超时、缺少档案回执或删除运行中的频道均标记档案不完整，已保存译文仍保留于原笔记。

验证：20 项新增后端测试及 28 项频道/Worker 回归通过，新增项包括并发去重、分页、权限撤销、超限、尾段和源频道删除。Ruff、迁移一致性及差异检查通过。迁移 `0172_translation_archives` 已在隔离普通库和测试库应用，仅新增两张表，没有变更录音转写表。

新增开关 `MEETING_TRANSLATION_ARCHIVE_ENABLED` 默认关闭。待下一批 Agent/Web 完成后，部署迁移与兼容版本再开启。未真实录音、调用模型、发送消息或部署生产。T04 的私人/独立录音适配及完整首版仍未完成。
