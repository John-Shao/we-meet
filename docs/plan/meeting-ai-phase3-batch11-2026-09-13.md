# 阶段 3 第十一批（累计第三十一批）：Web 转写控制与逐字稿

已保存录音可手动转写、取消和重新转写；缺片录音需要勾选接受不完整来源。状态区显示等待／执行／完成／未完成／取消，按已发送音频片数报告进度，不将传输比例当成识别准确率。

- 创建意图先写入按账号／录音隔离的 sessionStorage，再请求后端。未知响应使用同一个幂等键；刷新页面后可确认上次请求。离开或切换身份取消前端请求，后台状态可再次查询。
- 当前成功逐字稿按已发布任务 ID 固定分页，重新转写期间保留上一版；后端不允许借版本查询读取失败／未发布文字。点击时间点回听受保护音频，仍遵守缺片暂停和当前权限检查。
- 状态访问失败时隐藏已缓存文字，原文请求失败支持刷新。历史列表显示最近十个版本状态；完整历史原文工作区另行连接。

验证：前端转写／播放器 9 项测试、后端转写与记录权限 37 项通过；应用 TypeScript、ESLint、生产构建通过（6,180 模块，保留原有 SVG 路径及大分包提示）。原生 Chromium 使用合成麦克风和 HTTP 测试替身，验证开始／暂停／刷新／保存、转写创建、逐字稿和回听定位；截图人工检查通过。未做真实供应商与物理设备联调。

下一批连接独立逐字稿到已有 Qwen 纪要版本、引用、人工修订和问答链路。独立录音仍是保存后转写，实时独立转写／实时总结尚未交付。
