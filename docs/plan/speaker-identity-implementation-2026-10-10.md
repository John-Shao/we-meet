## Qwen 编码器基础与调用边界走查（2026-10-10）

新增独立 `src/voiceprint` 服务：审核过的源码子集、完整权重哈希校验和离线提取、固定特征空间、CPU float32 推理、严格 WAV 边界、带 payload／模型／任务／到期时间的短期许可，以及纯传输的后端客户端。已实际加载 Qwen 固定 encoder，并通过本地真实 HTTP 完成后端客户端至实际编码器的联通。详情与复现命令见[服务说明](../../src/voiceprint/README.md)。

| 走查问题 | 修复与回归 |
|---|---|
| 请求体读取期间许可可能过期，仍会开始推理 | 读取后再次验证许可，过期不运行模型；输出前再验证一次 |
| 慢速正文可能在单次 socket 超时以内持续传输，延长任务占用 | 后端按可用字节读取，每次检查 30 秒正文期限及租约；连接／空闲读取超时 3 秒，拒绝压缩响应和超过 64 KB 的 JSON |
| 大量合法但缓慢的上传没有总量边界 | 同进程最多两份正在读取的正文，10 秒超时；取消和失败均释放上传容量 |
| HTTP 调用取消后，底层推理线程仍在运行，可能提前释放预算 | 保持线程任务引用，直到实际完成才释放；繁忙返回 503，健康接口仍可响应 |
| 非 ASCII／控制字符令牌、空 CA 设置或异常 URL 端口可能延迟报错或削弱 TLS 配置 | 在构造时拒绝；后端禁止非回环明文 HTTP、代理和重定向；服务端非回环监听要求 TLS，最低 TLS 1.2 |
| 巨大整数、非有限向量、浮点维度或深层 JSON／JWT 可能绕过类型校验或触发非预期异常 | 严格验证模型元数据类型、向量维度／范围／单位范数、质量契约，解析异常仅返回固定错误码 |
| 畸形 WAV 的超大 RIFF 子块使标准库抛出 `RuntimeError`，可能导致 500 | 将解析边界异常统一为 `wav_invalid`／422；回归先复现两个失败，修复后不触发推理 |

验证：独立服务 61 项测试全部通过（含实际权重测试，无跳过）；后端客户端 45 项回归通过；修改文件 Ruff 检查与格式检查通过。实际权重包两次提取所得 SHA-256 一致。wheel 打包成功，确认保留 Qwen 许可、修改说明及固定源码，不含模型权重和测试。依赖一致性检查通过；权重、录音和凭证不入库。

编码器基础提交时尚无业务 API 或 worker 调用此客户端。后续本人授权与撤销基础的进度见下节；加密登记／模板、任务租约／generation 提交复核、语音与单人质量分析、多人实名建议和跨端业务界面仍待实现，客户端的许可和缓存不能替代这些保护。HTTP 响应头慢速传输及卡住的原生推理还需后续独立 worker 的硬期限和进程回收兜底。暂无获授权真人样本，不能据此判定 Qwen 满足身份识别要求，也不触发 CAM++ 替换。

## 本人授权、加密和撤销基础（2026-10-10）

新增 `VoiceprintConsent/Event`、`VoiceprintProfile/Sample/Template` 和持久 `VoiceprintDeletionJob`，迁移 `0201`／`0202`。三类权限互相独立，组织功能和本人授权均默认关闭；管理员只能变更自己有管理权限的目标组织开关，不能写别人的权限。主动登记档案目前是内部服务，尚无上传／采样或可执行识别任务。

已接通本人设置 GET/PATCH、本人档案删除、删除任务读取及组织管理员开关 API。读取不创建授权；严格输入类型和预期版本保护写入，个人范围／每个组织使用独立档案密钥，设置响应不返回音频、向量或密文。功能暂停或离开组织后，本人已有数据仍可撤销／删除，不能再次授权该失效组织。

加密采用 AES-GCM：每个档案独立随机数据密钥，再由单独挂载的可轮换 keyring 包装；owner、组织、profile、generation、模型、用途及对象 ID 进入附加认证数据。没有 Django secret 回退，错作用域／模型／世代／对象或篡改密文均不能解密。该文件 keyring 是开发实现，不代表生产 KMS 已部署或备份可即时物理擦除。

删除先推进授权版本和 generation、清除旧档案的包装密钥，再排队物理清理；新登记生成新密钥，旧清理只删除较早世代。注销、最后一条有效组织关系丢失及级联删除都有撤销／墓碑保护；批量变更可由 `reconcile_voiceprints` 巡检，授权检查在巡检前即拒绝无效账号／成员。当前可信墓碑的最低 generation 会阻止旧备份行重新成为可用模板。

物理清理 `purge_voiceprints` 有界执行、最多三次失败重试，保留脱敏回执；`expire_voiceprint_samples` 清除到期待确认数据与短期试听音频，已确认且仍有效的特征继续保留。尚未把这些命令接入生产调度，也没有对生产备份和外部墓碑源进行恢复实测。

验证：新增授权／加密／清理 75 项测试、Qwen 客户端 45 项回归，加上接入生命周期信号后的账号、离职、人工身份和个人热词既有 74 项回归，共 194 项通过。覆盖第一次并发写入、DB 唯一约束、旧版本拒绝、重新登记与旧清理、级联删除、批量停用、TTL、跨组织密文交换、密钥轮换读取及清理失败上限。Ruff、迁移漂移检查、空测试库完整迁移、直接依赖／lock 元数据一致性检查通过。

本次授权基础走查先复现 17 项失败并修复：模板只有单个合格贡献就被视为可识别，未检查维度、有效语音时长、重复音频、缺失特征及混入无效贡献；组织配置版本损坏时仍可能开启；巡检扫描与加锁之间账号／授权被删除会中断整批处理。模板门禁现要求固定 Qwen 空间／1024 维、最多 5 个设备组、每组全部贡献当前且经确认／质量检查，至少 3 个不同片段及 30 秒有效语音。组织坏配置拒绝启用，巡检跳过并发删除项；相关回归已包含在上述 194 项中。

本轮测试使用合成数据与随机测试密钥，不采集真人声音。登记上传／随机提示语、本人试听确认、语音与单人质量、任务 worker 与硬期限、模板生成和匹配、通话采样、来源删除贡献重建、Web／Android 设置、Helm／密钥管理和可信恢复规程继续待完成。完整功能仍以本文件表格及原方案逐项验收。
