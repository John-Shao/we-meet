## Qwen 编码器基础与调用边界走查（2026-10-10）

新增独立 `src/voiceprint` 服务：审核过的源码子集、完整权重哈希校验和离线提取、固定特征空间、CPU float32 推理、严格 WAV 边界、带 payload／模型／任务／到期时间的短期许可，以及纯传输的后端客户端。已实际加载 Qwen 固定 encoder，并通过本地真实 HTTP 完成后端客户端至实际编码器的联通。详情与复现命令见[服务说明](../../src/voiceprint/README.md)。

| 走查问题 | 修复与回归 |
|---|---|
| 请求体读取期间许可可能过期，仍会开始推理 | 读取后再次验证许可，过期不运行模型；输出前再验证一次 |
| 慢速正文可能在单次 socket 超时以内持续传输，延长任务占用 | 后端按可用字节读取，每次检查 30 秒正文期限及租约；连接／空闲读取超时 3 秒，拒绝压缩响应和超过 64 KB 的 JSON |
| 大量合法但缓慢的上传没有总量边界 | 同进程最多两份正在读取的正文，10 秒超时；取消和失败均释放上传容量 |
| HTTP 调用取消后，底层推理线程仍在运行，可能提前释放预算 | 保持线程任务引用，直到实际完成才释放；繁忙返回 503，健康接口仍可响应 |
| 非 ASCII／控制字符令牌、空 CA 设置或异常 URL 端口可能延迟报错或削弱 TLS 配置 | 在构造时拒绝；后端禁止非回环明文 HTTP、代理和重定向；服务端非回环监听要求 TLS，最低 TLS 1.2 |
| 巨大整数、非有限向量、浮点维度或深层 JSON／JWT 可能绕过类型校验或触发非预期异常 | 严格验证模型元数据类型、向量维度／范围／单位范数、质量契约，解析异常仅返回固定错误码 |
| 畸形 WAV 的超大 RIFF 子块使标准库抛出 `RuntimeError`，可能导致 500 | 将解析边界异常统一为 `wav_invalid`／422；回归先复现两个失败，修复后不触发推理 |

验证：独立服务 61 项测试全部通过（含实际权重测试，无跳过）；后端客户端 45 项回归通过；修改文件 Ruff 检查与格式检查通过。实际权重包两次提取所得 SHA-256 一致。wheel 打包成功，确认保留 Qwen 许可、修改说明及固定源码，不含模型权重和测试。依赖一致性检查通过；权重、录音和凭证不入库。

当前没有业务 API 或 worker 调用此客户端。本人授权、加密登记／模板、撤销删除、任务租约／generation 提交复核、语音与单人质量分析、多人实名建议和跨端业务界面仍待实现；客户端的许可和缓存不能替代这些保护。HTTP 响应头慢速传输及卡住的原生推理还需后续独立 worker 的硬期限和进程回收兜底。暂无获授权真人样本，不能据此判定 Qwen 满足身份识别要求，也不触发 CAM++ 替换。
