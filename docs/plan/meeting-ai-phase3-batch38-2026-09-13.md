私人翻译 Agent 与 Web 已接入第 57 批契约。开始前可选择保存，私人同传和双向按住说话共用有界投递队列；默认不保存，关闭面板不改变当前运行的选择。

- Agent 保存确认译文，候选文本与权限撤销后的新输出不进入队列。正反方向分别生成哈希和核验回执，使用固定私人运行与 Worker 身份，不能误认共享频道回执。
