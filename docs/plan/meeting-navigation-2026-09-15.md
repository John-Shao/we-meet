# 会议模块导航调整（2026-09-15）

## 页面结构

- 视频会议：快速会议、加入会议、预约会议，以及预约列表和历史视频会议。
- AI 录音：原生录音工作区；点击开始录音才申请麦克风权限并开始采集，保留恢复、待保存和上传重试流程。
- 会议实录：音视频及文字记录的资料库，继续支持来源、归属筛选和搜索。
- 智能纪要：有纪要的实录列表。

## App

会议页左上角菜单打开抽屉，沿用云文档和任务的全屏遮罩、宽度限制和返回关闭行为。切换栏目后关闭抽屉，底部导航仍选中会议。首次默认视频会议，后续按账号保存上次栏目；历史栏目不可用时回退视频会议。

视频会议首页不再混入独立录音，也不再请求录音分页；已保存录音可从会议实录查看。消息、日历和历史详情的原有导航回调保留。消息卡片的实录详情路由及纪要版本参数不变，返回仍回到原消息页面。

录音页绑定已有前台服务读取状态，栏目切换不会调用开始或停止采集；正在录音的前台服务继续运行。详情页仍使用返回按钮，四个栏目根页使用菜单按钮。

## Web

会议常驻侧栏统一为相同的四个栏目，保留开关控制和会议设置。快速、加入、预约位于视频会议主区。页面 URL、API、资源 ID 不变。

- Android：模拟器运行导航与录音界面 10 项测试通过，覆盖栏目选择、不可用栏目回退、菜单操作不触发录音及既有录音操作。

部署后验证：切换四个栏目、退出再进入会议、系统返回关闭抽屉；开始录音后切换栏目再返回；从消息卡片打开实录并返回聊天；快速会议、加入会议和预约会议正常进入原流程。
