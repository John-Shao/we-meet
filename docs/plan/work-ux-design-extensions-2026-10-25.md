## 0. 交付摘要

扩展 UX 解决一个问题：**用户如何在提交任务前，看懂“这次会用哪些方法、读哪些数据、产出什么”，并且不会被未实现的能力误导。**

| 交付 | 内容 |
|---|---|
| 入口 | Composer 的 `＋` 菜单（套件/技能/文件夹）、连接器独立入口、快捷命令；能力库；任务摘要 |
| 组合 | 一个主套件、套件内技能、最多 3 个补充技能、必需/可选连接器、环境校验 |
| 授权 | 连接器只读 scope、OAuth/账号连接、任务级 scope、撤销、数据披露 |
| 状态 | 未启用/未授权/过期/组织禁用/环境不支持/超限/冲突/缺连接器/无链式 |
| 阶段 | R1 套件模板单 run；R2a 只读连接器；R3 项目/链式预览；R5c 伙伴不在本设计 |
| 原型 | 可点击中保真，覆盖组合、授权、错误和任务摘要 |

**不在本设计内**：写入连接器、MCP/STDIO、浏览器接管、开放市场、原始 `SKILL.md` 展示、R5c 工作伙伴的完整界面。

## 1. 阶段与边界

| 阶段 | 能力 | 用户可见 | 不可见/不承诺 |
|---|---|---|---|
| R1 | 技能、套件模板、快捷命令、输出标准 | Composer `＋` 菜单中的套件/技能；套件详情；`/` 快捷命令；能力库套件/技能 | 链式、连接器、富成果 |
| R2a | 只读 SaaS 连接器 | 连接器 chip、目录、授权、任务 scope、数据披露、撤销 | 写入、MCP、本机连接器 |
| R3 | 项目上下文、确定性编排、schema | 项目 chip、brief/flow、链式计划、步骤确认 | 富成果/工作台 |
| R5c | 工作伙伴 | 角色卡、默认能力 | 长期记忆、主页、自动化 |
| 后续 | 写入连接器、MCP、市场 | 另行设计 | 本设计不展示 |

关键边界：

- R1 套件是**单次运行内的提示组合**，不是多 run、不是步骤级审批、不是 schema 传递。
- R1 对外叫“套件模板/工作方案”，不叫“完整专家套件”。
- R2a 只做只读；写入风险不进入本设计。
- R3 才出现链式/项目上下文；R1/R2a 不显示“链式”入口。
- R5c 伙伴不进入 R1–R3 导航。

## 2. 设计目标

1. 用户能在 30 秒内判断套件是否适合当前任务。
2. 用户能在提交前看到“本次使用”的套件、技能、连接器和数据范围。
3. 缺连接器、环境不兼容、超限、组织禁用时，用户知道原因和下一步。
4. 用户能完成连接器授权并理解“只读、读什么、能撤销”。
5. R1 用户不会误以为套件在自动执行多步链式流程。
6. 管理员能看清能力状态，不需要进入用户任务。

### 2.1 体验指标

| 指标 | 目标 |
|---|---|
| 套件选择正确率 | ≥80% |
| 本次使用理解率 | ≥90% |
| 连接器授权完成率 | ≥70% |
| 缺连接器错误恢复率 | ≥80% |
| R1/R3 能力差异理解率 | ≥80% |
| 严重可用性问题 | 0 个 P0 |

## 3. 心智模型与术语

| 概念 | 用户理解 | 不是什么 |
|---|---|---|
| 套件 | 一套可复用的工作方法：步骤、输出标准、快捷命令 | 不是人设，不是市场商品 |
| 技能 | 方法/步骤包；套件内技能按提示顺序组织 | 不持有外部账号 |
| 快捷命令 | 套件预置的任务入口 `/` | 不是自动提交 |
| 连接器 | 授权范围内的外部数据/工具 | 不是方法，不是权限 |
| 项目 | 跨任务上下文容器（R3） | 不是云盘 |
| 工作伙伴 | 套件 + 短角色指令（R5c） | 不是长期记忆 |
| 安装 | 能力进入目录 | 不等于启用 |
| 启用 | 组织/用户允许使用 | 不等于已授权 |
| 授权 | 连接器账号/scope 已授予 | 不等于本次自动调用 |
| 调用 | 任务明确选择并使用 | 不等于永久放行 |

一句话：

> **套件是方法，技能是步骤，连接器是数据，快捷命令是入口，项目是上下文。**

### 3.1 本地实机参考（2026-10-25）

已直接查看本机安装的千问办公和豆包，用于校准信息架构与交互；细节仍以两份独立调研报告为准。

| 产品观察 | 借鉴 | 不照搬 |
|---|---|---|
| 千问办公左侧“扩展”下分“专家套件 / 技能 / 连接器” | 能力分组清晰；用户知道三类能力分开管理 | 不在主导航一次放三个子项；R1/R2a 用一个“能力”入口 + tabs |
| 千问技能/套件库有“市场 / 已安装”、搜索、分类、热门/最新 | 搜索、分类、已启用/组织目录筛选、卡片元信息 | 不做市场、热度、下载量、官方精选榜单 |
| 套件卡显示技能数、数据连接数、版本、安装状态 | 卡片显示技能数、必需连接器、版本、状态 | 不把角色/行业包作为首版主模型；套件仍按方法组织 |
| 新任务输入 `输入/调用技能`，工具条有“通用/默认权限/模型” | 保留 `/` 快捷命令、权限摘要 | 不暴露模型切换；不把 inline `/`/`@` 作为唯一入口；保留 `＋` 菜单与连接器独立入口 |
| 任务结果可折叠“已使用技能”“已工具调用记录” | 任务摘要 + 可折叠“本次能力与调用记录” | 不展示原始内部日志/思维链 |
| 连接器按系统级/沟通协作/行业分组，含浏览器、计算机控制 | 只读连接器按知识库/项目管理/日历分组 | 不复制浏览器/计算机控制；不做写入连接器 |
| 千问能力页有大 hero、插画、安装量 | 保留能力卡的清晰层级 | 不做营销 hero、插画、人气数字 |
| 豆包把“插件·技能·伙伴”合并为一个入口，用 tabs 切换 | 合并入口 + tabs；伙伴作为后续 tab | R1/R2a 不做伙伴；R5c 再评估 |

借鉴后的调整：

1. 一个“能力”入口，内部 tabs：套件/技能/连接器；二级“全部/已启用”。
2. 能力卡显示版本、技能数、必需连接器、环境、状态，不显示热度和下载量。
3. Composer 用 `＋` 菜单承载套件/技能/文件夹，连接器保留独立入口，同时支持 `/` 快捷命令。
4. 任务摘要增加可折叠的“本次能力与调用记录”，便于复盘。
5. 连接器只做只读分类分组，不出现浏览器/计算机控制/写入入口。

## 4. 信息架构与入口

```text
工作
├── 工作首页
│   └── Composer
│       ├── ＋ 菜单（套件/技能/文件夹）
│       ├── 连接器入口（与 ＋ 同级）
│       ├── 执行器/权限
│       ├── 新建项目（R3）
│       └── / 快捷命令
├── 扩展能力（一级）
│   ├── 套件列表（二级）
│   │   └── 套件详情（三级）
│   ├── 技能列表（二级）
│   │   └── 技能详情（三级）
│   └── 连接器列表（二级）
│       └── 连接器详情/授权（三级）
├── 我的工作
└── 管理后台 > 工作 > 扩展能力（R1/R2a）
```

入口原则：

- **不在主导航放“市场”**；能力库是组织目录，不是开放市场。
- Composer 只展示当前可用/可授权的能力；未启用不显示。
- 套件详情从 Composer 或能力库进入；连接器授权从任务缺省状态或能力库进入。
- 任务创建后，任务工作区只显示“本次使用”摘要，不再展示完整能力库。
- 一级页的 tabs 由服务端 abilities/capabilities 驱动：未开通的类型不渲染，不显示空 tab 或“敬请期待”。
- 管理/创建入口按权限码显示：管理员“管理”，组织作者“创建套件”；普通成员不显示。
- R3 项目 chip 只在项目上下文可用时出现。

路由建议：

| 路由 | 页面 | 层级 | 阶段 |
|---|---|---|---|
| `/work/capabilities` | 扩展能力首页：组织推荐 + tabs + 分类 + 推荐/更多 | 一级 | R1/R2a |
| `/work/capabilities/suites` | 套件列表：搜索、分类、状态筛选 | 二级 | R1 |
| `/work/capabilities/suites/:id` | 套件详情：方法、输出、快捷命令、连接器、版本、示例 | 三级 | R1 |
| `/work/capabilities/suites/new` | 创建套件（组织作者） | 三级 | R1 |
| `/work/capabilities/skills` | 技能列表 | 二级 | R1 |
| `/work/capabilities/skills/:id` | 技能详情：方法、输入/输出、依赖、相关套件 | 三级 | R1 |
| `/work/capabilities/connectors` | 连接器列表 | 二级 | R2a |
| `/work/capabilities/connectors/:id` | 连接器详情/授权入口 | 三级 | R2a |
| `/work/items/:id` | 任务工作区（含本次使用） | — | R0+ |
| `/admin/work/capabilities` | 组织能力管理 | — | R1/R2a |

## 5. 任务内组合

### 5.1 组合规则

| 规则 | 说明 |
|---|---|
| 一个主套件 | 一个任务最多一个套件 |
| 套件内技能 | 由套件定义顺序；不计入“补充技能”上限 |
| 补充技能 | 最多 3 个；不能重复套件内技能 |
| 环境兼容 | 套件/技能环境必须与任务环境一致；不自动切换 |
| 必需连接器 | 缺失时阻止提交；提供“连接”入口 |
| 可选连接器 | 用户可按需选择；不默认授权 |
| 输出标准 | 套件输出标准优先；补充技能不能覆盖 |
| 提示预算 | 组合后的提示不得超执行器上限；超限阻止 |
| 无链式声明 | R1 标注“预设组合，无链式上下文”；R3 才显示链式计划 |

### 5.2 本次使用摘要

摘要必须回答：套件、技能、连接器/数据范围、环境、交付物、权限。

```text
本次使用：云端 · 套件「产品方案」 · 技能「竞品分析」「结构自检」
          · 连接器「知识库」（只读：项目资料） · 交付 Markdown
          · 预设组合，无链式上下文
```

变体：

| 场景 | 摘要 | 动作 |
|---|---|---|
| 无扩展 | 云端 · 不访问本机 · Markdown · 保存到任务 | 正常提交 |
| 只选套件 | 套件「产品方案」 · 5 个技能 · Markdown | 可提交 |
| 套件 + 补充技能 | 套件「产品方案」 · 补充 2 个技能 | 可提交；显示“补充技能” |
| 套件 + 连接器 | 套件「客户周报」 · 连接器「知识库」（只读） | 可提交；显示数据范围 |
| 缺连接器 | 套件「客户周报」需要连接器「知识库」 | 阻止提交；“连接” |
| 环境不兼容 | 套件仅支持本机 | 阻止提交；“切换本机” |
| 超限 | 补充技能最多 3 个 | 阻止添加；说明 |
| R3 链式 | 读取 brief/flow → 输出 schema | 显示计划；非 R1 预览 |

### 5.3 快捷命令

- Composer 输入 `/` 打开命令列表，按套件分组。
- 命令显示：名称、所属套件、输出标准、是否需要连接器。
- 点击只预填任务描述 + 套件，不自动提交。
- 命令不携带隐藏权限；连接器/文件夹仍需显式确认。
- R1 命令是提示模板；R3 才可能触发链式计划。

## 6. 界面规格

### 6.1 Composer 与千问新任务对齐

```text
下午好，JS
今天想完成什么工作？
用 ＋ 添加套件和技能；连接器单独授权；提交前看清本次会用到的能力。

┌──────────────────────────────────────────────────────────────┐
│ 描述任务，输入/调用技能                                      │
│                                                              │
│ [＋] [项目：会员改版 ×] [连接器 1] [执行器：云端 ▾]          │
│ [默认权限 ▾] [/ 命令]                               [发送]    │
└──────────────────────────────────────────────────────────────┘
＋ 菜单：套件 / 技能 / 选择文件夹
＋ 新建项目  R3
本次使用：云端执行器 · 项目「会员改版」 · 套件「产品方案」
          · 技能「竞品分析」 · 连接器「知识库」（只读：项目资料）
          · 权限：默认权限 · 交付 Markdown
```

与千问“新任务”的对齐：

| 千问新任务 | Work 工作首页 | 说明 |
|---|---|---|
| `＋` 工具菜单 | `＋` 工具菜单 | 套件、技能、选择文件夹 |
| 技能、专家套件子菜单 | `＋` 菜单内的套件、技能 | 套件和技能不各占一个 chip；选择状态回显在菜单行与摘要 |
| 连接器 | 独立入口（与 `＋` 同级） | R2a；不放进工具菜单，选择后显示“连接器 N” |
| 选择文件/选择文件夹 | 选择文件夹 | 不重新引入文件上传材料能力 |
| 新建项目 | 新建项目（R3） | R3 预览可见；R1/R2a 不显示 |
| 通用/设计/幻灯片/写作 | 套件/方法 | Work 用套件定义方法，不复制场景类型 |
| 默认权限 | 默认权限 | 默认权限/自动审批/计划批准后；**没有完全访问** |
| 执行位置由权限文案隐含 | 执行器：云端/本机 | Work 显式展示执行器位置；本机需授权文件夹 |
| 模型“标准”、语音 | 不显示 | Work 不暴露模型切换；语音不是当前范围 |
| 推荐场景 chips | 推荐套件 | 按方法/套件组织，不做电商式分类 |

规则：

- 输入框字段用“任务描述”，新建/提交动作围绕“任务”；“工作”只用于产品、页面和活动标题。
- `＋` 菜单收纳套件、技能和选择文件夹；连接器是与 `＋` 同级的独立入口，未开通阶段不渲染。
- 套件/技能不再各占一个 chip；已选套件、技能数和名称回显在 `＋` 菜单行和“本次使用”摘要，`＋` 按钮显示已选状态。
- “新建项目”是输入框下方的独立入口（R3 预览）；R1/R2a 不渲染；项目 chip 显示当前项目。
- 执行器 chip 打开位置菜单：云端/本机；远程设备 R2b 后开放；本机未授权文件夹时不能提交。
- 权限 chip 打开权限菜单：默认权限、自动审批、计划批准后；不提供“完全访问权限”。
- `/` 命令打开快捷命令；与工具菜单分开。
- 未启用能力不显示；组织禁用显示原因和申请路径。
- 扩展摘要与 R0 的“本次使用”合并，不新增第二套信任面板。

### 6.2 套件选择

入口：Composer `＋` 菜单 → 套件。

```text
选择套件
[搜索套件]                    [全部环境 ▾]
┌──────────────────────────────┐ ┌──────────────────────────────┐
│ 产品方案                     │ │ 客户周报                     │
│ 目标 → 背景 → 备选 → 风险    │ │ 来源 → 结论 → 行动项         │
│ 5 个技能 · Markdown · 云端   │ │ 4 个技能 · 需要「知识库」    │
│ [查看方法]                   │ │ [查看方法]                   │
└──────────────────────────────┘ └──────────────────────────────┘
[取消]                                      [使用此套件]
```

套件卡必须显示：

- 名称、一句话产出、技能数量、输出标准、环境；
- 必需连接器（没有则“无”）；
- 版本/作者（详情里展开）；
- 当前状态（可用/缺连接器/组织禁用/环境不兼容）。

### 6.3 套件详情

```text
产品方案 · v2 · 组织发布
产出：一份可评审的产品方案（Markdown）

技能顺序（R1 为提示顺序）：
1 目标澄清 → 2 背景研究 → 3 备选方案 → 4 取舍与风险 → 5 自检

输出标准：背景/目标/三个备选/取舍/风险/待确认
快捷命令：/写方案 /写评审材料
连接器：无
环境：云端
```

规则：

- “查看方法”展示人类可读说明，不展示原始提示词/`SKILL.md`。
- R1 明确标注“提示顺序”；R3 才叫“执行步骤”。
- 版本、作者、适用范围、更新记录可折叠。

### 6.4 技能选择

入口：Composer `＋` 菜单 → 技能。

```text
选择补充技能（最多 3 个）
[竞品分析] [结构自检] [数据核对] [用户访谈]
已选：竞品分析 ×  结构自检 ×        2/3
套件内技能：目标澄清、背景研究、备选方案、取舍与风险、自检
[取消]                                      [应用]
```

规则：

- 套件内技能只读列出，不占补充上限。
- 补充技能最多 3 个；第 4 个禁用并说明。
- 与套件内技能重复时提示“已在套件中”，不重复添加。
- 技能卡显示输出/环境/依赖；点击“详情”查看方法说明。

### 6.5 连接器选择与授权

入口：Composer 工具栏的独立“连接器”入口（与 `＋` 同级）。

```text
连接器
[知识库] 未连接 · 只读项目/文档        [连接]
[项目协作] 已连接 · 只读项目/任务       [选择]
[CRM] 组织已禁用                        [申请]
```

授权弹窗：

```text
连接「知识库」
将读取：项目资料、文档内容（只读）
不会：修改、删除、发消息
数据将发送到模型服务；令牌不进入提示
[取消] [连接账号]
```

规则：

- R2a 只有只读 scope；写入不展示。
- 连接器状态：未连接/已连接/授权过期/组织禁用/错误。
- 任务级 scope 只能在组织授权范围内收窄。
- 授权后摘要显示“连接器「知识库」（只读：项目资料）”。
- 撤销入口在连接器详情；撤销后新任务不可用，历史审计保留。
- 外部内容视为数据，不是指令；UI 不承诺“完全可信”。

### 6.6 扩展能力首页（一级）

一级页参考豆包“插件-技能-伙伴”的页面结构：顶部 tabs、组织推荐、分类筛选、卡片区；但不复制市场、热度、下载量和营销 hero。

```text
扩展能力        [范围] [搜索扩展能力] [管理] [创建套件]
┌ 组织推荐 ────────────────────────────────────────────────┐
│ 产品方案                                                 │
│ 围绕目标写一份可评审的产品方案…                          │
│ [查看方法] [查看全部套件]     [R1 套件模板] [5 个技能]   │
└──────────────────────────────────────────────────────────┘
[套件] [技能] [连接器]
[全部分类] [文档] [分析]        [全部状态] [仅已启用] [查看全部]

组织推荐（2）
[产品方案] [客户周报]

更多套件（1）
[本地资料整理]
```

与豆包的映射：

| 豆包页面 | 我方一级页 | 说明 |
|---|---|---|
| 插件 / 技能 / 工作伙伴 tabs | 套件 / 技能 / 连接器 tabs | 伙伴在 R5c，不进入当前一级页 |
| 精选 / 办公管理 / 金融分类 | 全部分类 / 文档 / 分析 / 项目 / 数据 | 分类来自组织目录 |
| 必备精选 hero | 组织推荐 feature | 只推一个组织套件，不做营销插画 |
| 大家都在用 | 更多套件/技能/连接器 | 不显示使用量、热度、下载量 |
| 卡片“添加” | 查看详情 / 使用 / 连接 | 详情是三级页，使用是组合动作 |
| 搜索 | 搜索扩展能力 | 名称搜索 |
| 已安装/市场 | 全部状态 / 仅已启用（连接器为仅已连接） | 不做市场 |

规则：

- 一级页只展示组织目录；不做开放市场。
- 顶部 tabs 由能力范围驱动：R1 显示套件/技能，R2a 增加连接器；未开通不渲染，不显示空 tab。
- 页头提供“管理”（管理员）和“创建套件”（组织作者）；无权限时不显示，不从市场安装。
- 每个 tab 有独立的推荐、分类和卡片。
- 组织推荐最多 2 个；更多区域展示剩余项；“查看全部”进入二级列表。
- 卡片显示名称、一句话说明、技能数/输出、必需连接器、版本状态。
- 状态不靠颜色单独表达；文字 + 颜色。
- 搜索无结果、组织未开通、加载中都要有空/加载状态。

能力门控：

| 能力 | 一级 tab | 显示条件 | 未开通时 |
|---|---|---|---|
| 套件/技能 | 套件、技能 | R1 已启用 | 不渲染 tab；管理面显示未开通 |
| 连接器 | 连接器 | R2a 已启用 | 不渲染 tab；不显示空占位 |
| 工作伙伴 | 工作伙伴 | R5c 已启用 | 不进入一级页 |
| 管理 | 管理按钮 | `org.work_capability.write` | 不显示 |
| 创建套件 | 创建按钮 | R1 组织作者权限 | 不显示 |

### 6.7 分类列表（二级）

```text

[搜索当前分类] [全部分类] [全部状态] [仅已启用]

[套件卡]
```

规则：

- 面包屑：`扩展能力 / 套件`；返回一级页。
- 二级页是完整列表，不再有 hero；保留搜索、分类、状态筛选。
- 卡片动作：查看详情（三级）、使用/连接（快速动作）。
- 空状态说明“没有匹配项”，提供清空筛选。
- 连接器列表的“仅已连接”替代“仅已启用”。

### 6.8 详情页（三级）

套件详情：

```text
扩展能力 / 套件 / 产品方案
[产] 产品方案 · v2 · 已启用          [返回列表] [使用此套件]

方法步骤                 版本 / 作者 / 状态
1 目标澄清               环境
2 背景研究               相关技能
3 备选方案
4 取舍与风险
5 自检
输出标准 / 快捷命令
连接器（无或必需）
```

技能详情：

```text
扩展能力 / 技能 / 竞品分析
[竞] 竞品分析 · 已启用               [返回列表] [添加为补充技能]

方法说明                 环境
输入 / 输出              依赖
适用 / 不适用            相关套件
```

连接器详情：

```text
扩展能力 / 连接器 / 知识库
[知] 知识库 · 未连接                 [返回列表] [连接账号]

数据范围（只读）          授权状态
只读与安全                相关套件
使用方式
```

规则：

- 三级页是独立页面，不是弹窗；Composer 的快速选择仍可用弹窗，但完整信息在三级页。
- 套件详情展示人类可读方法，不展示原始提示词/`SKILL.md`。
- 技能详情展示输入/输出、环境和依赖；已属于当前套件时禁用“添加”，不占补充上限。
- 连接器详情展示只读 scope、令牌边界、撤销；授权弹窗只做 scope 选择，授权后详情页显示“已授权：项目资料、文档”。
- 详情页增加“可以这样用”2–3 个示例：点击只预填 Composer，不自动提交。
- 技能详情提供“在任务中试用”语义；添加动作明确为“仅加入本次任务”，不是全局启用。
- 连接器详情示例在未连接时先打开授权，不假装已读取数据。
- 详情页的“使用/添加/连接”动作要回到 Composer 或更新当前组合，不绕过“本次使用”摘要。
- 面包屑保持 `扩展能力 / 类型 / 名称`；返回列表保留筛选状态（实现可后续补）。

### 6.9 任务工作区扩展摘要

```text
本次使用
套件「产品方案」 · 技能「竞品分析」「结构自检」
· 连接器「知识库」（只读：项目资料） · 预设组合，无链式
```

规则：

- 摘要放在任务头部或执行时间线上方，始终可见。
- 增加可折叠“本次能力与调用记录”：套件/技能版本、连接器 scope、执行模式、工具调用摘要。
- 连接器来源在时间线中可点击，回到连接器记录。
- R1 不显示“步骤审批”；R3 才显示链式计划/步骤确认。
- 任务失败时保留“本次使用”，便于判断是方法、数据还是模型问题。
- 可折叠记录借鉴千问“已使用技能/已工具调用记录”，但不展示原始内部日志/思维链。

### 6.10 R3 项目与链式预览

R3 才出现的增量：

```text
[项目：会员改版 ×]  [上下文：brief.json / flow-web.json]
本次计划：读取 brief → 竞品分析 → 方案生成 → 自检
输出：motion-plan.json（schema v1）
```

规则：

- 项目 chip 只在项目上下文可用时显示。
- 链式计划开始前展示；变更需批准。
- schema 不匹配阻止下一步；不静默降级。
- R1/R2a 不显示项目/链式入口。

### 6.11 工作伙伴（R5c）

- 不在 R1–R3 导航；只作为未来态说明。
- 伙伴 = 套件 + 短角色指令 + 默认环境/审批偏好。
- 不做长期记忆/主页/自动化；不单独售卖。
- 本设计不提供伙伴原型。

### 6.12 管理面：能力管理

| 区块 | 内容 | 动作 |
|---|---|---|
| 套件 | 组织套件、版本、状态 | 启用/下架/回滚 |
| 技能 | 可用技能、作者、版本 | 启用/禁用 |
| 连接器 | 连接器、scope、环境 | 允许/禁止/撤销 |
| 策略 | 默认套件、审批模式、环境 | 设置 |
| 审计 | 发布、授权、使用、撤销 | 导出 |

入口：

- 一级页页头“管理”进入管理面；仅管理员权限显示。
- 一级页页头“创建套件”进入组织作者创建流程；创建后进入组织目录，不进入开放市场。
- 普通成员不显示上述入口；未开通能力不显示对应 tabs。
- 席位、预算、策略与审计的完整规格见 [管理面原型](assets/work-ux-admin/prototype.html) 和 R0 UX §6.7；本页只定义能力目录管理的入口。

规则：

- 组织策略优先于用户选择；用户只能收窄。
- 组织禁用能力不在 Composer 中可选；显示原因/申请路径。
- 管理面以主组织为准；当前不做多组织切换。

## 7. 状态与微文案

| 状态 | UI | 文案 | 动作 |
|---|---|---|---|
| 无扩展 | `＋` 菜单仅文件夹；连接器入口不显示 | 无 | 正常提交 |
| 加载中 | `＋` 菜单与连接器入口骨架 | 正在加载能力… | 禁用 |
| 未启用 | 能力库可见，Composer 不显示 | 未启用 | 去能力库/联系管理员 |
| 未授权 | 连接器 chip 红点 | 需要连接「知识库」 | 连接 |
| 授权过期 | 连接器 chip 警示 | 授权已过期 | 重新连接 |
| 组织禁用 | 不可选，说明 | 组织已禁用该能力 | 申请/联系管理员 |
| 环境不支持 | 套件卡禁用 | 仅支持本机/云端 | 切换环境 |
| 超限 | 第 4 个技能禁用 | 补充技能最多 3 个 | 移除一个 |
| 冲突 | 技能提示 | 该技能已在套件中 | 移除/换技能 |
| 缺连接器 | 提交禁用 | 套件需要连接器「知识库」 | 连接 |
| 无链式 | R1 标签 | 预设组合，无链式上下文 | 继续/了解 R3 |
| schema 不匹配 | R3 阻止 | 上游输出不符合 schema | 修复/重试 |
| 组织策略锁定 | 设置只读 | 由组织策略设置 | 联系管理员 |
| 连接器错误 | 任务暂停 | 连接器调用失败 | 重试/撤销/查看审计 |

原型页头“状态演示”可切换正常、加载中、授权过期、连接器错误；授权过期保留原 scope，重新连接后恢复；连接器错误在任务摘要显示暂停与重试/撤销。

### 7.1 空状态

- 能力库无套件：说明“组织还没有发布套件”，不要显示市场。
- 无连接器：说明“当前没有可用的只读连接器”，提供管理员入口。
- 技能搜索无结果：清空搜索/查看全部。
- 任务无扩展：不显示“本次使用”扩展段，不占位。

### 7.2 错误恢复

- 缺连接器：点击“连接”完成授权后，摘要更新，提交恢复可用。
- 环境不兼容：提供“切换本机/云端”，不自动切换。
- 超限：提示移除哪个技能；不静默丢弃。
- 组织禁用：解释原因和申请路径，不让用户反复试。
- 连接器失败：保留任务与已有成果；重试/撤销/审计。

## 8. 关键交互

### 8.1 安装/启用/授权/调用

| 动作 | 入口 | UI 结果 |
|---|---|---|
| 安装 | 管理员目录 | 能力进入组织目录，不代表可用 |
| 启用 | 管理员能力管理 | 用户可在能力库看到，Composer 可选 |
| 授权 | 连接器详情/任务缺省 | 记录账号/scope，不等于自动调用 |
| 调用 | 任务选择连接器 | 本次使用摘要出现，执行时使用 |

### 8.2 组织策略优先

- 组织禁用：Composer 不显示或显示禁用原因；用户不能绕过。
- 组织允许但用户未授权：显示“未连接”，引导授权。
- 组织默认套件：Composer 可预选，但用户可移除。
- 组织强制审批：用户不能改成“全部允许”。

### 8.3 版本与快照

- 套件/技能/连接器版本在任务创建时冻结。
- 更新不回溯旧任务；任务摘要显示版本。
- 重试默认使用原快照；可用“最新版本重试”但需确认差异。
- 套件下架不删除历史版本；旧任务仍可查看。

### 8.4 环境与套件

- 套件声明环境（云端/本机/两者）。
- 当前环境不兼容时：阻止提交，提供切换动作；不自动切换。
- 本机套件需要文件夹授权；云端套件不显示文件夹。
- 手机端不执行本机套件；只查看/审批。

### 8.5 连接器授权

1. 点击连接器/缺省提示。
2. 授权弹窗展示数据范围、只读、去向、留存。
3. 用户连接账号（OAuth/账号授权）。
4. 选择任务级 scope（组织允许范围内）。
5. 摘要更新；提交恢复。
6. 撤销入口在连接器详情；撤销即时生效。

### 8.6 快捷命令

- `/` 打开命令菜单；按套件分组。
- 命令显示产出/环境/连接器需求。
- 点击预填；不提交。
- 命令不携带隐藏权限；缺连接器时打开授权。

### 8.7 不静默回退

- 套件缺连接器：不自动换套件、不跳过连接器。
- 环境不兼容：不自动切云端/本机。
- schema 不匹配：不静默截断/忽略。
- 技能冲突：不自动去重后提交，必须用户确认。

## 9. 响应式与可访问性

### 9.1 响应式

| 宽度 | 扩展 UI |
|---|---|
| ≥1200px | Composer 单行工具条；套件选择为右侧抽屉/大弹窗；能力库多列 |
| 768–1199px | 工具条换行；选择器为全宽弹窗；能力库两列 |
| <768px | 工具条两行排布；选择器为全屏 sheet；能力库单列 |

移动端：

- 套件/技能/连接器选择用全屏 sheet，底部固定“应用”。
- 连接器授权显示数据范围，按钮固定底部。
- 任务摘要折叠为 2 行 + “展开”。
- 快捷命令 `/` 用底部 sheet。

### 9.2 可访问性

目标基线：WCAG 2.1 AA（同 R0）。

- 选择器：`role="dialog"`、标题关联、焦点陷阱、Esc 关闭、焦点回归。
- 入口：`＋` 菜单用 button + `aria-haspopup="dialog"`；连接器/执行器/权限 chip 用 button；多选列表用 checkbox/`aria-pressed`。
- 连接器 scope：checkbox + label；只读 scope 明确文字。
- 错误：`role="alert"`；摘要更新 `aria-live="polite"`。
- 键盘：Tab 顺序、`/` 打开命令、Enter 选择、Esc 关闭。
- 加载骨架尊重 `prefers-reduced-motion`；授权过期/错误用文字+颜色双重提示。
- 对比度/触控目标/减少动效同 R0 标准。

## 10. 视觉方向

### 10.1 组件

| 组件 | 视觉 |
|---|---|
| 套件卡 | 白卡、1px 边框、标题+一句产出+元信息；不放大图 |
| 技能卡 | 紧凑行/卡；复选框；显示输出/环境 |
| 连接器卡 | 状态点 + 名称 + scope + 连接按钮 |
| 状态 badge | 已启用/未连接/组织禁用/仅本机 |
| 本次使用 | 浅蓝信息条；与 R0 信任面板一致 |
| R1 标签 | “预设组合”中性标签，不用“专家/链式” |

### 10.2 原则

- 能力库像“工具箱”，不像电商市场。
- 不使用“安装量/热度/作者头像”作为主要视觉。
- 品牌蓝只用于主行动/选中；状态色只表达状态。
- 套件卡信息密度高于市场卡；一屏能比较 2–3 个套件。
- 连接器授权以数据范围为中心，不用营销插画。

### 10.3 Token 映射

沿用 R0：

- 品牌 `#3370ff`；主按钮 `#2860d9`；画布 `#f6f6f6`；卡片 `#ffffff`；
- 文本 `#1a1c1e` / `#666666`；边框 `#e5e5e5`；
- 间距 8/12/16/24；圆角 8/12；字号沿用 WeMeet scale。

## 11. 原型说明

**文件**：[assets/work-ux-extensions/prototype.html](assets/work-ux-extensions/prototype.html)

打开方式：浏览器直接打开；无外部依赖。

### 11.1 可体验路径

1. 工作首页：点 `＋` 打开菜单 → 套件/技能/选择文件夹；点独立“连接器”入口授权数据；用执行器/权限 chip 切换位置和审批方式。
2. 点“新建项目”（R3 预览）填写项目名称和文件夹 → 项目 chip 出现在输入区。
3. 打开“扩展能力” → 查看组织推荐 → “查看全部套件”进入二级列表 → 打开套件详情 → “使用此套件”。
4. 在套件详情查看方法步骤、输出标准、快捷命令、连接器要求和版本；点击快捷命令预填回 Composer。
5. 切到“技能” → 查看全部技能 → 打开技能详情 → 添加为补充技能；再打开一次可移除。
6. 切到“连接器” → 查看全部连接器 → 打开知识库详情 → 连接账号 → 只勾选“读取项目资料” → 返回首页查看本次使用 scope。
7. 在详情页点击“可以这样用”示例 → 回填任务描述和套件/技能，不自动提交。
8. 切换页头“能力范围”到“仅 R1” → 连接器 tab、连接器独立入口和新建项目入口消失；`＋` 菜单只保留套件/技能/文件夹；切回 R1–R3 恢复。
9. 点击“管理”查看能力管理；点击“创建套件”创建一个组织套件并进入详情。
10. 选择“客户周报”（需要知识库）但未连接 → 提交被阻止 → 连接后恢复。
11. 选择“本地资料整理”但当前云端 → 阻止提交 → 切换本机。
12. 点击“/”快捷命令 → 预填目标 + 套件，不自动提交。
13. 任务提交后查看“本次使用”摘要与折叠的“本次能力与调用记录”；R1 显示“预设组合，无链式”。
14. 页头“状态演示”切换加载中/授权过期/连接器错误；授权过期可重新连接，连接器错误在任务页显示暂停与重试/撤销。

Composer 的 `＋` 菜单提供套件、技能和选择文件夹；连接器 chip 独立打开授权/选择弹窗。扩展能力首页、二级列表和三级详情用于完整浏览与管理；席位/预算/策略/审计见 [管理面原型](assets/work-ux-admin/prototype.html)。

### 11.2 原型限制

- 中保真；无后端；连接器授权为模拟。
- 管理面能力管理只演示目录状态；席位/预算/策略/审计在独立管理面原型中模拟。
- 状态演示为前端模拟，不触发真实 OAuth/连接器调用。
- 不实现 R3 链式/schema 和完整项目上下文；只提供新建项目与项目 chip 预览。
- 不实现 R5c 工作伙伴。
- 不实现写入连接器/MCP/市场。
- 不含真实模型调用和文件访问。

### 11.3 评审重点

- 用户能否在看详情后正确选择套件。
- “本次使用”是否说清数据范围。
- 缺连接器/环境不兼容是否可恢复。
- 授权过期/连接器错误是否能让用户找到重试或撤销。
- R1 是否被误认为链式。
- 工具条入口是否过载；`＋` 菜单是否易于发现；首屏是否仍能 60 秒提交。

## 12. 可用性测试

### 12.1 参与者

- 5–8 名设计合作伙伴，覆盖知识工作者、团队负责人、管理员。
- 45 分钟；原型 + 访谈；主持人只读任务。

### 12.2 任务

| 编号 | 任务 | 成功标准 |
|---|---|---|
| E1 | 从扩展能力首页进入套件列表和详情，选择合适套件 | 选中“产品方案”，能说出产出与方法步骤 |
| E2 | 添加 2 个补充技能 | 不超过 3 个，能解释套件内技能不占上限 |
| E3 | 连接知识库并选择只读范围 | 完成授权，能说出读什么/不写什么 |
| E4 | 选择“客户周报”但未连接知识库 | 找到缺连接器原因并完成连接 |
| E5 | 选择“本地资料整理”但当前云端 | 识别环境不兼容并切换本机 |
| E6 | 解释 R1 套件与 R3 链式差异 | 能说出 R1 是提示组合、R3 才有步骤/schema |

### 12.3 指标

- 任务完成率、完成时间、错误次数。
- 本次使用理解率、连接器授权理解率。
- R1/R3 差异理解率。
- SEQ ≥5/7；无 P0；P1 在 R1 开发前修复。

## 15. 附录

### 15.1 关键微文案

- 本次使用：云端 · 套件「产品方案」 · 技能「竞品分析」 · 连接器「知识库」（只读） · 预设组合。
- 套件环境不兼容：该套件仅支持本机；切换本机后继续。
- 缺连接器：套件「客户周报」需要连接器「知识库」；连接后即可提交。
- 连接器授权：只读项目资料；不会修改或删除；令牌不进入提示。
- 组织禁用：组织已禁用该连接器；联系管理员申请。
- 超限：补充技能最多 3 个；套件内技能不计入上限。
- R1 标签：预设组合，无链式上下文。
- R3 预览：本次计划会读取 brief/flow，并按 schema 输出。

### 15.2 状态色

| 状态 | 色 |
|---|---|
| 已启用/已连接 | 绿 |
| 待授权/待连接 | 琥珀 |
| 组织禁用/错误 | 红 |
| 仅本机/环境限制 | 灰/橙 |
| 选中/主行动 | 品牌蓝 |
