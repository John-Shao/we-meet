# 阶段 3 第三十一批（累计第 51 批）：共享同传 Agent 授权层

新增专用频道的内部回报客户端和本地授权租约，为多人音频执行器提供一致边界。

- 调度元数据只允许频道 ID、代次、会议 SID，不能携带模型、凭证或接收者覆盖。内部请求固定服务地址与 Worker UUID，限制响应大小并拒绝其他频道/代次响应。
- 认领和结束回执可有限重试，保持同一身份和请求内容；心跳失败不重试，不维持旧输出。正常停止的尾段必须另带明确许可和最新听众名单。
- 用单调时钟检查 15 秒本地授权期限。任何非法、缺失、超限或重复的授权响应先清除旧权限；同一频道不能中途变更模型或目标语言。
- 来源与接收者同时验证 LiveKit 身份、具体参与 SID 和标准人类参与类型，重连与 Agent 轨道不继承旧授权。断开事件可先于下次心跳立即移除该连接。

验证：11 项新增授权/回报测试及 12 项个人翻译控制回归通过，Ruff 与差异检查通过。所有网络调用为模拟，没有模型调用。专用多人音频运行时尚待下一批接入，因此频道开关继续保持关闭。
