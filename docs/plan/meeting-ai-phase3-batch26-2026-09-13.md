# 阶段 3 第二十六批（累计第 46 批）：通知页面与固定版本深链

纪要页面新增可展开的助手通知区域，展示默认策略、管理者可见的下一次生成候选名单以及本人最近通知状态。失败或结果未知时可明确重试本人原通知；已发送和远端不可用的通知不提供新发送操作。

- 重试前保存不含正文的会话恢复标记，按账号、记录和通知隔离。请求结果未知、刷新或重新进入时，继续使用原 UUID 和预期尝试次数。读取权限失败后移除旧名单、链接和重试操作。
- 通知卡片的 `?summary=` 参数打开智能纪要页签并按版本 ID 精确读取，历史版本不受首页分页影响。非法、缺失、其他记录的版本不会退回最新版。
- 固定版本视图显示该版引用和导出入口；不混入当前人工修订、旧流水线纪要或新生成按钮。可以明确返回会议记录查看其他内容。
