    成果预览

    产品评审方案

    本任务使用套件与技能生成；这里是中保真预览，不代表真实模型输出。

    1. 背景与目标

    确定会员改版第一阶段范围，形成可执行的取舍方案。

    2. 建议

    先做核心链路，第二阶段补视觉与运营工具。

    选择套件

    一个任务最多一个主套件；套件内技能不计入补充技能上限。

    选择补充技能

    补充技能最多 3 个；套件内技能不计入上限。

    已选 0/3
    套件内技能不计入上限；选择套件后显示。

    连接器

    R2a 只读；令牌不进入提示；任务级 scope 不能超过组织授权。

    连接「知识库」

    将读取指定项目资料和文档内容；不会修改或删除。令牌不进入模型提示。

    快捷命令

    点击只预填目标和套件，不自动提交；缺连接器仍会提示。

    扩展能力管理

    管理员入口。生产环境按权限码控制；席位、预算和审计见 管理面原型。

    创建套件

    组织作者入口。R1 套件是单 run 提示组合，不包含链式或连接器写入。

    添加工具

    套件、技能和文件夹从这里添加；连接器在工具栏单独授权；提交前仍会显示在“本次使用”。

    执行器位置

    执行位置决定数据访问和成果存放；提交前必须确认。

    默认权限

    组织策略优先；任务级只能收窄，不能放宽。

    选择本机工作文件夹

    只读取你授权的文件夹；命令逐次批准；不是操作系统沙箱。

    新建项目 R3 预览

    项目是跨任务的上下文容器；R1/R2a 不显示项目入口。
