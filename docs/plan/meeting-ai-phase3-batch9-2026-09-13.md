# 阶段 3 第九批（累计第二十九批）：独立转写任务与来源版本

封存录音后，所有者可显式创建一次转写任务。音频清单、模型、地区和付费身份固定，重复请求复用意图；重新转写使用新版本。缺片录音需明确接受，空音频拒绝创建。

- Worker 通过受保护接口领取一个任务，逐片获取校验后的 WAV；开始执行仅可确认一次，过期任务不重新领取。取消、账号或权限失效、功能关闭立即阻止后续执行；晚到回执不能将失败变成成功。
- 逐字稿按任务版本保留。只有供应商结束、全部输入确认与最终文字序号相符时才发布；新版本失败时继续显示旧版。未发布文字不会出现在记录原文和说话人列表中。
- 来源时间必须落在连续音频区间内，禁止跨缺片虚构时间。最多 4,320 片、50 个不连续区间、20,000 条最终文字和 4 MB 文本。心跳只返回进度，不重复传输完整清单；数据库仍校验有界输入快照，长录音性能需部署后评测。
- 实际供应商时长回执去重记录；个人录音不会因用户后来加入组织而改变费用归属。未报告计费时长保留未知。

模型沿用 `qwen-audio-3.0-asr-flash-streaming`。官方能力表说明其不支持说话人分离，当前使用未识别说话人，不推测同事身份：[阿里云 ASR 模型说明](https://help.aliyun.com/zh/model-studio/asr-model)。

验证：转写、音频保存、采集协议、原费用链路共 71 项测试通过，包括两个 Worker 并发领取；Ruff 和迁移一致性检查通过。迁移 `0165_capture_transcription_jobs` 仅在隔离数据库执行。`MEETING_CAPTURE_ASR_ENABLED` 默认关闭；此批只有任务协议，Worker 和 Web 入口在后续批次连接，未调用真实供应商。
