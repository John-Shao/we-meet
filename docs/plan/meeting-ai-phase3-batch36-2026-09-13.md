# 阶段 3 第三十六批（累计第 56 批）：共享译文保存与阅读

共享同传频道现在可以从 Web 明确选择保存译文，Agent 投递确认片段，会后在对应会议笔记中分页阅读。默认不勾选，不改变参会人的资料权限。

- Agent 使用独立有界队列保存确认译文（64 项、512 KiB），不保存候选文本。保存失败不阻断同传音频，档案独立标记不完整。
- 每条投递携带原频道、代次、Worker、发言人参与记录及供应商项目标识；最多三次重试同一内容，并核验返回的档案、代次、内容哈希和序号。停止时在原有尾段期限内排空，不重新调用模型。
- Web 仅在能力开放且频道未运行时显示保存选项。已保存频道可在新标签页打开对应笔记的译文页，避免离开正在进行的会议。
- 译文页先选择档案，再按序号分页阅读，展示语言、保存状态和发言人。接收时间与原文时间明确区分；不提供没有来源依据的精确回听。
- 列表和正文定期重新核验读取权限；权限失效后隐藏已显示内容，不回退到旧缓存。私人及独立录音译文仍待后续实现。

验证：Agent 62 项、后端档案 20 项、前端相关 25 项测试通过。Ruff、ESLint、翻译 JSON、TypeScript、生产构建通过。原生 Chromium 模拟接口检查桌面/移动布局、分页入口、不完整状态及权限撤销，未调用真实服务。构建仅有既有资源与大分块警告。

部署需包含 0172 迁移、兼容的后端、共享同传 Agent 和 Web，并显式开启记录及译文留存开关；本批无新增迁移。生产部署、真实音频质量与端到端测试由用户执行。首版开发和最终技术评审尚未完成。
