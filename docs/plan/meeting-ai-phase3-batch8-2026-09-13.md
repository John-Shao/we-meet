# 阶段 3 第八批（累计第二十八批）：独立音频回放

录音保存后可直接播放；本机历史记录也能打开回放。支持全局音频位置、暂停／继续、0.75–2 倍速以及缺片提示。

- 通过当前账号授权端点逐片读取，只保留一片短音频 Blob。复用登录刷新逻辑，并在读取响应流时限制 320,044 字节；下载后核对服务器回执的字节数与 SHA-256。
- 按原始时间定位，不把缺失时间偷偷跳到下一段。顺序／时间存在空隙时暂停，由用户明确选择下一段；不完整清单持续显示提示。按分片播放可能短暂缓冲，目前不宣称无缝长音频。
- 暂停、切换录音／账号或离开页面时释放 Blob 与播放资源；正在播放时另做当前权限检查，失效后清除缓存。拖动进度条在释放时才决定是否继续播放，避免每个滑动事件发起一次下载。
- 读取已有音频不依赖创建开关；仍要求当前录音所有者和当前原文资料访问权。生产对象存储必须维持私有桶策略，不能仅依赖对象键难猜。

验证：API 二进制边界与原登录回退 3 项、播放器 3 项通过；TypeScript、ESLint 和生产构建通过。原生 Chromium 合成音源流程增加真实 HTMLAudioElement 播放、受保护 WAV 读取、倍速和暂停释放检查。没有真实麦克风／生产存储测试。下一批进入独立录音的 ASR 执行与来源版本。
