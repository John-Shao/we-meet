# 阶段 3 第十五批（累计第 35 批）：Web 资料库与记录工作区

会议首页新增「会议笔记」「智能纪要」，与「AI 录音」组成资料入口。`/meeting/notes` 与 `/meeting/minutes` 共享记录身份；后者在服务端筛选已有纪要，打开同一个 `/meeting/records/:recordId`。

- 进行中和历史记录分别分页；来源、当前权限范围、标题搜索改变后重置游标，不保留上一范围内容。15 秒刷新，在读取失败后隐藏缓存标题并停止轮询。
- 云端记录详情按当前权限显示文字、纪要、发言人（独立录音）和信息。仅纪要分享不请求逐字稿、采集或音频；仅逐字稿分享不能进入付费控制。旧版会议逐字稿和纪要通过准确记录 ID 读取，不回退到复用房间的最新场次。
- 独立录音所有者可跨浏览器读取已结束的云端采集，回放、转写、查看纪要、修订、任务确认和问答沿用已验证组件。页面不创建 IndexedDB 录音日志，不申请麦克风，不发送设备控制命令。
- 尚未结束的采集提示返回原设备；音频组件与转写控制仅在已结束的采集挂载。纪要引用时间从记录时间轴换算到采集时间轴。
- 发言人展示已有标签，不把未知声音猜测为成员；线上会议的发言人资料与媒体工作区仍需后续补齐。

验证：相关前端 27 项通过；应用 TypeScript、ESLint、117 个 JSON 文件检查、生产构建通过。原生 Chromium HTTP fixture 检查覆盖桌面与 390px 窄屏、云端跳转、原文与纪要回听、发言人、撤权后卸载播放器，没有请求写接口或真实模型。构建保留既有 Marianne/devise SVG 与包体积警告。

没有数据库迁移或新增部署开关；资料库遵循 `MEETING_RECORDS_ENABLED`。本批不代表整体开发完成：独立实时转写/总结、多方同传、Android、文本留存清理、Docs 幂等交付依赖及完整 M3 验收仍待完成。继续完善工作区检索与来源定位。
