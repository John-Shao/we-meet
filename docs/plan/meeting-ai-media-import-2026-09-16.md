# AI 录音：导入音频与视频

## 已实现

- Web 与 Android 的 AI 录音首页并列提供“录音”和“导入”。点击导入直接打开系统文件选择器，选中文件后显示确认页；取消选择不上传。
- Web 按服务端允许的后缀配置文件选择器；Android 按对应 MIME 类型筛选，选择后再检查后缀和大小。两端都使用同一个后端能力接口，保留会议实录库中的导入快捷入口。
- 确认页展示文件名、类型、大小，保留可选上下文与热词。视频明确提示保留原文件，仅识别语音。用户确认后上传并启动文件转写；请求失败重试沿用原幂等键。
- 首页继续采用当前的最近 20 条上限，统一展示已结束的现场录音与导入音视频，显示来源和转写状态。“更多”进入会议实录并过滤“录音与导入”。
- 导入完成后打开录音详情，展示文件元数据、状态、会议实录与智能纪要链接。转写控制仅向所有者开放；共享读者不会获得重试能力。

## 数据与处理

- 新增查询条件 `source_type=recordings`，在数据库分页前合并 `audio_recording` 与 `upload`，保留原有权限过滤及时间排序。
- 记录接口新增可选 `upload` 元数据：类型、原始文件名、字节数、处理状态、所有者控制标识。不会返回存储路径、签名 URL、模型凭据或任务 ID。
- 原文件沿用私有音频存储的 `record-uploads/` 前缀保存，视频文件不在上传时替换为音频。元数据使用已有任务的 JSON 配置保存，不需要数据库迁移；旧记录按已有扩展名回退识别类型。
- 上传端检查后缀、大小及有界文件头。完整解码、音轨是否存在、媒体时长等由文件识别服务校验，失败保留原文件及可重试任务，不发布部分文字。
- 使用现有 `qwen-audio-3.0-asr-flash-filetrans` 文件任务处理视频中的语音，不新增转码服务。能力依据：[阿里云语音识别模型说明](https://help.aliyun.com/zh/model-studio/asr-model)。本批不新增视频画面分析或导入原视频播放器。

## 部署

生产配置已开启 `MEETING_FILE_ASR_ENABLED`；默认单文件上限维持 100 MiB，Ingress 请求体上限调整为 101 MiB，为 multipart 字段与请求头预留空间。API、Celery worker 和 beat 共享后端配置，复用已有私有存储及百炼凭据。

```bash
bash deploy/aliyun/release-meet.sh backend frontend
```

同时重新构建并安装 Android App。无需发布 IM SDK，无需修改 Secret。先更新后端，再验证新客户端的合并历史查询。

## 验证与走查

- 后端 43 项测试通过：真实 WAV/QuickTime 文件头、原文件逐字节保留、伪造媒体拒绝、幂等重试、旧元数据兼容、混合分页、跨用户隔离及共享只读限制。
- Helm 18 项测试通过：生产开关、请求体空间、API/worker/beat 的配置传递。
- Web 21 项相关测试通过；ESLint、JSON 检查及生产构建通过。
- Android 6 项上传仓库单元测试、7 项模拟器界面测试通过，包括直接打开文件选择器、音视频类型过滤、取消不上传及历史详情链接。
- 走查确认上传保持流式存储和有界文件头读取；列表关联查询避免逐条读取任务；未新增表或扩展共享权限。
- 自动测试使用本地隔离数据库和模拟服务，没有发起真实计费识别。部署后需用真实音频、带语音的视频及无音轨视频验证云端处理与失败提示。
