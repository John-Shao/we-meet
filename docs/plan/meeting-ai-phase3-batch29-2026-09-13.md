# 阶段 3 第二十九批（累计第 49 批）：多人同传频道与收听订阅契约

新增共享目标语言频道，独立于既有个人双向/连续翻译。管理者控制频道生命周期，参会者只改变本人连接的收听选择。

- 按确定会议场次、目标语言和生成代次隔离；中/英每种目标同时最多一个活动频道。创建频道先进入准备状态，有人明确收听后进入待启动状态。本批不调度模型或处理音频。
- 只有会议当前管理者可以启停；具备真实在线标准参与连接且满足组织条件的账号可以收听。材料共享权限或普通访问链接不构成收听资格。
- 订阅绑定具体参与连接，20 秒租约、独立版本号；切换目标语言后旧心跳失效，过期必须重新订阅，重连不会继承旧设备的选择。明确退订不停止其他听众。
- 每次控制保存请求回执，重放只返回原结果，不重做旧选择。公共接口仅返回本人连接与订阅；内部来源/目的身份不得发给普通客户端。
- 内部授权快照只选择当前标准参与者，排除 Agent；最多 16 个音源、100 个听众，超过音源上限明确失败，不静默截取部分会议。费用责任固定在频道发起者，不随听众变动。

验证：13 项数据库/API 测试通过，包含并发选择、频道唯一性、个人退订、旧请求与心跳、重连、跨场次/账号、组织退出、管理者撤权及源上限。0170 已在隔离数据库迁移；迁移一致性、Ruff 与差异检查通过。

`MEETING_INTERPRETATION_ENABLED` 默认关闭，`ROOM_INTERPRETATION_AGENT_NAME` 默认为空。Worker 调度/认领/音频与 Web 收听尚未接入，部署时不得提前打开此功能。下一批完成服务端 Worker 生命周期，随后连接多人音轨和端侧音频处理。
