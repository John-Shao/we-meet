## 1. 设计目标

### 1.1 用户目标

1. 第一次使用能在 60 秒内提交一个可执行任务。
2. 提交前能回答：在哪执行、会碰什么、得到什么、保存在哪。
3. 需要审批时知道“批准什么、为什么、拒绝会怎样”。
4. 任务完成后能快速判断成果是否可用，并完成采纳/导出。
5. 需要继续处理时能找到“需要你”，不丢任务。

### 1.2 体验指标

| 指标 | 目标 | 测量 |
|---|---|---|
| 首次任务完成率 | ≥80% | 可用性测试任务 1 |
| 环境/数据去向正确复述 | ≥90% | 测试后提问 |
| 审批理解率 | ≥90% | 能说出批准/拒绝后果 |
| 成果采纳完成率 | ≥80% | 测试任务 4 |
| 任务完成时间 | 首次 ≤3 分钟 | 测试记录 |
| 严重可用性问题 | 0 个 P0 | 观察与访谈 |

这些是设计验证目标，不是上线承诺。

### 1.3 设计边界

- R0a 只做云端文档/方案；R0b 加本机与组织治理。
- 不显示套件、连接器、项目、工作台、分享等未实现能力。
- 不把聊天作为主界面；对话/事件是任务工作区的一部分。
- 不承诺“全自动”；审批和边界必须可见。

## 2. 设计原则

| 原则 | 设计含义 | 反例 |
|---|---|---|
| 成果优先 | 每个任务有明确主成果；成果面板始终可到达 | 任务结束只有一段总结 |
| 边界可见 | 环境、权限、数据访问、成果去向在提交前可见 | 提交后才知道读本机文件 |
| 渐进披露 | 首屏只留任务描述、上下文、环境、发送；高级项按需 | 首屏堆 10 个开关 |
| 无假能力 | 没实现的能力不渲染；禁用项说明原因 | 灰色“专家套件”占位 |
| 一屏一主任务 | 首页是开始工作，任务页是执行/验收，我的工作是管理 | 首页同时做所有事 |
| 可恢复 | 断线、失败、预算、权限撤销都有下一步 | 错误只显示“失败” |
| 信任可见 | 审批、复核、预算、成果去向在关键节点出现 | 信任能力只藏在后台 |
| 克制 | 品牌蓝只用于主行动/选中；状态色只表达状态 | 大面积渐变、装饰插画 |

### 2.1 体验基调

- **工作型，不是聊天玩具**：中性表面、清晰层级、紧凑但不拥挤；不使用头像堆叠和气泡作为主布局。
- **平静的确定性**：状态、下一步、影响范围写清楚；不用夸张动效。
- **可截图的信任面板**：本次使用摘要、审批横幅、成果来源能直接截图给管理员看。

## 3. 用户与核心任务

### 3.1 主要角色

| 角色 | 核心任务 | 关键顾虑 |
|---|---|---|
| 知识工作者 | 写方案、整理资料、做计划 | 成果能不能直接用；是否要反复改 |
| 本地重度用户 | 在授权文件夹内整理/分析 | 原始文件会不会上传；命令会不会乱跑 |
| 组织管理员 | 授权、预算、审计 | 谁在用、碰了什么、能否撤销 |

### 3.2 三条核心流程

1. **云端文档**：描述目标 → 选云端 → 发送 → 执行 → 待验收 → 采纳。
2. **本机文件夹**：选本机 → 授权文件夹 → 逐次审批命令 → 成果写入 `WeMeet成果` → 选择性同步。
3. **成果验收**：打开成果 → 看版本/来源/复核 → 采纳 → 基于成果继续。

### 3.3 R0 不覆盖

- 套件/技能/连接器选择。
- 项目上下文、链式执行。
- 富成果、工作台、分享、评论。
- 远程设备派发（R2b）。

## 4. 信息架构与路由

```text
工作
├── 工作首页                 /work
│   └── Composer 展开态      /work/new
├── 我的工作                 /work/items
│   ├── 待处理
│   ├── 进行中
│   ├── 待验收
│   ├── 已完成
│   └── 全部
├── 任务工作区               /work/items/:id
├── 成果工作区               /work/items/:id/artifacts/:artifactId
└── 历史工作（只读）          /work/archive

管理后台 · 工作（独立于个人导航，管理员可见）
├── 概览
├── 成员与席位
├── 预算与用量
├── 能力与策略
└── 审计日志
```

规则：

- “新建任务”不是独立导航页；`/work/new` 是工作首页 Composer 的展开态。
- 左侧 Work 导航只有：工作首页、我的工作、历史工作；R1 后再加扩展能力/项目。
- 管理面不放进个人工作导航；从 WeMeet 管理后台“工作”分区进入，仅管理员权限可见。
- 手机底部 Tab：工作、我的；“需要你”用角标，不单列 Tab。
- 深链：任务、成果、历史工作都有稳定 URL；通知直达任务。

## 5. 核心流程

### 5.1 云端文档任务

```text
工作首页
  → 输入任务描述（必填）
  → 可选：交付要求、上下文
  → 环境：云端（默认）
  → 权限：每次询问（默认）
  → 发送
  → 任务工作区：执行中
  → 待验收
  → 打开成果 → 采纳
  → 已完成 → 基于此成果继续 / 返回我的工作
```

关键点：

- 发送前显示“本次使用”：云端、不访问本机、交付 Markdown、保存到任务。
- 任务执行中可取消；失败可重试；未知结果不自动重放。
- 待验收不是“已完成”；必须采纳或确认完成。

### 5.2 本机文件夹任务

```text
工作首页
  → 环境：本机
  → 选择文件夹（模态）
  → 授权成功 → 文件夹 chip
  → 权限：每次询问 / 只读自动
  → 发送
  → 任务工作区：等待命令审批
  → 批准 / 拒绝 / 本次任务同类只读允许
  → 执行 → 成果写入 WeMeet成果
  → 打开文件夹 / 选择同步到云端
  → 采纳
```

关键点：

- 未授权文件夹时，发送按钮禁用并说明原因。
- 命令审批显示命令、目录、目的、风险、拒绝后果。
- 断线不自动切云端；任务进入“设备断线”，可重连/换设备/取消。
- 原始文件默认不上传；成果正文同步由用户选择。

### 5.3 成果验收

```text
任务工作区
  → 成果面板
  → 版本选择 / 对比
  → 查看来源与复核意见
  → 采纳此版本
  → 任务已完成
  → 基于此成果继续（创建后续任务）
```

关键点：

- 采纳是明确动作；不是自动完成。
- 版本不覆盖；采纳后仍可改采纳到另一版本。
- 复核是建议，不是合规保证；用户可忽略并记录理由。
- R0 不显示分享；导出是本地下载。

### 5.4 状态流转

| 状态 | 触发 | 用户看到 | 下一步 |
|---|---|---|---|
| 草稿 | 输入中 | 发送可用/禁用原因 | 发送 |
| 已提交 | 发送成功 | 等待执行 | 取消 |
| 执行中 | 执行器开始 | 时间线、步骤 | 取消、等待 |
| 等待审批 | 命令/数据访问 | 审批横幅 | 批准/拒绝 |
| 待验收 | 技术执行完成 | 成果面板、采纳按钮 | 采纳/要求修改 |
| 已完成 | 采纳/确认完成 | 完成摘要、继续 | 继续/返回 |
| 设备断线 | 本机离线 | 断线横幅 | 重连/换设备/取消 |
| 失败 | 执行失败 | 错误原因、已产生成果 | 重试/修改 |
| 预算耗尽 | 达到上限 | 已用/上限 | 等待/申请预算 |
| 权限撤销 | 组织/成员撤销 | 停止原因 | 联系管理员 |

## 6. 界面规格

### 6.1 工作首页 / Composer

#### 布局

```text
┌ app rail ┬ Work 导航 ┬ 主内容 ────────────────────────────────┐
│ 消息     │ 工作       │ 下午好，JS                             │
│ 会议     │ ＋ 新建任务 │ 今天想完成什么工作？                   │
│ 工作 ●   │ 工作首页 ● │ 描述任务，输入/调用技能。              │
│ 文档     │ 我的工作   │ ┌───────────────────────────────────┐ │
│          │ 历史工作   │ │ 例如：为下周的产品评审写一份方案… │ │
│          │            │ │                                   │ │
│          │            │ │ [＋] [文件夹] [执行器：云端▾]     │ │
│          │            │ │ [默认权限▾] [发送]                │ │
│          │            │ └───────────────────────────────────┘ │
│          │            │ ＋ 新建项目 R3（R0 隐藏）              │
│          │            │ 本次使用：云端执行器 · Markdown        │
│          │            │ · 保存到任务 · 权限：默认权限          │
│          │            │                                       │
│          │            │ 推荐开始                              │
│          │            │ [起草方案] [整理资料] [制定计划]       │
│          │            │                                       │
│          │            │ 需要你（2）          继续工作          │
│          │            │ · 等待批准读取文件夹  · 产品评审方案 v3│
│          │            │ · 成果待验收          · 本地资料整理   │
└──────────┴────────────┴───────────────────────────────────────┘
```

#### 首屏元素

| 元素 | 内容 | 规则 |
|---|---|---|
| 问候 | 下午好，JS | 可选；不阻塞提交 |
| 标题 | 今天想完成什么工作？ | 固定，不随执行器变化 |
| 任务描述 | 目标、背景、限制、验收要求 | 必填；R0a 按服务端实际限制显示字数 |
| 工具菜单 | `＋` 打开：选择文件夹 | R0 不显示套件/技能/连接器；新建项目在 R3 以独立入口出现 |
| 上下文 | 本机文件夹 | 只显示文件夹名；绝对路径不上传 |
| 执行器位置 | 云端/本机；远程 R2b | 用 chip 打开菜单；本机需授权文件夹 |
| 权限 | 默认权限/自动审批/计划批准后 | 用 chip 打开菜单；无“完全访问权限” |
| 新建项目 | R3 项目上下文 | R0/R1/R2a 不渲染；不能做占位 |
| 发送 | 主按钮 | 空描述/缺文件夹/执行器离线时禁用并说明 |
| 本次使用 | 执行器 · 数据访问 · 交付物 · 去向 · 权限 · 预算 | 必显；非默认选择必须出现 |
| 推荐开始 | 3 个内置方法模板 | 点击预填，不自动提交 |
| 需要你 | 最多 3 条 + 查看全部 | 完整列表去我的工作/待处理 |
| 继续工作 | 最近任务 | 点击打开任务 |

#### 用词规则

| 场景 | 用词 | 示例 |
|---|---|---|
| 产品线、模块、页面、活动标题 | 工作 | WeMeet 工作、工作首页、我的工作、历史工作、继续工作、工作空间 |
| 提交后产生的执行/验收对象 | 任务 | 新建任务、任务描述、提交任务、任务摘要、任务状态、任务工作区 |
| Composer 输入字段 | 任务描述 | 不写“工作描述”，避免被理解为招聘 JD |

不使用“新工作”“发送工作”“新的工作”指代任务；“我的工作/历史工作”是页面名，页面内容与计数统一用“任务”。

#### 与千问新任务的共同外壳

- `＋` 工具菜单：Work R0 只有“选择文件夹”；R1 在菜单中加套件/技能，R2a 在 `＋` 同级增加连接器入口，R3 在输入框下方显示独立的新建项目入口。
- 执行器 chip：显式显示云端/本机；本机选择后提示授权文件夹。
- 权限 chip：默认权限/自动审批/计划批准后；拒绝“完全访问权限”。
- 新建项目：R3 才渲染；R0 不显示，避免假入口。
- 推荐任务/套件：放在输入框下方，点击预填不自动提交。

#### 状态

| 状态 | Composer 表现 | 文案 |
|---|---|---|
| 空描述 | 发送禁用 | 先描述你想完成的任务 |
| 本机未授权 | 发送禁用，文件夹 chip 高亮 | 选择一个工作文件夹后才能在本机执行 |
| 本机执行器离线 | 发送禁用 | 本机执行器未连接；切换云端或重试 |
| 云端执行不可用 | 环境禁用 | 云端执行暂不可用，请切换本机或联系管理员 |
| 超字数 | 计数变红，发送禁用 | 超出上限；精简描述或拆成两个任务 |
| 预算不足 | 发送禁用 | 今日预算已用完；申请预算或明天再试 |
| 组织禁用能力 | 不渲染该能力 | 联系管理员开通 |

#### 交互

1. 输入后自动保存草稿；切换环境/权限不丢描述。
2. 点击方法卡只预填描述，聚焦输入框，不提交。
3. 本机环境点击“上下文”打开文件夹授权模态；授权后显示文件夹名，不显示绝对路径。
4. 权限下拉展示每个模式的解释和影响；不做“全部允许”。
5. 发送前显示本次使用摘要；摘要可展开“执行边界”。
6. `Cmd/Ctrl + Enter` 提交；`/` 不在 R0a 使用（R1 快捷命令）。

### 6.2 任务工作区

#### 布局

```text
┌ 任务标题 · 待验收 · 云端 · ⋯ ────────────────────────────────┐
│ 需要你：批准运行命令 / 成果待验收                            │
├ 步骤 ─────────┬ 执行时间线 ──────────────┬ 成果 ────────────┤
│ 1 ✓ 读取资料   │ 09:12 已开始处理          │ [文档] [文件]     │
│ 2 ● 生成初稿   │ 09:13 已生成大纲          │ 版本 v1 ▾         │
│ 3 ○ 自检       │ 09:15 等待批准运行命令    │ ┌───────────────┐ │
│                │ 09:16 已生成初稿          │ │ 预览/编辑      │ │
│                │                           │ └───────────────┘ │
├────────────────┴───────────────────────────┴───────────────────┤
│ [要求修改]                     [采纳此版本] [导出]            │
└────────────────────────────────────────────────────────────────┘
```

#### 区域职责

| 区域 | 内容 | 规则 |
|---|---|---|
| 头部 | 标题、状态、环境、方法、预算、更多 | 标题可编辑；状态用 pill |
| 需要你 | 审批、补充、断线、验收 | 任务级最高优先级；动作在横幅内 |
| 步骤 | R0a 执行步骤；R0b 可选计划 | 不展示思维链；只展示可执行步骤 |
| 时间线 | 用户可见事件、审批、命令、失败 | 工具调用折叠；敏感信息脱敏 |
| 成果 | 主文档/文件、版本、采纳 | 始终可到达；空状态说明还在生成 |
| 底栏 | 要求修改、采纳、导出 | R0 不显示分享；导出为下载 |

#### 审批横幅

```text
需要你批准
运行命令：python analyze.py
目录：项目资料（本机）
目的：统计 3 个 CSV 的字段缺失率
风险：只读；不会修改原文件
[拒绝] [本次任务同类只读允许] [批准本次]
```

规则：

- 批准/拒绝都要有明确结果；拒绝后说明任务暂停还是继续。
- “本次任务同类只读允许”只覆盖当前任务/运行，24 小时或任务结束失效。
- 写入/分享/外部副作用永远逐次批准。
- 审批横幅可折叠详情；不把原始日志全量铺开。

#### 任务状态演示

设计评审时可在原型任务页切换：执行中、等待审批、待验收、设备断线、失败、预算耗尽。每个状态必须显示：

- 发生了什么；
- 已产生什么；
- 用户能做什么；
- 拒绝/取消后的结果。

### 6.5 首次使用

首次进入 Work 时显示三步引导；只出现一次，可跳过，也可从帮助入口重看。

```text
首次使用                                      1 / 3
先说清楚：任务在哪里执行？
──────────────────────────────────────────────
[云端执行]  不访问本机文件；适合文档、方案和分析
[本机执行]  在授权文件夹内整理资料；需要桌面端

[跳过]                                      [下一步]
```

步骤：

1. **执行位置**：云端/本机。本机需要桌面端；移动端只提供云端。
2. **执行边界**：提交前会显示读取范围、审批方式、成果去向；本机命令逐次批准。
3. **第一个任务**：从“起草方案/整理资料/制定计划”选一个模板，只预填任务描述，不自动提交。

规则：

- 不展示套件市场、连接器市场、项目等未就绪能力。
- 选择本机后引导授权文件夹；授权成功回到 Composer，不自动开始任务。
- 用户跳过时不改变默认执行位置（云端）。
- 组织禁用 Work 或没有席位时，不进入引导，直接显示申请路径。
- 引导完成事件计入激活漏斗；跳过不阻塞提交。

状态：

| 状态 | 处理 |
|---|---|
| 移动端选择本机 | 提示需要桌面端；切换到云端 |
| 本机执行器离线 | 保留云端，提示安装/重连 |
| 无可用执行位置 | 联系管理员；不展示空 Composer |
| 已看过引导 | 不再自动弹出；帮助入口可重看 |

原型：R0 原型右上角“首次使用”演示入口。

### 6.6 历史工作（只读）

历史工作是 R0 过渡期的只读归档，不属于“我的工作”的活跃任务列表。

```text
历史工作
旧任务只读归档；可以查看和导出，不能新建运行。

[旧版资料整理]  只读 · 本机 · 10 月 20 日   [导出]
[旧版产品方案]  已完成 · 云端 · 10 月 18 日 [导出]
```

规则：

- 旧任务、旧成果、旧链接可查；旧链接重定向到历史工作或新任务详情，不返回 404。
- 只读：不能重试、继续、修改或新建运行。
- 导出为本地下载；导出行为计入审计。
- 旧任务保留期按组织留存策略；至少覆盖过渡期。
- 归档为空时说明“没有历史任务”，并提供返回工作首页。
- 旧桌面版本只读并提示升级，不静默破坏。

### 6.7 管理后台：工作治理

管理面属于 WeMeet 管理后台，不在个人 Work 导航中；仅组织管理员或 `org.work_grant.write` 持有者可见。中保真原型：[管理面原型](assets/work-ux-admin/prototype.html)。

| 页面 | 核心内容 | 关键动作 |
|---|---|---|
| 概览 | 席位、预算、本周任务、待处理审计 | 跳转席位/预算/审计 |
| 成员与席位 | 成员、角色、状态、最近活跃 | 授予、撤销、恢复；席位满时禁用 |
| 预算与用量 | 月度预算、单任务上限、预警阈值、云端/本机用量 | 调整预算、查看告警 |
| 能力与策略 | 套件、连接器、默认权限、执行位置、分享/留存 | 启用/禁用、回滚、保存策略 |
| 审计日志 | 席位、预算、策略、能力、导出事件 | 筛选、导出 CSV |

规则：

- 席位上限由套餐决定；满员时“授予”禁用并说明撤销/扩容路径。
- 撤销席位需选择原因；撤销后停止新任务，历史成果按留存策略处理。
- 预算达到预警阈值显示警告；耗尽后暂停新任务，已开始任务按原预算完成。
- 组织策略优先于个人选择；成员只能收窄审批和 scope。
- 管理面只展示元数据与审计，不展示成员成果正文；导出包含姓名并留痕。
- 当前不支持同一会话切换多个组织；管理面以主组织为准。
- 若复用现有 Work 授权控制台，沿用 P1-A 的席位/权限 API；本规格只定义 Work 治理区块与状态。

状态：

| 状态 | 处理 |
|---|---|
| 席位已满 | 禁用授予；提示撤销或扩容 |
| 预算预警/耗尽 | 概览与预算页警示；耗尽暂停新任务 |
| 无管理权限 | 不显示管理入口；直接访问返回 403 文案 |
| 审计导出中/失败 | 显示进度与重试；成功留痕 |
| 组织归档 | 只读；停止新任务；保留审计 |

## 8. 关键交互

### 8.1 环境切换

- 云端 ↔ 本机：保留任务描述、交付要求；上下文本机/云端各自记住。
- 切到本机且未授权：显示文件夹选择；不自动切换。
- 本机执行器离线：发送禁用；提供“切换云端/重试/帮助”。
- 远程设备：R0 不出现；R2b 后再加。

### 8.2 文件夹授权

1. 点击“上下文”或“选择文件夹”。
2. 模态说明：只读取该文件夹；命令逐次批准；不是操作系统沙箱。
3. 选择文件夹（原型用示例文件夹）；显示文件夹名。
4. 授权成功：Composer 显示文件夹 chip；发送可用。
5. 重新登录/执行器重启：需要重新授权；任务提示。

### 8.3 命令审批

- 展示：命令、目录、目的、风险、拒绝后果。
- 动作：拒绝、批准本次、本次任务同类只读允许。
- 同类只读允许：仅当前任务/运行、24 小时、可撤销、审计。
- 写入/外部副作用：没有“同类自动”，只能逐次批准或拒绝。
- 审批等待时任务暂停；用户离开再回来仍能看到横幅。

### 8.4 成果版本与采纳

- 版本选择在成果面板顶部；当前版本有“采纳”标记。
- 对比：选择两个版本，展示差异；不自动合并。
- 采纳：确认“采纳后任务完成”；可取消。
- 采纳后继续编辑 → 新版本；可改采纳。
- 要求修改：创建后续任务，带父任务/成果引用；不覆盖原成果。

### 8.5 失败与恢复

| 情况 | 交互 |
|---|---|
| 执行失败 | 显示错误码/原因/已产生成果；重试/修改后重试 |
| 设备断线 | 显示断线横幅；重连/换设备/取消；不自动切云端 |
| 预算耗尽 | 显示已用/上限；等待/申请预算/取消 |
| 权限撤销 | 停止执行；成果访问按策略；联系管理员 |
| 取消 | 请求取消；迟到结果丢弃；已生成成果保留只读 |
| 未知结果 | 先查询原运行；不自动第二次付费调用 |

### 8.6 键盘与焦点

- `Tab` 顺序：导航 → 输入 → `＋` 工具 → 上下文 → 执行器 → 权限 → 发送 → 结果。
- `Cmd/Ctrl + Enter` 提交；`Esc` 关闭模态/弹出层。
- 模态打开时焦点进入模态；关闭后回到触发按钮。
- 审批横幅出现时使用 `aria-live="polite"` 通知，但不抢焦点。

## 10. 可访问性

目标基线：**WCAG 2.1 AA**（颜色对比、键盘、焦点、表单、状态提示）；R0 以中保真原型做走查，正式审计在实现阶段完成。

### 10.1 要求

- 语义：`header/nav/main/aside`，标题层级连续。
- 键盘：所有交互可 Tab 到达；焦点环可见；无键盘陷阱。
- 模态：`role="dialog"`、`aria-modal="true"`、标题关联、Esc 关闭、焦点回归。
- 状态：`aria-live="polite"` 用于任务状态/审批出现；错误 `role="alert"`。
- 表单：label 关联、错误描述、必填标记；字数计数可读。
- 颜色：正文对比度 ≥4.5:1；状态不只靠颜色，配文字/图标。
- 动效：尊重 `prefers-reduced-motion`；不依赖动画传达状态。
- 触控：移动端点击目标 ≥44×44px。
- 屏幕阅读器：执行器/权限 chip 打开含说明的可选组（radiogroup）；审批按钮读清“批准本次/拒绝”。
- 首次使用：步骤进度可读；跳过/下一步有明确标签；关闭后焦点回到触发按钮。
- 管理面：表格有 caption/列标题；开关有可读标签；席位满/预算耗尽用文字+颜色双重提示。

### 10.2 测试清单

- Tab 走完首页 → 提交 → 任务 → 成果 → 采纳。
- 审批横幅出现时能读到原因和动作。
- 模态打开/关闭焦点正确。
- 200% 缩放不丢内容；窄屏不横向滚动。
- 高对比度/深色模式下状态可读。

### 11.2 Work 模式

- 白色卡片 + 浅灰画布；1px 边框；轻阴影只用于浮动层。

- 任务工作区信息密度高于首页；成果工作区更宽松，便于阅读。

### 11.3 动效

- 150–200ms；页面切换淡入/位移 4px；审批横幅出现不抖动布局。
- 加载用骨架/进度点，不用无限旋转大图。
- `prefers-reduced-motion` 时移除位移动画。

## 12. 原型说明

**文件**：[assets/work-ux-r0/prototype.html](assets/work-ux-r0/prototype.html)；管理面：[assets/work-ux-admin/prototype.html](assets/work-ux-admin/prototype.html)

打开方式：直接用浏览器打开；无外部依赖、无网络请求。

### 12.1 可体验路径

1. 首页输入任务描述 → 云端发送 → 任务执行 → 待验收 → 打开成果 → 采纳。
2. 首页点执行器 chip → 本机；点 `＋` 工具菜单 → 选择文件夹；发送 → 批准命令 → 成果写入 `WeMeet成果` → 采纳。
3. 我的工作 → 待处理 → 打开审批任务 → 批准/拒绝。
4. 任务页“状态演示”切换：执行中、等待审批、待验收、设备断线、失败、预算耗尽。
5. 成果页切换版本、对比、查看来源/复核、采纳。
6. 点权限 chip 切换默认权限/自动审批/计划批准后；确认没有“完全访问权限”。
7. 顶部切换深色/浅色；重置演示。
8. 点顶部“首次使用”走完 3 步引导；选择本机后授权文件夹，确认不会自动提交。
9. 导航“历史工作”查看只读归档与导出。
10. 左侧底部“打开管理面原型”→ 席位已满、预算告急演示；授予/撤销席位、调整预算、保存策略、导出审计。

### 12.2 原型限制

- 中保真，不是最终视觉；颜色/间距按 WeMeet token 近似。
- 无后端；任务进度、审批、成果为本地模拟。
- 筛选/搜索为静态演示；导出、重连、预算申请为提示反馈。
- 不含套件/连接器/项目/分享/富成果。
- 移动端为响应式布局演示；本机执行在手机端禁用，仅桌面可用。
- 管理面为独立原型，使用模拟数据；不接真实席位/预算/审计 API。
- 数据为演示文案，不代表真实模型输出。

### 12.3 评审重点

- 首屏是否能在 60 秒内完成提交。
- 用户是否理解“云端/本机”和“本次使用”。
- 首次使用能否在不看文档的情况下完成执行位置选择和第一个任务。
- 审批横幅是否说清批准/拒绝后果。
- 成果页是否让“采纳”成为明确动作。
- 我的工作是否让“需要你”可发现。
- 管理员能否在席位满/预算告急时找到下一步，并理解撤销/调预算的后果。

## 13. 可用性测试计划

### 13.1 参与者

- 5–8 名设计合作伙伴用户，覆盖知识工作者、本地重度用户、管理员。
- 每人 45 分钟；远程/现场均可；录屏 + 观察笔记。
- 使用中保真原型；主持人只读任务，不引导点击。

### 13.2 任务

| 编号 | 任务 | 成功标准 |
|---|---|---|
| T1 | 创建一份云端方案任务 | 60 秒内提交；能说出在云端执行 |
| T2 | 切换到本机并授权文件夹 | 找到文件夹授权；能说出原始文件不上传 |
| T3 | 处理一次命令审批 | 能说出批准/拒绝后果；完成批准 |
| T4 | 找到待验收成果并采纳 | 找到版本/采纳；完成任务 |
| T5 | 在我的工作中找到“需要你”任务 | 找到待处理并打开 |
| T6 | 首次使用导引中选择执行位置并开始第一个任务 | 能说出执行位置/边界；不被自动提交 |
| T7 | 管理员授予席位并调整预算 | 找到入口；理解席位满/预算告警 |

### 13.3 访谈问题

- 你刚才怎么判断任务在哪执行？
- 你提交前知道会读哪些文件吗？
- 审批横幅里你最关心什么？拒绝后你以为什么会发生？
- 成果页你怎么判断能不能用？
- 哪个地方让你犹豫/想找设置？

### 13.4 指标

- 任务完成率、完成时间、错误次数。
- 环境/数据去向正确复述率。
- 审批理解率。
- SEQ（Single Ease Question）≥5/7。
- 严重问题：P0 阻断、P1 高摩擦、P2 文案/视觉。

### 13.5 通过标准

- T1–T7 完成率 ≥80%；管理员任务 T7 至少 3 名管理员完成。
- 环境/数据去向正确复述 ≥90%。
- 审批理解 ≥90%。
- 无 P0；P1 在 R0a 开发前修复或明确接受。

### 13.6 研究执行包（U1，2026-10-26 准备）

| 项 | 内容 |
|---|---|
| 招募 | 5–8 名设计伙伴，覆盖 ≥3 家组织；知识工作者、本地重度用户、管理员各 ≥2 名；排除参与设计/评审者 |
| 筛选项 | 每周任务频率、是否使用 AI 办公工具、是否管理员、是否同意录屏 |
| 议程 | 5 分钟背景与知情同意；35 分钟 T1–T7；5 分钟访谈与 SEQ |
| 记录 | 录屏 + 观察笔记；仅记录任务/时间/错误/原话，不记录业务正文；使用匿名编号 |
| 产出 | 可用性报告（完成率/时间/错误/SEQ/问题分级）+ 修复清单；P0/P1 回写状态矩阵/文案 |
| 排期 | 2026-11-16 招募完成；11-20～11-24 执行；11-27 报告；DR3 2026-12-01 复核 |
| 负责人 | 产品 + 设计执行；前端/后端按修复清单回写 |

**边界**：本节只是执行包；未招募、未执行前 U1 不关闭，不得用内部走查替代设计伙伴数据。

## 15. 开放问题

| 问题 | 影响 | 建议 |
|---|---|---|
| 首页是否保留“继续工作” | 首屏信息密度 | 保留，最多 3 条 |
| 任务标题自动生成规则 | 历史列表可读性 | 取任务描述前 20 字 + 动词；可编辑 |
| 本机文件夹路径展示 | 信任/隐私 | 显示文件夹名；绝对路径只在系统选择器 |
| 审批横幅位置 | 视觉优先级 | 任务头部下方，不遮挡成果 |
| 成果编辑自动保存 | 版本噪音 | 手动保存 + 草稿状态；采纳才完成 |
| 复核是否默认开启 | 成本/等待 | R0b 可选；不默认 |
| 移动端是否支持编辑 | 范围 | R0 只读预览；编辑 R4b |
| 深色模式优先级 | 视觉工作量 | 实现时补齐；原型只演示浅色 |
| 历史工作保留期 | 过渡/合规 | 按产品留存策略；至少覆盖过渡期 |
| 首次使用是否可跳过 | 激活/合规 | 可跳过；组织可在 onboarding 中强调策略 |
| 管理面复用范围 | 交付/一致性 | 席位/权限沿用 P1-A；预算/策略/审计若已有后台则复用样式与 API |

## 16. 附录

### 16.1 状态与色板

| 状态 | 色板 | 用法 |
|---|---|---|
| 执行中/品牌 | 蓝 `#3370ff` | 主行动、选中、进度 |
| 等待审批 | 琥珀 | 横幅、状态 pill |
| 待验收 | 蓝绿 | 成果就绪、采纳提示 |
| 已完成 | 绿 | 完成摘要、采纳标记 |
| 失败/撤销 | 红 | 错误、权限撤销 |
| 断线/预算 | 灰/橙 | 暂停、等待 |

### 16.2 关键文案库

- 首页标题：今天想完成什么工作？
- 首页副标题：描述目标、交付要求和限制；其余按需展开。
- 本次使用：云端 · 不访问本机 · 交付 Markdown · 保存到任务。
- 本机授权：只读取你授权的文件夹；命令逐次批准；不是操作系统沙箱。
- 审批标题：需要你批准运行命令。
- 审批说明：只读；不会修改原文件；拒绝后任务暂停。
- 待验收：成果已生成，等待你验收。
- 采纳：采纳此版本后任务完成；其他版本保留。
- 断线：设备断线，执行待确认；不会自动切云端。
- 预算：今日预算已用完；申请预算或明天再试。
- 历史工作：只读归档；可查看和导出，不能新建运行。
- 首次使用：先从哪种执行位置开始？；提交前会显示执行边界；选模板只预填，不自动提交。
- 管理面席位满：席位已满；撤销或扩容后才能授予。
- 管理面预算耗尽：本月预算已耗尽；新任务暂停，已开始任务按原预算完成。
- 管理面撤销：撤销后不能创建新任务；历史任务与成果按留存策略处理。
