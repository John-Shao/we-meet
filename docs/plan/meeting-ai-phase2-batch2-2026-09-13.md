# 会议 AI 阶段 2：第二批（累计第八批）

日期：2026-09-13。基线：`8771dec6`。本批保存 Qwen ASR 的源观察结果，并贯通原文送达、不可变快照和纪要阅读。

## 实现与边界

- Agent 分别统计已观察流、供应商任务、输入采样数、final 句数、计费秒数和有限错误码。任务身份去重，冲突、溢出及未收尾流显式记为异常；不保存音频正文、密钥或供应商异常原文。
- writer 结束时冻结终态请求，HTTP 重试复用相同状态与观察报告。晚到事件不能修改已经提交的报告；有异常或未结束任务时不声明完整送达。
- 后端对报告进行严格校验，报告与送达终态一起保存。终态重放必须完全相同；失败报告不能以 complete 封口。已有无报告的 Agent 保持兼容。
- 原文快照包含报告并参与指纹；已生成纪要读取当时的观察结果。新增 source-status 接口仅允许有纪要阅读权限的用户访问准确记录的场次，使用游标分页和 private/no-store 响应。
- 页面分别呈现原文送达状态、已观察音频的 ASR 收尾状态、整场音频覆盖状态。即使供应商 task-finished 全部收齐，整场覆盖仍为未验证；没有输入任务时显示“未观察到音频输入”。
