# 阶段 3 第十三批（累计第三十三批）：录音纪要、修订与问答入口

录音页面可展开「智能纪要与问答」，复用现有最终纪要请求、历史版本、人工修订、行动项确认和原文快照问答面板。入口按后端可用性展示；关闭生成开关后已有纪要仍可阅读。

- 引用先读取对应版本原文，核对 ID／修订号／时间，再提供原音回听按钮。未授权、读取失败或原文尚未返回时不提供回听引用操作；底层播放器重新校验音频权限。
- 独立录音联动测试涵盖人工修改和私人问答；问答费用保持原记录组织归属，用户后来加入组织不改变个人记录的费用归集。
- 本批走查修复第 31 批逐字稿分页契约：后端实际返回 `next_cursor`，前端此前误读为 URL 字段 `next`。新增真实数据库 31 条原文的两页读取测试及前端前后翻页测试。
- 浏览器截图发现并修复早期阶段总结／自动总结／会中文字页面的中文问号文案。单元测试使用键名替身无法发现此问题，现补实际中文界面检查。

验证：后端独立纪要／问答／人工修订 25 项与转写 13 项通过；前端相关 24 项通过；Ruff、ESLint、应用 TypeScript 与生产构建通过。原生 Chromium 合成麦克风、模拟 HTTP 流程包含录音、转写、纪要生成、引用展开和原音回听。没有实际 LLM、Docs 或 IM 调用。

统一资料库与跨浏览器找回入口继续实施；当前完整记录仍可由已有 API 读取，录音页历史本身只覆盖此浏览器本地日志。多人频道同传、Android、实时独立转写／总结和 Docs 交付依赖仍未完成，不能宣布总体首版交付。
