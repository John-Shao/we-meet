# 阶段 3 第二十一批（累计第 41 批）：纪要文档导出页面

AI 版本、已保存的人工修订和历史人工版本现在均提供文档导出入口。展开后预览明确版本的文档内容，再确认创建；现有导出显示状态、打开文档或预览原副本后重试。

- 中文/英文章节标题可选，正文保持原文，界面明确说明不执行翻译。
- 网络不确定时在 sessionStorage 保留最小请求标识和哈希，不存正文或凭证；重载后重发完全相同的请求。记录、用户、版本、语言相互隔离。
- 更换版本/语言会丢弃旧预览，关闭/切换账号会中止旧页面请求。预览变化、尝试次数变化、权限失败都不能直接沿用旧确认。
- 已完成或不可用的文档不显示重建按钮。Docs 服务地址变化时隐藏旧文档链接，避免把旧 ID 导向另一服务。
- 预览按文档排版显示，禁止 HTML、外部图片和链接元素；待办仍需在任务入口另行确认。文档仅为请求人创建，不自动共享。

验证：前端 26 项通过（10 项新导出、16 项既有纪要/人工修订）；后端预览/请求 10 项通过；TypeScript、ESLint、Ruff、差异检查和生产构建通过。Chromium 验证桌面与 390px 手机排版、明确确认、断网重载同键同体重发、文档链接和权限撤销，截图已检查。所有 HTTP 写入均被测试替身拦截，没有真实创建文档。
