# 阶段 3 第三十七批（累计第 57 批）：私人译文留存后端

私人同传和双向语音翻译新增明确的保存选项，复用原会议场次笔记，档案按发起人单独隔离。此批为后端契约，下一批接入 Agent 与 Web。

- 开始请求可传 `save_translations`；默认不保存。记录和留存开关均开启才允许创建档案，重复意图复用原档案，不创建第二份笔记。
- 内部 `/api/agent/translations/segments/` 严格核验运行、Worker、代次、会议 SID 与本人原始参与连接；共享会议中的其他发言人不能写入私人档案。
- 同传仅接受正向译文，按住说话模式接受正反两个方向，各方向冻结目标语言。相同供应商项目标识在不同方向相互独立，同一方向重试不可改写正文。
- 查询同时要求当前原文阅读权限和档案所有者身份。其他会议管理员即使可读原文也看不到私人档案；取消原文权限后，所有者也不能继续读取。
- 保存完成使用独立回执；缺少回执、超时或源运行删除均标记不完整，保留已经保存的内容。私人源连接离开后拒绝新译文。
- 运行中关闭私人翻译开关，现在会在下次心跳停止输入且不再授权尾段输出；原先仅阻止新启动。普通显式停止仍允许有权限的限时尾段。新写入同样检查开关，原内容的精确重试仅返回回执。

验证：19 项新增测试与 36 项既有共享档案/私人控制回归，共 55 项通过；Ruff、迁移一致性和差异检查通过。无新增迁移，无真实模型、音频、部署或外部消息。Agent/Web 尚未接入此契约，部署时须等待下一批配套版本。
