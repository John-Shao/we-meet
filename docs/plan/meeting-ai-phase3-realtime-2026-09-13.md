## 阶段 3 第二十九批（累计第 49 批）：多人同传频道与收听订阅契约

新增共享目标语言频道，独立于既有个人双向/连续翻译。管理者控制频道生命周期，参会者只改变本人连接的收听选择。

- 按确定会议场次、目标语言和生成代次隔离；中/英每种目标同时最多一个活动频道。创建频道先进入准备状态，有人明确收听后进入待启动状态。本批不调度模型或处理音频。
- 只有会议当前管理者可以启停；具备真实在线标准参与连接且满足组织条件的账号可以收听。材料共享权限或普通访问链接不构成收听资格。
- 订阅绑定具体参与连接，20 秒租约、独立版本号；切换目标语言后旧心跳失效，过期必须重新订阅，重连不会继承旧设备的选择。明确退订不停止其他听众。
- 每次控制保存请求回执，重放只返回原结果，不重做旧选择。公共接口仅返回本人连接与订阅；内部来源/目的身份不得发给普通客户端。
- 内部授权快照只选择当前标准参与者，排除 Agent；最多 16 个音源、100 个听众，超过音源上限明确失败，不静默截取部分会议。费用责任固定在频道发起者，不随听众变动。

验证：13 项数据库/API 测试通过，包含并发选择、频道唯一性、个人退订、旧请求与心跳、重连、跨场次/账号、组织退出、管理者撤权及源上限。0170 已在隔离数据库迁移；迁移一致性、Ruff 与差异检查通过。

`MEETING_INTERPRETATION_ENABLED` 默认关闭，`ROOM_INTERPRETATION_AGENT_NAME` 默认为空。Worker 调度/认领/音频与 Web 收听尚未接入，部署时不得提前打开此功能。下一批完成服务端 Worker 生命周期，随后连接多人音轨和端侧音频处理。

## 阶段 3 第三十批（累计第 50 批）：共享同传 Worker 生命周期

共享频道接入现有周期任务，补齐调度、唯一认领、授权心跳及终态回执。仅待启动且有有效听众的频道会调度专用 Agent；不复用个人翻译 Worker。

- 认领绑定频道、场次 SID、会议 ID、代次和 Worker UUID。重复调度只有一个认领者；相同进程的认领重放返回当前授权。认领后不再次调度模型执行。
- 启动期限固定为首次订阅后的 60 秒；Worker 心跳租约 15 秒，停止收尾最多 25 秒。调度重试和心跳不会无限延长期限，过期后的成功回执不能覆盖失败状态。
- 普通停止先关闭新输入，向仍有资格的听众送达尾段后结束；撤权、组织变化、功能关闭或音源超限时停止输出。没有有效听众时结束频道，继续使用需明确新开频道，不自动重启收费链路。
- 内部 API 复用现有 Agent 密钥鉴权，普通用户不能取得其他人的音源/输出身份。回执中的实际 usage 可为空，不把未知费用当成零。
- 周期检查轮转已检查频道，不让准备中的空闲频道挡住后续任务；轮转不会更新 Worker 心跳。

验证：15 项 Worker 测试及 13 项频道回归通过，覆盖并发认领、尾段与撤权分流、听众退出、启动/停止期限、晚到回执、调度错误脱敏和公平检查。0171 已在隔离数据库迁移；迁移一致性、Ruff 和差异检查通过。没有调用实际 LiveKit 调度或模型。

开关继续关闭；本批是服务端执行契约，专用多人音频 Agent 与 Web 频道收听尚待下一批接入。部署需保留现有 Worker/周期任务，并在后续 Agent 实现后配置 `ROOM_INTERPRETATION_AGENT_NAME`。总体 M3/M4 仍未完成。

## 阶段 3 第三十一批（累计第 51 批）：共享同传 Agent 授权层

新增专用频道的内部回报客户端和本地授权租约，为多人音频执行器提供一致边界。

- 调度元数据只允许频道 ID、代次、会议 SID，不能携带模型、凭证或接收者覆盖。内部请求固定服务地址与 Worker UUID，限制响应大小并拒绝其他频道/代次响应。
- 认领和结束回执可有限重试，保持同一身份和请求内容；心跳失败不重试，不维持旧输出。正常停止的尾段必须另带明确许可和最新听众名单。
- 用单调时钟检查 15 秒本地授权期限。任何非法、缺失、超限或重复的授权响应先清除旧权限；同一频道不能中途变更模型或目标语言。
- 来源与接收者同时验证 LiveKit 身份、具体参与 SID 和标准人类参与类型，重连与 Agent 轨道不继承旧授权。断开事件可先于下次心跳立即移除该连接。

验证：11 项新增授权/回报测试及 12 项个人翻译控制回归通过，Ruff 与差异检查通过。所有网络调用为模拟，没有模型调用。专用多人音频运行时尚待下一批接入，因此频道开关继续保持关闭。

## 阶段 3 第三十二批（累计第 52 批）：共享同传音频 Agent

新增 `src/agents/qwen_interpretation_agent.py`，接通上一批的频道授权与独立发言人音频执行器。

- 以 `SUBSCRIBE_NONE` 入会，认领频道代次后先设置译音轨道的服务端收听 ACL。只订阅授权名单中、参与 SID 一致的标准参与者麦克风，排除屏幕声音及 Agent 输入。
- 每位发言人使用独立的 Qwen 实时翻译会话和译音轨道，16 kHz 单声道输入、24 kHz 单声道输出。握手成功后才开始接收音频并通知轨道就绪；启动期间的内容不承诺转译。
- 输入采用单个有界 FIFO，最多暂存一秒 PCM；超限明确中断整个频道。音频会话失败不自动重连、不重放音频；同一参与记录的麦克风轨道替换或结束后重建也会中断频道，需要显式重新开启。
- 译文逐人定向发送，携带频道、代次、发言人参与记录/SID、译音轨道及接收者订阅 ID/修订号。保留 response/item 标识用于前端去重。单包上限 14,000 字节，超限失败；一位接收者发送失败时取消其余待发送任务，避免遗留后台队列。
- 新收听者或新订阅修订号会收到已有轨道的就绪信息。授权过期、断开或成员种类/SID 不一致时停止输出；断开事件立即更新服务端 ACL。LiveKit ACL 按 identity 生效，本地同时检查具体 SID，Web 仍须以当前连接和订阅修订号校验数据。
- 正常停止只有后端明确授权的听众能收到尾段。权限撤销直接中止待发送输入和输出。完成回执分别记录供应商结束和本地消费完成；本地消费完成不表示远端用户已经听到。任一响应缺少的用量字段保持未知。

验证：15 项运行时测试，加授权、个人翻译控制和 Qwen 协议回归，共 53 项通过；Ruff 与差异检查通过。全部使用模拟音频/网络，没有模型调用或实际会议接入。

部署要求：复用 Agent 镜像，新增独立工作负载，命令为 `python qwen_interpretation_agent.py start`；Agent 和后端配置相同 `ROOM_INTERPRETATION_AGENT_NAME`，并配置现有 LiveKit、内部 Agent 鉴权和 DashScope 环境变量。不要替换原转写 Agent 的启动命令。后端须包含迁移 0170/0171 并运行 Celery worker/beat。

频道开关继续默认关闭。下一批完成 Web 收听与频道控制后，才进入部署联调；多人重叠发言的听感、网络延迟和实际供应商兼容性由真实会议测试验证。完整 M3/M4 及最终技术评审仍未完成。

## 阶段 3 第三十三批（累计第 53 批）：共享同传 Web 协议边界

本批补齐 Web 收听所需的订阅身份和租期字段，并提供前端事件校验与有限译文列表。

- 订阅查询和续期结果增加真实订阅 ID，以及服务端计算的剩余秒数；失效或撤销的订阅返回零。客户端以请求发出时的单调时钟计算保守截止时间，不使用客户端日期推测服务器租期，也不把响应延迟算作额外授权。
- 译文必须同时匹配频道、代次、目标语言、订阅 ID 和修订号，来自频道对应的 Agent；验证发言人参与 ID/SID、音频轨道 SID、response/item 标识，拒绝非法 UTF-8、超大包和非翻译事件。
- 各发言人独立去重，确认译文不能被较早的候选文本覆盖。前端只保留最近 60 条，不写入正式逐字稿。

验证：5 项前端协议测试、28 项频道与 Worker 后端测试通过，TypeScript、ESLint、Ruff 和差异检查通过。没有数据库迁移，没有真实会议、模型或消息发送。下一批接通实际收听生命周期和会议内界面；频道开关仍默认关闭。

## 阶段 3 第三十四批（累计第 54 批）：会议内共享同传收听

会议工具新增“会议同声传译”，与个人语音翻译入口并列。

- 管理员可开启/结束中文或英语频道，结束按钮明确影响全部收听者；实际参会人可自行加入、切换语言、停止个人收听或只静音译音。开启频道不会自动替管理员订阅，停止个人收听不结束其他人的频道。
- 收听状态放在会议范围的 Provider，关闭工具面板仍继续收听。用户切换、会议/参与 SID 变化、断网、Agent 断开或授权错误均撤销本地音频和译文；后台存在订阅不会自动播放或自动恢复续期。
- 只有明确选择且订阅结果已核对时才续期，每 5 秒使用相同连接、频道和修订号续期。以请求起点的单调时钟计算剩余授权，过期或续期错误立即停止；不会把响应延迟算成额外租期，也不会自动重新加入。
- 视频会议及呼叫界面的通用音频渲染器均排除未经授权的同传轨道。当前订阅、频道代次、Agent 身份/SID 及具体轨道就绪信息全部匹配后才挂载音频元素；切换语言、静音或撤权会卸载。原有麦克风、屏幕声音和个人翻译播放流程保留。
- 开始/停止频道和加入/退出订阅都先保存确切操作意图。丢失响应后使用原 key、原修订号核对，重载不自动提交；旧回执不会被当作新的收听授权。读取和写入增加超时。
- 译文显示发言人和确认状态，最多保留最近 60 条。取消发布的轨道清除本地缓存。Agent 每 10 秒补发当前轨道信息，处理首次就绪事件早于 Web 收到订阅响应的情况。

验证：31 项前端同传/个人翻译测试通过，其中新增生命周期、音频挂载、界面交互共 14 项；54 项 Agent 测试通过。TypeScript、ESLint、Ruff、JSON 校验及生产构建通过。原生 Chromium 检查桌面及 390 px 手机界面的收听、全员结束和不确定结果恢复，截图已查看，无横向溢出。构建仅有原有资源与分包警告。

所有检查均使用模拟上下文或截获的请求，没有真实录音、会议、模型调用或部署。真实多人听感、浏览器自动播放、手机后台行为和服务端 ACL 撤销时延需部署后联调。

本批共享同传的后端、Agent 与 Web 链路可以进入部署验证：后端迁移 0170/0171、Celery worker/beat、独立 `qwen_interpretation_agent.py start` 工作负载，并在前后端/Agent 同步更新后启用 `MEETING_INTERPRETATION_ENABLED`。开关仍默认关闭。T04 译文关联、独立录音实时链路、Android 及最终全量技术评审仍待完成。

## 阶段 3 第三十五批（累计第 55 批）：确认译文关联会议笔记

新增独立译文档案与确认片段表，不复用或改写正式逐字稿。此批完成共享频道的后端契约，Agent 投递与 Web 保存/阅读入口随后接入。

- 开启频道时可以明确传入 `save_translations: true`。只有记录及译文留存开关都启用才接受；在同一事务内绑定准确会议场次的笔记，重用该场次唯一的记录，不根据标题或“最近会议”猜测来源。默认不留存。
- 每个档案冻结频道 ID、代次、所有者、记录及配置。确认片段以发言人参与记录、方向和供应商 response/item ID 幂等保存；重试相同内容返回原回执，不同内容不能覆盖。并发操作共用一条序号和字节计数。
- 内部写入口要求专用 Agent 鉴权、认领 Worker、会议/SID/代次一致，以及当前频道和组织权限。只接收标准参与者的确认译文；允许正常停止的限时尾段，不接收候选文本、旧 Worker 或结束后的新片段。
- 单档案最多 20,000 个片段、8 MiB 文本；超限不部分落库。译文写入不更新正式原文或其修订号。精确重试只返回无正文回执，不重新写入，即使功能已关闭或执行已结束。
- 查询在分页前后检查当前原文阅读权限，仅参会或仅能阅读纪要均不够。档案每页 30 项、片段每页 50 项，序号稳定；未来私人档案按所有者进一步过滤。当前共享频道不会因为收听而创建资料权限。
- 片段明确标记时间为 `delivery`，原文引用为 null。供应商目前未提供可验证的逐句源音频对应关系，不能把到达时间用于精确回听或冒充正式原文引用。
- 档案完成由独立 `archive_finished` 回执确认；供应商/本地音频完成不等于留存完成。Worker 超时、缺少档案回执或删除运行中的频道均标记档案不完整，已保存译文仍保留于原笔记。

验证：20 项新增后端测试及 28 项频道/Worker 回归通过，新增项包括并发去重、分页、权限撤销、超限、尾段和源频道删除。Ruff、迁移一致性及差异检查通过。迁移 `0172_translation_archives` 已在隔离普通库和测试库应用，仅新增两张表，没有变更录音转写表。

新增开关 `MEETING_TRANSLATION_ARCHIVE_ENABLED` 默认关闭。待下一批 Agent/Web 完成后，部署迁移与兼容版本再开启。未真实录音、调用模型、发送消息或部署生产。T04 的私人/独立录音适配及完整首版仍未完成。

## 阶段 3 第三十六批（累计第 56 批）：共享译文保存与阅读
