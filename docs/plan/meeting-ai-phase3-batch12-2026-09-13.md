# 阶段 3 第十二批（累计第三十二批）：独立录音纪要来源适配

已成功发布的独立逐字稿接入现有 Qwen3.8-Flash 纪要任务、不可变输入快照与引用校验。没有创建占位 MeetingSession，也不复制到旧在线 Transcript 表。

- 显式开关 `MEETING_CAPTURE_SUMMARY_ENABLED` 默认关闭，同时要求原记录／采集／版本化生成／请求与 Celery 开关。当前原文所有者才能生成；共享只读授权不允许支出。独立录音暂只支持保存并转写完成后的最终纪要，不开放在线实时／速记自动开关。
- 来源固定为一份独立录音及其已发布 ASR 版本，引用保留实际原文 ID 和修订号。校验连续文字序号、最终数量及内容指纹；缺失、未发布、静音无文字或来源篡改均阻止生成。
- 缺片音频即使可用部分 ASR 已结束，纪要仍保留来源不完整状态；不声称录音或识别覆盖完整。重新转写发布后取消旧来源执行，历史纪要和输入快照保留。
- 总结仍执行全量来源预算、结构检查、一次执行和当前权限复核。费用回调保留请求人及原记录组织，个人来源不按后来组织身份归集。

验证：既有在线纪要／请求／权限／计费 79 项回归、独立来源 8 项、自动生成／采集边界 20 项通过；Ruff 通过。新增功能不需要迁移，最新迁移仍为 0165。没有真实 LLM 调用；下一批在录音页复用现有纪要、人工修订和问答面板。
