# 阶段 3 第三十四批（累计第 54 批）：会议内共享同传收听

会议工具新增“会议同声传译”，与个人语音翻译入口并列。

- 管理员可开启/结束中文或英语频道，结束按钮明确影响全部收听者；实际参会人可自行加入、切换语言、停止个人收听或只静音译音。开启频道不会自动替管理员订阅，停止个人收听不结束其他人的频道。
- 收听状态放在会议范围的 Provider，关闭工具面板仍继续收听。用户切换、会议/参与 SID 变化、断网、Agent 断开或授权错误均撤销本地音频和译文；后台存在订阅不会自动播放或自动恢复续期。
- 只有明确选择且订阅结果已核对时才续期，每 5 秒使用相同连接、频道和修订号续期。以请求起点的单调时钟计算剩余授权，过期或续期错误立即停止；不会把响应延迟算成额外租期，也不会自动重新加入。
- 视频会议及呼叫界面的通用音频渲染器均排除未经授权的同传轨道。当前订阅、频道代次、Agent 身份/SID 及具体轨道就绪信息全部匹配后才挂载音频元素；切换语言、静音或撤权会卸载。原有麦克风、屏幕声音和个人翻译播放流程保留。
- 开始/停止频道和加入/退出订阅都先保存确切操作意图。丢失响应后使用原 key、原修订号核对，重载不自动提交；旧回执不会被当作新的收听授权。读取和写入增加超时。
- 译文显示发言人和确认状态，最多保留最近 60 条。取消发布的轨道清除本地缓存。Agent 每 10 秒补发当前轨道信息，处理首次就绪事件早于 Web 收到订阅响应的情况。

验证：31 项前端同传/个人翻译测试通过，其中新增生命周期、音频挂载、界面交互共 14 项；54 项 Agent 测试通过。TypeScript、ESLint、Ruff、JSON 校验及生产构建通过。原生 Chromium 检查桌面及 390 px 手机界面的收听、全员结束和不确定结果恢复，截图已查看，无横向溢出。构建仅有原有资源与分包警告。

所有检查均使用模拟上下文或截获的请求，没有真实录音、会议、模型调用或部署。真实多人听感、浏览器自动播放、手机后台行为和服务端 ACL 撤销时延需部署后联调。

本批共享同传的后端、Agent 与 Web 链路可以进入部署验证：后端迁移 0170/0171、Celery worker/beat、独立 `qwen_interpretation_agent.py start` 工作负载，并在前后端/Agent 同步更新后启用 `MEETING_INTERPRETATION_ENABLED`。开关仍默认关闭。T04 译文关联、独立录音实时链路、Android 及最终全量技术评审仍待完成。
