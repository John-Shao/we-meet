# 阶段 3 第三十批（累计第 50 批）：共享同传 Worker 生命周期

共享频道接入现有周期任务，补齐调度、唯一认领、授权心跳及终态回执。仅待启动且有有效听众的频道会调度专用 Agent；不复用个人翻译 Worker。

- 认领绑定频道、场次 SID、会议 ID、代次和 Worker UUID。重复调度只有一个认领者；相同进程的认领重放返回当前授权。认领后不再次调度模型执行。
- 启动期限固定为首次订阅后的 60 秒；Worker 心跳租约 15 秒，停止收尾最多 25 秒。调度重试和心跳不会无限延长期限，过期后的成功回执不能覆盖失败状态。
- 普通停止先关闭新输入，向仍有资格的听众送达尾段后结束；撤权、组织变化、功能关闭或音源超限时停止输出。没有有效听众时结束频道，继续使用需明确新开频道，不自动重启收费链路。
- 内部 API 复用现有 Agent 密钥鉴权，普通用户不能取得其他人的音源/输出身份。回执中的实际 usage 可为空，不把未知费用当成零。
- 周期检查轮转已检查频道，不让准备中的空闲频道挡住后续任务；轮转不会更新 Worker 心跳。

验证：15 项 Worker 测试及 13 项频道回归通过，覆盖并发认领、尾段与撤权分流、听众退出、启动/停止期限、晚到回执、调度错误脱敏和公平检查。0171 已在隔离数据库迁移；迁移一致性、Ruff 和差异检查通过。没有调用实际 LiveKit 调度或模型。

开关继续关闭；本批是服务端执行契约，专用多人音频 Agent 与 Web 频道收听尚待下一批接入。部署需保留现有 Worker/周期任务，并在后续 Agent 实现后配置 `ROOM_INTERPRETATION_AGENT_NAME`。总体 M3/M4 仍未完成。
