# ADR-0023 静态单层凭证加密，云 KMS 缓接

状态：Accepted（D-03 B 于 2026-10-27 签收；云 KMS 部分按 #40 A 裁为带重开条件的范围例外）
日期：2026-10-27
范围：R0a 凭证与正文密钥管理；不证明生产就绪。

## 决策

采用静态服务密钥＋单层静态凭证加密（全局主密钥＋按 `org_id` 派生）；云 KMS 在试点期不接，单主密钥不轮换，作为带重开条件的范围例外。

## 背景

完整 KMS 信封加密与轮换是目标态，但 R0a 试点需要一个可立即落地、可审计的密钥面。在演示组织＋演示数据的前提下，静态单层加密的风险可接受；一旦接触真实客户数据，该例外必须重开。

## 关键约束

- 正文 AES-256-GCM 按 org 派生密钥加密；PG 只存 `content_ref/hash/bytes`。
- 凭证只写不回读、可即时吊销、强审计。
- 试点期单主密钥不轮换；key_version 重加密未实现。

## 放弃的方案

- 方案 A（立即接云 KMS + 轮换）：试点期成本与依赖过高，且无真实客户数据时收益有限。
- 方案 B（多层信封）：增加复杂度，R0a 不承担。

## 影响

- 正面：密钥面可立即落地、可审计；Content Store 本地实现已上线。
- 代价：单主密钥不轮换是已知局限；Content Store 零真实请求，重加密/留存清扫未实现。
- 后续必须验证（重开条件）：接触真实客户数据前接云 KMS 并实现轮换；外部安全审计（J39）。
