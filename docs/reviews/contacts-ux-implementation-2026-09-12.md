# 通讯录 UX 优化交付记录

工作分支：`fix/contacts-ux`，基于 `origin/aliyun-dev@747485aa`。本记录覆盖实现与验证；不包含合并或部署。

## 已完成

- 部门浏览优先显示名单，窄屏通过“部门资料”按钮查看资料。
- 窄屏详情复用 Modal，支持 Escape、焦点约束与关闭后的焦点恢复；关闭同步清除成员/群参数。窄屏打开成员或群资料写入浏览历史，浏览器后退能返回原列表。
- 小屏通讯录导航改为弹窗；通讯录页面的应用主导航默认收起，仍可手动展开，且不覆盖桌面导航偏好。
- 星标行保留“发消息”作为快捷动作，取消星标由详情开关完成，可再次打开恢复。
- 星标匹配服务端姓名/简称拼音键，覆盖全拼、首字母、大小写、空白与音标折叠；筛选计数按结果显示，零结果可清空搜索。
- 切换部门或搜索时，用加载状态替代旧名单，防止新标题下出现可操作的旧成员。
- 发消息、偏好开关及外部联系人操作提供等待/禁用状态，阻止重复提交；特别提醒失败使用独立文案。
- 外部联系人及联系人申请分别显示加载错误与重试入口；刷新失败保留缓存内容。
- 外部账号查找区分初始、加载、无结果、失败状态；输入变化立即清除旧结果，过期响应不能覆盖新输入；接受/发送失败保留结果并允许重试。
- 成员详情显示离职说明，隐藏离职者的星标与特别提醒开关；保留历史沟通入口，由现有后端权限决定是否允许。深链详情提供加载、失败、无权限、不存在及重试反馈。
- 新增文案覆盖中文、英文、法文、德文、荷兰文。

## 集成注意

服务端仅在成员序列化结果增加已有 `User.search_key` 字段，无数据库迁移。前端字段为可选，兼容旧响应；完整星标拼音搜索需要前后端一起更新。该字段只包含姓名与简称派生的搜索词。

真实登录、IM 服务、后端数据库集成、读屏及其他视口的完整验收尚未执行。建议在已有后端测试环境运行 `core/tests/test_api_directory_contact_prefs.py` 与 `core/tests/test_api_directory_search_pinyin.py`，然后使用真实开发账号复核消息跳转和联系人申请流程。
