# 双语互译长句中断与内部诊断版

用户在荣耀 300 / Android 16 反馈：“我明天上午 9 点去火车站，然后乘坐高铁去上海参加会议”，译音只播到 “at nine”，页面提示翻译中断。**根因尚未确认，0.3.0-work.6 是诊断增强，不是已确认的截断修复。**

## 当前证据

- 14:46 附近两次会话已取得票据、建立连接并产生译文输出，不能与 14:31 的票据 HTTP 502/503 混为同一故障。两次结果输出到服务端记录中断分别约 14.291 秒、5.170 秒，不能据此认定固定五秒超时。
- 使用 Windows 合成的同一句话，经生产镜像内的独立探针和真实模型验证，自动与固定方向均得到一条完整译音和结束边界；返回词项包含九点、上海、会议。未保存模型原文、译文或输出音频；词项命中不等于完整语义验收，也不覆盖荣耀实际播放。
- OPPO / Android 12 的真实 AudioTrack 回归一次送入 12 秒 PCM，确认全部样本写入、播放头排空、输入 ACK 持续、会话未断开。输入与业务连接均为测试替身，PCM 为零值；不标为人工听感或真实语音端到端验收。
- 当前普通手机无法通过 ADB 取日志；原页面把多个失败原因归并为同一提示。诊断版增加 BT01～BT18 固定错误编号，使下次复现可以区分输入中断、输出失败、ACK 超时、播放排空超时和服务端错误。没有增加原文、译文或音频上传。
