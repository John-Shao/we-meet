# Work 单账号联调准备（2026-10-07）

本批补齐新 Agent 功能的账号准入，默认 `closed`，统一覆盖云端 Agent、本地设备协调、远程工作空间派发和 Pi 审查。`allowlist` 只接受已有活跃真实用户的 UUID；空名单、无效 UUID 或未知模式关闭准入。原有功能开关和权限同时生效，普通 Work 材料及 communication 沿用现有能力。能力接口按账号返回并禁止缓存；后台 Outbox 在提交前与回收结果时重新核验账号，避免只限制 UI。

撤销准入后，新任务、设备注册、工作空间登记、远程派发和领取停止。未提交 Gateway 的云端任务失败且不发起请求；已提交任务仅取消并继续用量对账。本地下一次状态回报要求停止，不能撤销已发生的本机文件操作。原权限下的历史读取、取消和成功成果主动同步保留。

用户指定的演示账号已只读核验：数据库唯一匹配、活跃、具有真实身份、非设备账号，生产演示 OTP 配置有效。随后使用真实 HTTPS OTP API 登录，认证资料中的 UUID 与数据库核验一致，Work 能力接口返回四个新功能关闭、普通 Work 和材料开启。这是实际账号和 HTTP 认证验证，尚不等于 Android/Electron 原生登录界面联合验收。手机号、OTP、token 和实际准入 UUID 不写入本回执；token 仅驻留本机验证进程内存，未保存。未发送真实短信、未创建业务任务、未调用模型。

本地使用独立内部 Docker 网络、PostgreSQL 16 和 Redis 7，无端口发布或供应商网络访问。完整 Work 回归 106 项通过、6 项显式 SDK/客户端 opt-in 跳过，包含新增账号隔离和撤销测试 19 项。发布相关测试 52 项通过，覆盖私有准入 overlay 的九个后端模板消费者、真实 Helm 部分模块发布、现有 CI 门禁及会议 AI 发布脚本。Ruff、Bash 语法、迁移一致性和 git diff 检查通过。新增 Work 回归接入 Release guard CI。

生产仍运行原已验收业务镜像，四个新功能开关保持关闭；本批准入代码尚未部署，无数据库模型/迁移变化。下一批准备本源码的不可变候选镜像及单账号启用清单；先部署准入代码并保持关闭，再单独评审本地/远程入口、桌面文件夹授权、命令和文件修改审批，以及模型调用预算。Gateway 当前为合成材料审查验收配置，不能据此直接开启业务审查或云端执行。
