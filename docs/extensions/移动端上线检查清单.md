## 7. 部署后冒烟（逐接口）

用 demo 手机号取 `<access_token>` 后：

- [ ] `POST /api/mobile/auth/send-otp/`、`verify-otp/` —— 响应键、400/429 行为
- [ ] `GET /api/v1.0/users/me/` —— 含 `intro`/`avatar_url`/`cover_url`
- [ ] **三步上传**：`POST users/me/upload-url/` → `PUT` 图片到 OSS → `PATCH users/me/profile-image/` —— 重点验证 OSS 签名（见第 2 节风险）
- [ ] 上传后 `GET users/me/` 的 `avatar_url` 为可访问的签名 URL
- [ ] `POST /api/v1.0/rooms/` 建房 —— 响应含 6 位 `meeting_code`
- [ ] `GET /api/v1.0/rooms/{meeting_code}/` —— 用会议号能取到房间 + `livekit` token
- [ ] `POST /api/v1.0/rooms/{id}/end/` —— 返回 `ended_at`；结束后再 GET 该房间**无 `livekit` 块**（禁止重进生效）
- [ ] `POST /api/v1.0/users/me/deregister/` —— 返回 204
