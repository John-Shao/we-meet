# 后端管理助手提示词

告别结束通话：执行 `python manage.py extend_end_call_commands`，向现有结束通话规则和工具说明追加“再见”“拜拜”及“再见了”“拜拜了”“那就再见吧”“好啦，拜拜”等自然派生说法。用户向当前 AI 通话告别时直接调用 `end_call({})`，沿用现有资源释放流程。否定、询问、翻译、假设、引用、角色扮演及 AI 自己的告别不触发挂断。命令幂等并保留管理员编辑、启停状态和其他提示词；无需数据库迁移或更新 APK，新通话读取新规则。

2026-10-10 已在生产启用告别挂断扩展，原正文已备份，核对其他提示词及启停状态保持一致。61 项相关后端测试通过，覆盖配置追加幂等、异常目录不部分修改和新会话无需重启读取规则。Pixel 7 Pro 的五项真实模型回归通过：四种 AOQ 合成语音告别、语音/视频资源释放，以及 WebRTC 文本告别；否定、词义询问、翻译、假设和引用均保持通话。独立告别明确视为挂断授权，即使上一轮解释过告别词也必须调用工具。测试验证工具调用一次、正常结束状态和租约释放，不代表真人麦克风或弱网验收。

扩展再次拍图指令：执行 `python manage.py extend_photo_qa_commands`，向现有两条拍图工具提示词追加“再看看”“再看一下”及“你再看看”“再看一下嘛”“帮我再看看”“再帮我看一下”等自然派生说法。每次重新拍摄；没有新问题时沿用上一轮拍图问题，无上下文时描述眼前主要物体。否定、引用、假设和用法询问不触发拍图，明确的摄像头开关仍使用模式切换工具。命令可重复执行，保留后台编辑、启停状态和其他提示词；无数据库迁移或客户端更新。新通话读取新规则。

2026-10-10 已在生产数据库追加两条扩展规则，核对其他提示词及启停状态均保持一致；原正文已备份。56 项后端测试通过，覆盖命令幂等、后台编辑保留、异常目录不产生部分更新，以及无需重启便向新会话下发扩展规则。Pixel 7 Pro 的 AOQ 合成语音测试通过：“帮我看”之后四种新说法各拍一张新照片，保持同一连接、租约与语音模式；随后打开摄像头、视频拍图、关闭摄像头仍按原规则执行。使用实际 Camera2 和生产视觉接口，未保存照片到测试归档；不代表真人麦克风或弱网验收。

拍图问答新增三条系统提示词：`call.tool.photo` 定义单次拍图意图与模式切换的边界，`call.tool.description.take_photo` 是工具说明，`call.photo_qa` 是视觉问答系统指令。数据迁移 0200 只添加缺失记录，保留已有后台编辑和启停状态，不修改旧摄像头提示词。

客户端在通话分配时传 `photo_qa=true`，后端先校验三条提示词，再分配连接。“帮我看”等单次视觉请求调用 `take_photo(question)`；明确的“打开摄像头／关闭摄像头”继续调用 `set_camera_enabled`。拍图规则在摄像头规则之后拼接，并声明单次看图优先级，避免泛化看图请求误开持续视频。

图片仅在内存中处理：语音模式临时使用后置摄像头，视频模式取当前镜头的新帧；拍图不切换模式。App 将最终 JPEG（不超过 512 KB）和模型从本轮语音理解出的完整问题发往 `POST /api/v1.0/ai-call/photo/`。该接口绑定用户正在使用的通话租约，调用 `AI_CALL_PHOTO_MODEL`（默认 `qwen3.8-flash`），工具将视觉回答返回原实时模型，由当前通话音色回答。视觉接口收到语义问题和图片；原始音频继续由实时 Omni 接收，未重复上传给视觉接口。照片不写入相册或历史，也不作为工具输出或日志内容。

先部署后端并应用 0200，再安装支持拍图的客户端。新客户端需要上述提示词；旧客户端默认不请求拍图能力，原通话行为保持兼容。

客户端原有提示词迁入 AIPrompt。迁移 0199 清空旧目录，创建 12 条新记录：四个通话场景（英语旅行、日语旅行、商务、口语陪练）和八条系统指令（默认助手、翻译语言识别、摄像头控制、结束通话、三个工具说明、摄像头状态同步）。迁移只执行一次；后续后台修改不被启动或请求覆盖。旧记录的 UUID 失效，旧提示词选择回退到后台默认指令；旧客户端场景 ID 在新客户端加载配置时转换为新提示词 UUID。

管理后台 AI prompts 可编辑正文、名称、排序、启停。`code` 是稳定用途标识，请保留已有标识；`scope=call` 是用户可选场景，`scope=system` 是系统指令，不出现在用户场景列表，也不能通过场景 UUID 被误选。

- `call.scene.travel`、`call.scene.travel_ja`、`call.scene.business`、`call.scene.practice`：通话场景。
- `call.default`：默认通话指令。
- `translation.language_detection`：语言识别模板，支持 `{source_language}`、`{target_language}`。
- `call.tool.camera`、`call.tool.end_call`：工具调用规则。
- `call.tool.description.set_camera_enabled`、`call.tool.description.get_camera_state`、`call.tool.description.end_call`：工具说明。
- `call.tool.camera_state`：摄像头状态同步模板，支持 `{camera_state}`。

通话配置接口返回启用的 call 场景，带 UUID、code、label、content。通话分配接口读取当前后台正文，并返回 `instructions` 和 `tool_instructions`；客户端按实际可用工具拼接规则及说明，不再用本地场景正文覆盖后台结果。双语互译语言识别会话返回渲染后的 `instructions`，AOQ/WebRTC 共用。手动指定方向不申请语言识别会话，因此不依赖该模板。双语互译场景仍只记录偏好，不自动把通话场景提示词发送给翻译模型。

客户端保留场景历史标识、界面文案、工具名称、参数结构和执行逻辑，不保留提示词正文。必需的系统提示词被停用、缺失或为空时，后端在分配付费模型连接前返回 503，不回退到旧硬编码正文。提示词在新建会话时读取；后台修改不打断已建立的会话。
