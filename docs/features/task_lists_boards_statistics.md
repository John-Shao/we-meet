# 任务清单、分组、看板与统计当前功能说明

任务模块用“任务清单”承载轻量项目，用组织级“自定义分组”表达阶段或分类；列表、看板和统计共享相同的任务可见性与筛选条件。

## 产品结构

- **清单导航分组**：`TaskListGroup` 用于在左侧导航组织多个任务清单，由创建人或组织管理员管理。
- **任务清单**：`TaskList` 是组织级轻量项目容器，包含名称、说明、颜色、归档状态和成员权限。
- **独立任务**：没有 `task_list` 的任务；虚拟“独立任务”入口只用于筛选，不具备清单管理操作。
- **自定义分组**：`TaskGroup` 是独立于任务清单的组织级任务属性。Web 二级导航和 Android 任务抽屉展示全部自定义分组，并提供创建、管理和直接筛选入口；旧数据可保留可选的来源清单关联以兼容原有权限。
- **列表**：支持表内编辑、字段排序、自定义分组和跨分组拖动。
- **看板**：按 `todo`、`completed` 两种状态分列；拖动卡片复用任务状态权限和校验。
- **统计**：展示任务总数、未完成、已完成、逾期、完成率、负责人工作量和分组进度。

选中某个任务清单后，列表、看板和统计限定在该清单；选中自定义分组时会清除任务清单和自定义视图，切换至“全部相关 / 未完成 / 列表”并只显示该分组的任务。归档清单默认隐藏且不能新增任务，可由有管理权限的用户恢复。

## 数据与生命周期

- 清单和清单导航分组名称在组织内不区分大小写唯一。
- 自定义分组名称在组织内不区分大小写唯一。
- 删除空自定义分组后不会影响其他任务；包含任务的分组不能删除。正在查看的分组失效后，客户端回退到“全部相关”并提示用户。
- 删除任务清单时，任务的清单外键置空并保留；自定义分组及任务的分组属性不受影响。
- 删除清单可选择同时删除该清单下无负责人的任务；有负责人的任务始终保留为独立任务。
- 任务改变清单、分组或位置时写入 `placement_changed` 操作历史。

## 清单成员角色

| 能力 | viewer | editor | owner |
| --- | --- | --- | --- |
| 查看清单和清单内任务 | 是 | 是 | 是 |
| 创建、编辑和完成清单内任务 | 否 | 是 | 是 |
| 修改旧清单来源的自定义分组、删除空分组 | 否 | 是 | 是 |
| 修改或归档清单 | 否 | 是 | 是 |
| 管理清单分享成员 | 否 | 是 | 是 |
| 退出清单 | 是 | 是 | 否 |
| 删除清单 | 否 | 否 | 是 |

任务自身的创建人和负责人即使不是清单编辑者，也保留直接协作权限；关注人可查看和评论，但不能编辑或管理附件。清单查看者只读。

组织管理员可以管理全部清单导航分组；清单业务权限仍由 `TaskListAccess` 的 viewer/editor/owner 角色判定。

所有组织成员都能查看、选择和新建自定义分组。新建分组由创建人管理；旧清单来源分组还允许对应清单的 editor/owner 管理。排序时只有当前项和相邻项都可管理才允许交换。

## API

- `GET|POST /api/v1.0/task-list-groups/`
- `PATCH|DELETE /api/v1.0/task-list-groups/{id}/`
- `GET|POST /api/v1.0/task-lists/`
- `GET|PATCH|DELETE /api/v1.0/task-lists/{id}/`
- `GET|POST /api/v1.0/task-lists/{id}/groups/`
- `GET|POST /api/v1.0/task-lists/{id}/shares/`
- `PATCH|DELETE /api/v1.0/task-lists/{id}/shares/{user_id}/`
- `POST /api/v1.0/task-lists/{id}/leave/`
- `GET|POST /api/v1.0/task-groups/`
- `PATCH|DELETE /api/v1.0/task-groups/{id}/`
- `GET /api/v1.0/tasks/?task_list=all|unassigned|<task_list_uuid>&group=all|<group_uuid>`
- `GET /api/v1.0/tasks/statistics/?task_list=all|unassigned|<task_list_uuid>&group=all|<group_uuid>`

任务创建和修改接口接受 `task_list_id`、`group_id` 和 `position`。任务清单与自定义分组相互独立；后端要求清单属于同组织、未归档且调用者可编辑，并要求分组属于任务所在组织。非法或其他组织的 `group` 查询值返回字段级 400。

## 统计口径

- 未完成：`status=todo`。
- 已完成：`status=completed`。
- 逾期：未完成、有负责人，且截止日期早于负责人本地日期。
- 完成率：`completed / total`，四舍五入为整数百分比；总数为零时返回 0。
- 负责人工作量：多人任务分别计入每位负责人，汇总总量、未完成、已完成和逾期。
- 分组进度：按分组汇总总量与完成数，未分组任务使用 `group_id=null` 单独汇总。

统计只聚合调用者本来可见且符合当前筛选条件的任务，不能借统计接口推断其他用户的私有任务。

## 当前边界

任务清单不是完整项目管理系统。当前不提供里程碑、甘特图、容量工时、自动化规则、任务依赖或自定义字段。
