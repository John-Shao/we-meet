# T4.3 任务清单、分组、看板与统计

本阶段参考飞书任务的组织方式，用“任务清单”承载轻量项目，用“分组”表达清单内的阶段或分类，并让列表、看板和统计共享同一批任务与筛选条件。

## 产品结构

- **任务清单**：组织级的轻量项目容器。成员可以创建清单；创建人和组织管理员可以维护或删除清单。
- **独立任务（stand‑alone tasks）**：未加入任何任务清单的任务。存在独立任务时，导航会在普通任务清单下方显示只读的“独立任务”虚拟清单；它只用于查看全部独立任务，不提供分享、重命名、归档、退出或删除等清单操作。
- **任务分组**：只存在于某个任务清单内，可用于“待分析 / 分析中 / 确定处理”等自定义阶段。分组支持展开、收起和分组内新建任务。
- **列表视图**：按自定义分组展示任务，并在“创建人”前显示“所属清单”列；独立任务在该列显示“独立任务”。任务创建人可以把任务拖入其他分组。
- **看板视图**：按待处理、进行中、已完成、已取消四种任务状态分列。拖动卡片会复用既有状态机和权限校验。
- **统计视图**：展示任务总量、开放数、完成数、取消数、逾期数、完成率，以及负责人工作量和分组进度。

左侧二级导航保留“我负责的 / 我创建的 / 全部相关 / 已完成”等快捷入口，并在其下增加任务清单。选中清单后，列表、看板和统计都限定在该清单；未选择清单时仍可使用原有个人任务视图。

## 数据模型

- `TaskList`：组织、名称、描述、颜色、创建人、归档状态。名称在组织内不区分大小写唯一。
- `TaskGroup`：所属任务清单、名称、排序值。名称在清单内不区分大小写唯一。
- `Task.task_list`：可空；删除清单后任务保留并回到未归属状态。
- `Task.group`：可空；删除分组后任务保留并回到未分组。
- `Task.position`：为清单内自定义排序预留的稳定位置字段。

任务移动清单或分组会写入 `placement_changed` 操作历史。

## 权限与可见性

- 清单和分组按当前用户所属组织隔离。
- 清单所有者和编辑者可修改清单、维护分组及任务；只有所有者可删除清单，且所有者不能直接退出清单。查看者可以退出，但不能修改清单内容。
- 清单成员可查看清单内全部任务；查看者只读，编辑者和所有者可编辑任务。任务创建人和负责人即使不是清单编辑者，仍保留其直接协作权限。
- 任务取消及取消后的恢复始终只允许任务创建人；负责人可按原规则推进其他状态。
- 创建人、负责人、清单编辑者和所有者可发表评论和管理附件；清单查看者只能读取。
- 统计只聚合调用者本来就能在任务列表看到的任务，不能借统计接口推断其他成员的私有任务。

## API

- `GET|POST /api/v1.0/task-lists/`
- `GET|PATCH|DELETE /api/v1.0/task-lists/{id}/`
- `GET|POST /api/v1.0/task-lists/{id}/groups/`
- `PATCH|DELETE /api/v1.0/task-groups/{id}/`
- `GET /api/v1.0/tasks/?task_list=all|unassigned|<task_list_uuid>`
- `GET /api/v1.0/tasks/statistics/?task_list=all|unassigned|<task_list_uuid>`

任务创建和修改接口接受 `task_list_id`、`group_id` 和 `position`。后端校验清单属于当前组织、分组属于所选清单，并拒绝跨组织或跨清单组合。

## 统计口径

- 开放任务：`todo` 与 `in_progress`。
- 逾期任务：开放、存在负责人，且截止日期早于负责人本地日期。
- 完成率：`completed / (total - canceled)`；分母为零时返回 0。
- 负责人工作量：按负责人汇总总量、开放、完成和逾期任务。
- 分组进度：按分组汇总总量与完成数；未分组任务独立汇总。

## 当前边界

本阶段没有引入完整项目组合管理、项目成员角色、里程碑、甘特图、分组排序拖拽、任务自定义排序、容量工时或自动化规则。`TaskList` 是轻量项目容器，后续可以在不改变任务可见性模型的前提下继续演进。
