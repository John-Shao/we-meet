# 会议远程控制使用说明

适用版本：`feature/meeting-remote-control` 分支，2026-10-15。本文依据当前界面和执行逻辑编写，供内部验收使用；独立双机、真实输入完整矩阵和正式签名安装尚未全部验收，功能默认关闭。当前进展与限制见[实施记录](../reviews/meeting-remote-control-implementation-2026-10-15.md)。

## 使用前确认

- A 是操作方，使用 PC 上的 Chrome、Edge 或 We-Meet 桌面端；B 是设备所有者，使用包含远控组件的 Windows x64 桌面端。手机控制、macOS/Linux 被控不在首期范围。
- 双方用各自的已认证真人账号加入同一会议，并满足组织策略。访客、设备账号和机器人不能使用。首期不支持同一账号在两台设备同时加入同一会议。
- 管理员已按[运维说明](../installation/meeting-remote-control-operations.md)启用允许的测试范围；A 在 B 的参会者菜单中可以看到“申请远程操作”。管理员不能代替 B 同意。
- B 共享的是一块完整显示器，窗口或浏览器标签页共享不能用于被控。共享画面遵循会议原有的可见范围，也可能被会议录制。

这项授权允许 A 使用 B 的鼠标、键盘和显式文本输入。虽然指针映射到选定显示器，键盘焦点和系统快捷键仍可能影响其他显示器上的应用，不能把它当作只允许访问某一个应用的隔离区。B 应先确认控制者身份、共享屏幕和允许完成的任务。

## 申请、授权并开始操作

1. **A 发起申请。** 打开 B 的参会者菜单，选择“申请远程操作”。控制视图显示等待状态；发出申请不代表已取得控制权。
2. **B 查看申请。** 会议中的“远程控制”提示显示申请人和授权范围。B 可选择“拒绝”，或点击“查看并确认”。
3. **B 选择整屏。** 如果当前没有可用的整屏共享，点击“选择整屏并继续”。如提示替换当前共享，先点击“停止当前共享”，再选择完整屏幕。已有符合要求且已绑定的整屏共享可以直接进入本机确认。
4. **B 在本机窗口批准。** 核对申请人、显示器分辨率和剩余时间，点击“允许本次控制”。点击拒绝、关闭窗口或倒计时结束都不会批准。会议页面中的“查看并确认”本身不是最终授权。
5. **A 开始操作。** 等待共享画面可用及状态提示“已获授权，点击开始操作”，再点击“开始操作”。只有状态为“正在操作远端”且焦点在“远程屏幕操作区”时，普通键鼠才会转发。

如果申请已过期或会话已结束，A 重新申请，B 重新确认。重新连接、重新登录或重新打开页面不会继承旧授权。

## 键鼠、中文与快捷键

鼠标在远程画面中的有效区域移动、点击、滚动和拖拽；画面周围的黑边不作为远程坐标。不要尝试操作 B 的原生授权框、控制条或恢复按钮，这些区域保留给 B 本机操作。

中文等文字使用控制视图下方的“向远端输入文本”框：先完成本地输入法选字，再点击“发送文本”。以界面显示的 `256` 长度上限为准，较长内容分次发送。点击输入框时普通键鼠捕获会暂停；选字、编辑草稿或在框内按回车不会实时发送到 B。

“发送文本”只发送本次文字，不自动追加回车。需要在远端提交时，先核对目标窗口和已输入内容，再使用明确的远端 Enter 按钮。发送期间不要重复提交；只有收到执行回执才清空草稿。若提示“未收到文本执行回执”，文字可能已经输入，先核对远端画面，再决定是否重发。

控制视图提供 Enter、Tab、Esc、Ctrl+A、Ctrl+C、Ctrl+V、Ctrl+Z 按钮。A 在本机按 Esc 用于暂停捕获；需要让 B 的应用收到 Esc 时，使用界面上的远端 Esc 按钮。Ctrl+C/Ctrl+V 作用于 B 的应用和 B 的剪贴板，首期没有两台设备之间的剪贴板同步，也没有文件传输。系统保留组合或浏览器截获的快捷键不保证可转发。

## 暂停、恢复与结束

| 场景 | 当前行为与后续操作 |
| --- | --- |
| A 点击“暂停操作”、按 Esc、切到聊天或其他标签页、缩小控制视图 | 停止捕获并请求释放；回到可用画面后重新点击“开始操作”，等待通道重新开放 |
| B 在本机操作键鼠 | 暂停远控；A 无权自行解除。B 在本机状态条点击“恢复控制…”，重新确认后，A 再按界面提示开始 |
| B 只想结束控制并继续会议 | 点击原生状态条“停止控制”、托盘“停止远程控制”或会议提示中的“停止远程控制” |
| B 需要紧急停止 | 在 B 本机按 **Ctrl+Alt+Shift+F10**；停止后如需控制，重新申请并确认 |
| A 完成任务 | 点击控制视图右上角“结束” |
| 停止/替换共享、离会、断线、账号变化、锁屏/休眠、显示器配置变化 | 旧控制会话终止；环境恢复后重新申请，不自动继续执行旧输入 |

结束远控不等于结束会议，也不等于关闭屏幕共享。若不希望继续展示画面，B 另外停止共享。B 本地接管时，如果双方刚好同时按住同一修饰键，B 应松开后再按，避免把远程和物理按键当作相互独立的系统状态。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 没有“申请远程操作”入口 | 检查组织是否启用、双方是否正式登录并在同一会议、B 是否使用支持版本的 Windows 桌面端；当前已有控制会话或 B 原生能力不可用时也不会提供入口 |
| 一直要求选择整屏 | 使用 B 桌面端重新选择一块完整显示器；不要选择窗口或标签页。若显示器信息无法匹配，保留普通共享，停止远控验收并记录环境 |
| “开始操作”不可用，提示等待共享画面 | 等待画面和授权就绪，确认 B 仍在共享、会议连接正常；不要仅凭静止截图判断输入可以继续。持续不恢复时结束后重新申请 |
| “对方已暂停，请等待对方确认恢复” | 由 B 在本机状态条恢复并确认；A 反复点击开始不能代替 B 的动作 |
| 画面可见但管理员窗口或 UAC 无法操作 | 首期按普通用户权限执行，不能控制安全桌面或保证跨完整性级别输入；由 B 本地处理，再重新申请，不通过管理员运行绕过限制 |
| 原生确认窗口没有出现或很快消失 | 核对申请是否过期、是否取消、共享是否更换或连接是否变化；旧申请不能延长或自动批准，必要时发起新申请 |
| “释放结果未能确认，请检查本机键鼠状态” | 远控已被阻断；先停止测试，由 B 本地检查并松开可能保持的 Ctrl/Alt/Shift 或鼠标按钮，确认本机输入恢复正常，再完全退出并重新启动桌面端。离会、换房间或重载页面不会解除该阻断；重启本身也不能作为释放成功的证明。仍有异常时停止使用并提交诊断信息 |

发生异常时提供：桌面端版本、Windows 版本、A 的浏览器/客户端版本、发生时间、界面提示、当时是否切屏/断网/锁屏，以及显示器数量、分辨率和缩放比例。仅在必要时提供已遮挡敏感内容的截图；不要提交输入文本、密码、令牌、私钥或证书密码。

## 内部验收记录

首次双机验收至少记录 A/B 的独立设备与客户端版本、普通用户权限、共享显示器、网络条件，以及申请→B 原生批准→A 开始→操作→B 本地接管→B 恢复→停止的结果。中文发送、暂停时已按下键的释放、共享停止和断线后重新申请分别记录，不能只以“画面能看到”判断远控通过。

完整必测矩阵和发布门槛仍以[设计 §14](../plan/meeting-remote-control-design-2026-10-14.md#14-测试与验收)为准；本说明不代替双机、故障、性能、正式签名及安装升级验收。
