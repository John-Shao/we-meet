# 会议模块边界

Web 与 Android 使用同一套职责划分：

| 模块 | 负责 | 引用其他模块 |
| --- | --- | --- |
| 视频会议 | 建会、入会、预约与会中协作 | 会后查看会议实录、智能纪要 |
| AI 录音 | 独立录音、暂停与结束、实时文字与翻译、本地恢复及补传 | 保存后打开对应实录或纪要 |
| 会议实录 | 原始资料归档、音频回放、转写与重试、文字检索、翻译记录 | 打开同一资料的智能纪要 |
| 智能纪要 | 生成与阅读纪要、问答、编辑、分享及待办跟进 | 引用原文、回放位置及任务模块 |

视频会议与独立录音分别采集资料，统一进入实录和纪要。独立录音无需创建或加入视频会议，视频会议首页不嵌入录音工作区。会中字幕和本场问答仍属于会中辅助功能。

## 入口规则

- 视频会议首页展示预约和会前操作，以链接进入会后资料；跨会议 AI 搜索保留在资料库及全局搜索。
- AI 录音页保留实时转写，结束后的回放、文件转写及纪要操作由对应实录页承接。
- Web 本地列表只呈现未结束或尚有音频待处理的录音，不截断待恢复条目；不删除本地日志或音频。
- Android 实录的文字记录页通过「转写管理」复用现有转写与临时音频清理组件；打开页面不会自动提交转写任务。
- 入口调整不删除历史会议、已有资料或旧详情路由。部署中较早的历史材料仍使用现有 `backfill_meeting_records` 流程归入实录库；不能仅以房间未关闭判断会议正在进行。

所有资料读取和操作继续遵循既有账号、权限与服务开关。
