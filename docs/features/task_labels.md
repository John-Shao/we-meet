# T4.2 任务标签

## 目标与边界

任务标签用于在组织内复用轻量分类，并覆盖个人任务、会议行动项生成的任务和一级子任务。本阶段提供标签库维护、任务关联、列表筛选、语义色展示和操作历史，不引入项目、看板、统计或标签变更 IM 通知。

## 数据模型

- `TaskLabel` 隶属于一个组织，包含名称、颜色和创建人。
- 名称最长 32 个字符，在同一组织内不区分大小写唯一。
- 颜色枚举为 `grey / blue / green / yellow / orange / red / purple`，只影响展示，不承载权限或排序语义。
- `Task.organization` 持久化任务所属组织；新任务取创建人的当前组织，历史任务在迁移 `0119` 中按主组织优先的有效成员关系回填。
- `Task.labels` 是多对多关系，每个任务最多关联五个同组织标签。
- 子任务拥有独立标签，不继承父任务；会议行动项生成的任务默认无标签。

## 权限与接口

- 当前组织成员可以读取组织标签库。
- 标签创建人和组织管理员可以修改或删除标签；其他成员只能使用标签。
- 只有任务创建人可以调整任务标签，负责人不能修改。
- 删除标签只解除现有任务关联，不删除任务。

接口：

- `GET/POST /api/v1.0/task-labels/`
- `PATCH/DELETE /api/v1.0/task-labels/{id}/`
- 任务与子任务创建、任务修改通过 `label_ids` 写入，响应通过 `labels` 返回标签快照。
- `GET /api/v1.0/tasks/?label=all|unlabeled|<label_uuid>` 与范围、日期和优先级筛选按 AND 组合。

## 历史、通知与展示

标签集合实际变化时写入 `labels_changed` 操作历史，保存变更前后的标签名称和颜色；集合未变化时不写历史。标签变更本身不发送任务助手通知，避免贴标整理造成协作噪音；分派、时间提醒、改期和状态变化卡片会展示任务当前标签。

任务与子任务创建、编辑表单共用标签选择组件，任务卡片和子任务列表展示语义色标签。任务中心提供单选标签筛选以及无标签筛选；标签管理支持创建、改名、改色和带确认的删除操作，并适配五种语言、浅色/深色主题和窄屏布局。

## 发布与验收

- backend 与 frontend 使用同一 Git 短哈希镜像标签发布。
- 确认迁移 `0119_task_labels` 执行成功；本阶段没有新增环境变量或 Helm 配置。
- 验收组织隔离、同名冲突、管理权限、任务创建/编辑、最多五个限制、跨组织拒绝、组合筛选、历史记录、无变化不记录、任务助手卡片标签，以及双主题和窄屏展示。
